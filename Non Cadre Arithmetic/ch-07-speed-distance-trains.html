১. গতিবেগের একক রূপান্তরের ম্যাজিক ফ্যাক্টর

গতিবেগের অঙ্কে সবচেয়ে গুরুত্বপূর্ণ হলো কিলোমিটার/ঘণ্টা এবং মিটার/সেকেন্ডের পারস্পরিক রূপান্তর:

১ কিমি/ঘণ্টা = ১০০০ মি ÷ ৩৬০০ সে = ৫⁄১৮ মি/সে
১ মি/সে = ৩৬০০ ÷ ১০০০ = ১৮⁄৫ কিমি/ঘণ্টা
  • কিমি/ঘণ্টা ➔ মি/সে: মানকে ৫⁄১৮ দিয়ে গুণ করুন।
  • মি/সে ➔ কিমি/ঘণ্টা: মানকে ১৮⁄৫ দিয়ে গুণ করুন।
  • যেমন: ৬০ কিমি/ঘণ্টা = ৬০ × (৫/১৮) = ৫০⁄৩ মি/সে।
২. ট্রেনের দৈর্ঘ্য ও দূরত্ব অতিক্রমের ৩টি নিয়ম

ট্রেন কোনো বস্তুকে অতিক্রম করার সময় অতিক্রান্ত মোট দূরত্বের নিয়ম:

  • খুঁটি / ল্যাম্পপোস্ট / মানুষ অতিক্রম: ট্রেন শুধু তার নিজের দৈর্ঘ্য (L) অতিক্রম করে।
  • প্লাটফর্ম / সেতু / টানেল অতিক্রম: মোট অতিক্রান্ত দূরত্ব = ট্রেনের দৈর্ঘ্য (L) + প্লাটফর্মের দৈর্ঘ্য (P)।
  • সময় নির্ণয়ের মূল সূত্র: সময় (T) = মোট দূরত্ব (D) ÷ গতিবেগ (S)।
T = (L + P) ÷ Speed
৩. নৌকা ও স্রোতের গতিবেগের মূল সূত্রাবলি

নৌকার বেগ u এবং স্রোতের বেগ v হলে:

অনুকূলে কার্যকর বেগ (Downstream) = u + v
প্রতিকূলে কার্যকর বেগ (Upstream) = u - v
  • স্থির পানিতে নৌকার বেগ (u): (অনুকূলে বেগ + প্রতিকূলে বেগ)⁄২
  • স্রোতের বেগ (v): (অনুকূলে বেগ - প্রতিকূলে বেগ)⁄২
  • d দূরত্ব গিয়ে ফিরে আসার মোট সময় = d⁄(u + v) + d⁄(u - v)
৪. গড় গতিবেগ (Average Speed) সূত্র

যদি কোনো দূরত্ব নির্দিষ্ট বেগে গিয়ে পুনরায় একই দূরত্ব ভিন্ন বেগে ফিরে আসা হয়:

গড় গতিবেগ = (২ × x × y)⁄(x + y)
  • যাতায়াতের দূরত্ব সমান না হলে: গড় বেগ = মোট দূরত্ব ÷ মোট সময়।
  • দূরপাল্লার ট্রেনের ক্ষেত্রে: পৌঁছানোর সময় - ছাড়ার সময় = মোট সময়।
💡 দ্রুত গণনার গোল্ডেন ট্রিক: ১৮/৫ ও ৫/১৮ সহজে মনে রাখার উপায়!

ছোট এককে (মিটার/সেকেন্ড) যেতে হলে ছোট সংখ্যা ৫ উপরে (৫/১৮) থাকবে।
বড় এককে (কিলোমিটার/ঘণ্টা) যেতে হলে বড় সংখ্যা ১৮ উপরে (১৮/৫) থাকবে!

অতিক্রমের বিষয় মোট দূরত্ব (D) কার্যকর গতিবেগ (S) সময় সূত্র (T = D/S)
খুঁটি / ল্যাম্পপোস্ট / দাঁড়ানো ব্যক্তি ট্রেনের দৈর্ঘ্য (L) ট্রেনের বেগ (V) T = L / V
প্লাটফর্ম / ব্রিজ / কালভার্ট L + প্লাটফর্মের দৈর্ঘ্য (P) ট্রেনের বেগ (V) T = (L + P) / V
নৌকা (স্রোতের অনুকূলে) নদীর দূরত্ব (d) নৌকা + স্রোত (u + v) T = d / (u + v)
নৌকা (স্রোতের প্রতিকূলে) নদীর দূরত্ব (d) নৌকা - স্রোত (u - v) T = d / (u - v)

৬০ কিমি = ৬০,০০০ মিটার যায় ৩৬০০ সেকেন্ডে।
∴ ৪০০ মিটার অতিক্রম করতে সময় লাগবে = (৩৬০০ × ৪০০)⁄৬০,০০০ = ৩৬ × ৪⁄৬ = ২৪ সেকেন্ড।

মোট দূরত্ব = ৩০০ কিমি।
