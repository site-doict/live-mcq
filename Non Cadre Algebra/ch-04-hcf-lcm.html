ল.সা.গু ও গ.সা.গু (HCF & LCM of Algebraic Expressions)

PART 1

প্রামাণ্য ইন্টারেক্টিভ রিভিশন নোট ও সূত্রাবলি

১. মৌলিক ধারণা ও ঘাতের নিয়ম

বীজগাণিতিক রাশিমালার ক্ষেত্রে:

  • গ.সা.গু (HCF / GCD): সাধারণ উৎপাদকসমূহের সর্বনিম্ন ঘাতের গুণফল (শুধু কমন উৎপাদক)।
  • ল.সা.গু (LCM): উৎপাদকসমূহের সর্বোচ্চ ঘাতের গুণফল (কমন ও আনকমন সব উৎপাদক)।
  • পরস্পর সহমৌলিক: যদি রাশিগুলোর মধ্যে 1 ছাড়া কোনো সাধারণ উৎপাদক না থাকে, তবে গ.সা.গু = 1 এবং ল.সা.গু = রাশিগুলোর গুণফল।
`a³ - b³` ও `a³ + b³` এর মধ্যে কোনো সাধারণ উৎপাদক নেই ⇒ গ.সা.গু = `1`

২. সংখ্যা সহগ বনাম পূর্ণ রাশির গ.সা.গু

সাবধানতা (বিসিএস ফাঁদ): প্রশ্নে যদি শুধু 'সংখ্যা সহগের' গ.সা.গু জানতে চায়, তবে চলক বিবেচনায় আসবে না!
রাশিদ্বয় সংখ্যা সহগের গ.সা.গু পূর্ণ রাশির গ.সা.গু
6a²bc ও 4a³b²c² গ.সা.গু(6, 4) = 2 2a²bc
12x²y ও 18xy² গ.সা.গু(12, 18) = 6 6xy

৩. ল.সা.গু ও গ.সা.গু-র মৌলিক সম্পর্ক

যেকোনো দুটি বীজগাণিতিক রাশির ক্ষেত্রে:

১ম রাশি × ২য় রাশি = ল.সা.গু × গ.সা.গু
৪৫তম বিসিএস প্রয়োগ:
`x²y + xy²` এবং `x² + xy` রাশিদ্বয়ের ল.সা.গু ও গ.সা.গু-র গুণফল কত?
= ১ম রাশি × ২য় রাশি
= `xy(x + y) × x(x + y)`
= x²y(x + y)²

৪. ভগ্নাংশের লঘিষ্ঠকরণ ও প্রয়োগ

লব ও হরকে উৎপাদকে বিশ্লেষণ করে সাধারণ গ.সা.গু বর্জন করলে ভগ্নাংশটি লঘিষ্ঠ আকারে প্রকাশিত হয়:

`(x² - 6x + 5) / (x² - 25)`
= `{(x - 5)(x - 1)} / {(x + 5)(x - 5)}`
= (x - 1) / (x + 5)
PART 2

বিগত বছরের প্রামাণ্য প্রশ্নব্যাংক ও ইন্টারঅ্যাক্টিভ কুইজ

স্কোর: ০ / ১১
প্রশ্ন ০১ পিএসসি (স্টাফ অফিসার)-০২
a² - b² ও a³ + b³ এর গ.সা.গু কত?
সঠিক উত্তর: ক
সমাধান:
১ম রাশি = a² - b² = (a + b)(a - b)
২য় রাশি = a³ + b³ = (a + b)(a² - ab + b²)
উভয় রাশির মধ্যে সাধারণ মৌলিক উৎপাদক (a + b)।
∴ নির্ণেয় গ.সা.গু = (a + b)।
প্রশ্ন ০২ প্রতিরক্ষা মন্ত্রণালয় সহকারী পরিচালক (নন-টেকনিক্যাল)-২৩
6a²bc এবং 4a³b²c² সংখ্যা সহগের গ.সা.গু নিচের কোনটি?
সঠিক উত্তর: ঘ
ব্যাখ্যা:
প্রশ্নে স্পষ্ট করে 'সংখ্যা সহগের' গ.সা.গু জানতে চেয়েছে।
এখানে সংখ্যা সহগ দুটি হলো 6 এবং 4।
6 = 2 × 3
4 = 2 × 2
সুতরাং, সংখ্যা সহগদ্বয়ের গ.সা.গু = 2।
যেহেতু অপশনগুলোতে শুধু '2' নেই (বরং বীজগণিতীয় প্রতীকসহ দেওয়া আছে), তাই সঠিক উত্তর 'কোনোটিই নয়'।
প্রশ্ন ০৩ পররাষ্ট্র মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-২২
a² - b² এবং a³ + b³ রাশি দুইটির গ.সা.গু কত?
সঠিক উত্তর: গ
সমাধান:
১ম রাশি = a² - b² = (a + b)(a - b)
২য় রাশি = a³ + b³ = (a + b)(a² - ab + b²)
সুতরাং, সাধারণ উৎপাদক (a + b)।
∴ গ.সা.গু = (a + b)।
প্রশ্ন ০৪ পররাষ্ট্র মন্ত্রণালয় (সুপারিনটেনডেন্ট)-১৯
a³ - b³, a³ + b³ এর গ.সা.গু কত?
সঠিক উত্তর: খ
সমাধান:
১ম রাশি = a³ - b³ = (a - b)(a² + ab + b²)
২য় রাশি = a³ + b³ = (a + b)(a² - ab + b²)
এখানে রাশি দুটির মধ্যে 1 ব্যতীত কোনো সাধারণ গুণনীয়ক নেই।
∴ নির্ণেয় গ.সা.গু = 1।
প্রশ্ন ০৫ টেক্সটাইল ইঞ্জিনিয়ারিং কলেজ (ইন্সট্রাক্টর)-১৮
a³b²c², a²b³c⁴ ও a⁴b⁴c² এর গ.সা.গু কত?
সঠিক উত্তর: ক
সমাধান:
প্রদত্ত রাশিসমূহ: a³b²c², a²b³c⁴ এবং a⁴b⁴c²
এখানে প্রতিটি চলকের সর্বনিম্ন ঘাত (Lowest Power) নিতে হবে:
• a এর সর্বনিম্ন ঘাত = a²
• b এর সর্বনিম্ন ঘাত = b²
• c এর সর্বনিম্ন ঘাত = c²
∴ নির্ণেয় গ.সা.গু = a²b²c²।
প্রশ্ন ০৬ নার্সিং ও মিডওয়াইফারি অধিদপ্তর (মিডওয়াইফ)-১৭
a(a + b), ab(a + b)² এর গ.সা.গু কত?
সঠিক উত্তর: ক
সমাধান:
১ম রাশি = a(a + b)
২য় রাশি = ab(a + b)² = a · b · (a + b)(a + b)
উভয় রাশির মধ্যে সাধারণ উৎপাদক = a(a + b)।
∴ নির্ণেয় গ.সা.গু = a(a + b)।
প্রশ্ন ০৭ বিভিন্ন মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-২০১৫
x² - 11x + 30 এবং x³ - 4x² - 2x - 15 বীজগাণিতিক রাশি দুইটির গ.সা.গু কত?
সঠিক উত্তর: খ
সমাধান:
[Note: মূল বইয়ের প্রশ্নে প্রথম রাশিতে 3 টাইপ হয়েছিল, সঠিক মান 30]।
১ম রাশি = x² - 11x + 30
= x² - 6x - 5x + 30
= x(x - 6) - 5(x - 6)
= (x - 6)(x - 5)

২য় রাশি = x³ - 4x² - 2x - 15
x = 5 বসালে: 5³ - 4(5)² - 2(5) - 15 = 125 - 100 - 10 - 15 = 0
∴ (x - 5) একটি উৎপাদক।
= x³ - 5x² + x² - 5x + 3x - 15
= x²(x - 5) + x(x - 5) + 3(x - 5)
= (x - 5)(x² + x + 3)

সুতরাং সাধারণ উৎপাদক = (x - 5)।
∴ নির্ণেয় গ.সা.গু = (x - 5)।
প্রশ্ন ০৮ কারিগরি শিক্ষা অধিদপ্তর (জুনিয়র ইন্সট্রাক্টর)-১৮
x³ + x²y, x²y + xy² এর ল.সা.গু কোনটি?
সঠিক উত্তর: গ
ব্যাখ্যা:
১ম রাশি = x³ + x²y = x²(x + y)
২য় রাশি = x²y + xy² = xy(x + y)
ল.সা.গু-তে চলকসমূহের সর্বোচ্চ ঘাত ও কমন-আনকমন সব উৎপাদক আসবে:
x² ও xy এর ল.সা.গু = x²y
এবং সাধারণ উৎপাদক = (x + y)
∴ নির্ণেয় ল.সা.গু = x²y(x + y)।
প্রশ্ন ০৯ ৪৫তম বিসিএস / পিএসসি নন-ক্যাডার
x²y + xy² এবং x² + xy রাশিদ্বয়ের ল.সা.গু এবং গ.সা.গু এর গুণফল কত?
সঠিক উত্তর: গ
সমাধান:
আমরা জানি, দুটি রাশির গুণফল = তাদের ল.সা.গু × গ.সা.গু
১ম রাশি = x²y + xy² = xy(x + y)
২য় রাশি = x² + xy = x(x + y)
∴ ল.সা.গু ও গ.সা.গু এর গুণফল = ১ম রাশি × ২য় রাশি
= xy(x + y) × x(x + y)
= x²y(x + y)²।
প্রশ্ন ১০ বিভিন্ন মন্ত্রণালয়/বিভাগ/অধিদপ্তরের ব্যক্তিগত কর্মকর্তা-১৮
(x² - 6x + 5)/(x² - 25) এর লঘিষ্ঠ আকারে প্রকাশিত রূপ কোনটি?
সঠিক উত্তর: গ
সমাধান:
(x² - 6x + 5) / (x² - 25)
= (x² - 5x - x + 5) / (x² - 5²)
= {x(x - 5) - 1(x - 5)} / {(x + 5)(x - 5)}
= {(x - 5)(x - 1)} / {(x + 5)(x - 5)}
= (x - 1) / (x + 5)।
প্রশ্ন ১১ জনপ্রশাসন মন্ত্রণালয়ের সহকারী কর্মকর্তা-২০১৬
x² - 3x + 2 এবং x² - 5x + 6 এর ল.সা.গু = কত?
সঠিক উত্তর: ক
সমাধান:
১ম রাশি = x² - 3x + 2
= x² - 2x - x + 2
= x(x - 2) - 1(x - 2)
= (x - 2)(x - 1)

২য় রাশি = x² - 5x + 6
= x² - 3x - 2x + 6
= x(x - 3) - 2(x - 3)
= (x - 3)(x - 2)

∴ নির্ণেয় ল.সা.গু = (x - 1)(x - 2)(x - 3)।
