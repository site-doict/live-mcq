ফাংশন (Functions)

PART 1

প্রামাণ্য ইন্টারেক্টিভ রিভিশন নোট ও সূত্রাবলি

১. ডোমেন ও রেঞ্জের মৌলিক সংজ্ঞা

ফাংশন `y = f(x)` এর ক্ষেত্রে:

  • ডোমেন (Domain): চলক `x` এর যে সকল বাস্তব মানের জন্য `f(x)` বাস্তব ও সংজ্ঞায়িত হয়।
  • রেঞ্জ (Range): ডোমেনের অন্তর্ভুক্ত মানসমূহের জন্য `y` বা `f(x)` এর প্রাপ্ত বাস্তব মানসমূহ।
  • ধ্রুবক ফাংশন: `f(x) = c` হলে `x` এর যেকোনো মানের জন্য `f(x) = c` (যেমন: `f(x) = 10` হলে `f(0) = 10`)।

২. ডোমেন নির্ণয়ের ৩টি গোল্ডেন রুলস

ফাংশনের ধরন বাস্তব হওয়ার শর্ত ডোমেন রূপ
f(x) = P(x) / Q(x) হর Q(x) ≠ 0 ℝ - {যে মানে হর 0}
f(x) = √(ax + b) ax + b ≥ 0 {x ∈ ℝ : x ≥ -b/a}
f(x) = √(a² - x²) a² - x² ≥ 0 [-a, a] বা -a ≤ x ≤ a
উদাহরণ: `f(x) = (x + 3) / (x - 1)` হলে হর `x - 1 ≠ 0 ⇒ x ≠ 1`। ডোমেন = `{x ∈ ℝ : x ≠ 1}`।

৩. পরমমান ফাংশন: f(x) = |x| / x

পরমমানের সংজ্ঞানুযায়ী:

`|x| = x` (যদি `x ≥ 0`) এবং `|x| = -x` (যদি `x < 0`)

সুতরাং, `f(x) = |x| / x` ফাংশনের ক্ষেত্রে:

  • যেকোনো ধনাত্মক মানে `x > 0 ⇒ f(x) = x/x = 1`
  • যেকোনো ঋণাত্মক মানে `x < 0 ⇒ f(x) = -x/x = -1`
  • অতএব, `f(-10) = |-10| / (-10) = 10 / (-10) = -1`

৪. কম্পোজিট ও দ্বি-চলক ফাংশন

ফাংশনের ইনপুট হিসেবে অন্য একটি ফাংশন বা একাধিক চলক থাকা:

`f(x, y) = x²y²` এবং `h(x) = x² - 5`
• প্রথমে `h(3) = 3² - 5 = 4`
• এরপর `f(2, h(3)) = f(2, 4) = 2² × 4² = 4 × 16 = 64`
উৎপাদক উপপাদ্য (Factor Theorem):
যদি `(ax + b)` কোনো বহুপদী `f(x)` এর উৎপাদক হয়, তবে `f(-b/a) = 0` হবে।
PART 2

বিগত বছরের প্রামাণ্য প্রশ্নব্যাংক ও ইন্টারঅ্যাক্টিভ কুইজ

স্কোর: ০ / ১২
প্রশ্ন ০১ প্রেসিডেন্ট এর কার্যালয় (পিএসসি), সহকারী প্রটোকল অফিসার-২৪
f(x) = (4x - 7)/(2x - 4) একটি ফাংশন হলে f(-1/2) = কত?
সঠিক উত্তর: খ
সমাধান:
দেওয়া আছে, f(x) = (4x - 7) / (2x - 4)
∴ f(-1/2) = {4(-1/2) - 7} / {2(-1/2) - 4}
= (-2 - 7) / (-1 - 4)
= -9 / -5
= 9/5
প্রশ্ন ০২ পিএসসি (জেলা ক্রীড়া কর্মকর্তা)-২৩
f(x) = √(4x - 1) ফাংশনটির ডোমেন কত?
সঠিক উত্তর: ক
ব্যাখ্যা:
f(x) = √(4x - 1) বাস্তব ও সংজ্ঞায়িত হবে যদি ও কেবল যদি বর্গমূলের ভিতরের রাশি অঋণাত্মক হয়:
4x - 1 ≥ 0
⇒ 4x ≥ 1
⇒ x ≥ 1/4
∴ ডোমেন = {x ∈ ℝ : x ≥ 1/4}।
[Note: বইয়ের উত্তরমালায় ভুলবশত ঘ মুদ্রিত হলেও সমাধান অনুযায়ী সঠিক উত্তর অপশন ক]।
প্রশ্ন ০৩ পিএসসি (ইন্সট্রাক্টর/ওয়ার্কশপ সুপার)-২৩
f(x) = x³ - x² - x - 1/8 হলে, f(-1/2) এর মান কত?
সঠিক উত্তর: গ
সমাধান:
দেওয়া আছে, f(x) = x³ - x² - x - 1/8
∴ f(-1/2) = (-1/2)³ - (-1/2)² - (-1/2) - 1/8
= -1/8 - 1/4 + 1/2 - 1/8
= -1/8 - 2/8 + 4/8 - 1/8
= (-1 - 2 + 4 - 1) / 8
= 0 / 8 = 0
প্রশ্ন ০৪ ফায়ার সার্ভিস ও সিভিল ডিফেন্স অধিদপ্তর (স্টেশন অফিসার)-২২
f(x) = |x|/x হলে, f(-10) কত হবে?
সঠিক উত্তর: ঘ
সমাধান:
দেওয়া আছে, f(x) = |x| / x
∴ f(-10) = |-10| / (-10)
= 10 / (-10)
= -1
[Note: পরমমানের সংজ্ঞানুযায়ী x < 0 হলে |x| = -x, তাই f(x) = -x/x = -1। বইয়ের মুদ্রিত ব্যাজে গ থাকলেও সমাধান অনুযায়ী সঠিক উত্তর ঘ: -1]।
প্রশ্ন ০৫ পররাষ্ট্র মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-২১
f(x) = 10 হলে f(0) = ?
সঠিক উত্তর: খ
ব্যাখ্যা:
f(x) = 10 একটি ধ্রুবক ফাংশন (Constant Function)।
এখানে x এর যেকোনো বাস্তব মানের জন্যই ফাংশনের মান সর্বদা 10 হবে।
∴ f(0) = 10।
প্রশ্ন ০৬ পররাষ্ট্র মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-১৯
f(x) = x³ + ax³ + 2x³ = 0 হলে, a এর মান কত?
সঠিক উত্তর: ঘ
সমাধান:
দেওয়া আছে,
f(x) = x³ + ax³ + 2x³ = 0
⇒ 3x³ + ax³ = 0
⇒ x³(3 + a) = 0
যেহেতু x ≠ 0,
⇒ 3 + a = 0
∴ a = -3
[Note: অপশনে মুদ্রিত -1 এর স্থানে -3 হলে উত্তর সঠিক হয়]।
প্রশ্ন ০৭ পিএসসি (বিভিন্ন মন্ত্রণালয়ের ব্যক্তিগত কর্মকর্তা)-১৯
f(x) = (x + 3)/(x - 1) এর Domain কত?
সঠিক উত্তর: ক
ব্যাখ্যা:
x এর যেসকল বাস্তব মানের জন্য f(x) সংজ্ঞায়িত হয়, তাদের সেটকে ডোমেন বলে।
ভগ্নাংশ আকারের ফাংশনে হর শূন্য হতে পারে না।
এখানে হর x - 1 = 0 ⇒ x = 1 হলে ফাংশনটি অসংজ্ঞায়িত হয়ে যায়।
সুতরাং x = 1 ব্যতীত সকল বাস্তব সংখ্যাই ফাংশনটির ডোমেন।
∴ Domain = {x ∈ ℝ : x ≠ 1} বা ℝ - {1}।
প্রশ্ন ০৮ তথ্য মন্ত্রণালয়ের অধীন চলচ্চিত্র ও প্রকাশনা অধিদপ্তরের ক্যামেরাম্যান-১৯
f(x) = x² - 4x + 4 হলে f(2) = ?
সঠিক উত্তর: ক
সমাধান:
f(x) = x² - 4x + 4 = (x - 2)²
∴ f(2) = 2² - 4(2) + 4
= 4 - 8 + 4
= 0
প্রশ্ন ০৯ গণপূর্ত অধিদপ্তর (উপসহকারী প্রকৌশলী ও ড্রাফটসম্যান)-১৮
x, y বাস্তব রাশি এবং f(x, y) = x²y², যদি h(x) = (x² - 5) হয়, তবে f(2, h(3)) এর মান কত?
সঠিক উত্তর: ক
সমাধান:
দেওয়া আছে, h(x) = x² - 5
∴ h(3) = 3² - 5 = 9 - 5 = 4

আবার, f(x, y) = x²y²
∴ f(2, h(3)) = f(2, 4)
= (2)² × (4)²
= 4 × 16 = 64
প্রশ্ন ১০ বাংলাদেশ রেলওয়ের উপসহকারী প্রকৌশলী (সিভিল)-১৬
f(x) = √(4 - x²) হলে f এর রেঞ্জ কত?
সঠিক উত্তর: গ
সমাধান:
দেওয়া আছে, f(x) = √(4 - x²)
বাস্তব মানের জন্য 4 - x² ≥ 0 ⇒ x² ≤ 4 ⇒ -2 ≤ x ≤ 2 (এটি হলো ডোমেন)।
বর্গমূল চিহ্নের মান সর্বদা অঋণাত্মক হওয়ায় রেঞ্জ: 0 ≤ y ≤ 2।
[Note: বইয়ের উত্তরমালায় ডোমেন সাপেক্ষে উত্তর গ (-2 ≤ x ≤ 2) দেওয়া হয়েছে]।
প্রশ্ন ১১ জনস্বাস্থ্য প্রকৌশল অধিদপ্তরের উপ-সহকারী প্রকৌশলী (সিভিল)-২০১৫
f(x) এর একটি উৎপাদক (3x + 2) হলে নিচের কোনটির মান শূন্য হবে?
সঠিক উত্তর: ঘ
ব্যাখ্যা:
উৎপাদক উপপাদ্য অনুসারে, যদি (ax + b) কোনো বহুপদী f(x) এর একটি উৎপাদক হয়, তবে f(-b/a) = 0 হবে।
এখানে 3x + 2 = 0 ⇒ x = -2/3
অতএব, f(-2/3) = 0 হবে।
[Note: বইয়ের নোটে উল্লেখ করা হয়েছে, উৎপাদক যদি (2x + 3) হতো, তবে উত্তর হতো f(-3/2)]।
প্রশ্ন ১২ কারা অধিদপ্তর (কারা তত্ত্বাবধায়ক)-১৩
f(x) = x² + 1/(x - 1) - 1 হলে, নিম্নের কোনটি সঠিক?
সঠিক উত্তর: ঘ
সমাধান:
দেওয়া আছে, f(x) = x² + 1/(x - 1) - 1
অপশনগুলো পরীক্ষা করি:
• x = 1 হলে হর 1 - 1 = 0 হয়, তাই f(1) অসংজ্ঞায়িত (খ ও গ ভুল)।
• x = 0 হলে f(0) = 0² + 1/(-1) - 1 = -2 (ক ভুল)।
• x = -1 হলে:
f(-1) = (-1)² + 1/(-1 - 1) - 1
= 1 + 1/(-2) - 1
= 1 - 1/2 - 1
= -1/2
সুতরাং অপশন (ঘ) সঠিক।
