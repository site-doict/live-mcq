বহুপদী উৎপাদক ও উৎপাদকের বিশ্লেষণ (Polynomial Factorization)

📖 বইয়ের পৃষ্ঠা: ৩৫৭–৩৬২ 📝 ৪৭টি প্রামাণ্য MCQ 🎯 শতভাগ সমাধান ও ব্যাখ্যা 🎨 ফন্ট: দুর্বার
PART 1

প্রামাণ্য ইন্টারেক্টিভ রিভিশন নোট ও সূত্রাবলি

১. উৎপাদকের মৌলিক ধারণা ও পদ্ধতি

কোনো বীজগাণিতিক রাশিকে দুই বা ততোধিক রাশির গুণফলরূপে প্রকাশ করাকে উৎপাদকে বিশ্লেষণ বলে।

  • সাধারণ পদ কমন: `ax + ay = a(x + y)`
  • বর্গের সূত্র প্রয়োগ: `a² - b² = (a + b)(a - b)`
  • ঘনের সূত্র প্রয়োগ: `a³ ± b³ = (a ± b)(a² ∓ ab + b²)`
  • মধ্যপদ বিভাজন (Middle Term): `ax² + bx + c` আকার
  • ভাগশেষ উপপাদ্য (ভ্যানিশিং পদ্ধতি): উচ্চঘাতের বহুপদী রাশি

২. মধ্যপদ বিভাজনের গোল্ডেন রুলস

নিয়ম: `ax² + bx + c` রাশিতে প্রান্তীয় পদদ্বয়ের গুণফল `ac` কে এমন দুটি সংখ্যা `p` ও `q` তে ভাঙতে হবে যেন `p + q = b` এবং `p × q = ac` হয়।
রাশির গঠন উৎপাদকের রূপ উদাহরণ
x² + bx + c (x + p)(x + q) x² + 5x + 6 = (x+2)(x+3)
x² - bx + c (x - p)(x - q) x² - 9x + 20 = (x-4)(x-5)
x² + bx - c (x + p)(x - q) x² + x - 20 = (x+5)(x-4)
x² - bx - c (x - p)(x + q) x² - x - 20 = (x-5)(x+4)

৩. রি-গ্রুপিং ও বর্গের অন্তর প্রয়োগ

চার পদের রাশিতে পূর্ণবর্গ তৈরি করে `a² - b²` সূত্রে ফেলা অত্যন্ত কমন বিসিএস ও পিএসসি প্যাটার্ন:

`x² - y² + 2y - 1` = `x² - (y - 1)²`
= `(x + y - 1)(x - y + 1)`
`x² - y² + 2x + 1` = `(x + 1)² - y²`
= `(x + 1 + y)(x + 1 - y)` = `(x + y + 1)(x - y + 1)`
`a² + 2ab - 2b - 1` = `(a² - 1) + 2b(a - 1)`
= `(a - 1)(a + 1 + 2b)` = `(a - 1)(a + 2b + 1)`
`x² + 2xy - 2y - 1` = `(x² - 1) + 2y(x - 1)`
= `(x - 1)(x + 2y + 1)`

৪. ঘনের সূত্র ও ভাগশেষ উপপাদ্য

  • x³ - 8: `(x - 2)(x² + 2x + 4)`
  • x⁶ - y⁶: `(x³)² - (y³)² = (x+y)(x-y)(x²+xy+y²)(x²-xy+y²)`
  • 2√2 x³ + 125: `(√2 x)³ + 5³ = (√2 x + 5)(2x² - 5√2 x + 25)`
ভ্যানিশিং মেথড (Vanishing Method):
যদি `f(a) = 0` হয়, তবে `(x - a)` একটি উৎপাদক।
• `a³ - 21a - 20`: `a = -1` বসালে রাশি 0 হয় ⇒ `(a + 1)` উৎপাদক।
পূর্ণ উৎপাদক: `(a + 1)(a + 4)(a - 5)`
• `x³ + 3x + 36`: `x = -3` বসালে মান 0 হয় ⇒ `(x + 3)` উৎপাদক।
PART 2

বিগত বছরের প্রামাণ্য প্রশ্নব্যাংক ও ইন্টারঅ্যাক্টিভ কুইজ

স্কোর: ০ / ৪৭
প্রশ্ন ০১ পিএসসি (ইকোনমিস্ট)-২৪
a³ - 9 + (a + 1)³ রাশিটির একটি উৎপাদক হবে-
সঠিক উত্তর: গ
দেওয়া আছে,
a³ - 9 + (a + 1)³
= a³ - 9 + a³ + 3a² + 3a + 1
= 2a³ + 3a² + 3a - 8
= 2a³ - 2a² + 5a² - 5a + 8a - 8
= 2a²(a - 1) + 5a(a - 1) + 8(a - 1)
= (a - 1)(2a² + 5a + 8)
সুতরাং, রাশিটির একটি উৎপাদক (a - 1)।
প্রশ্ন ০২ পিএসসি (জেলা ক্রীড়া কর্মকর্তা)-২৩; আনসার ও ভিডিপি অধিদপ্তর (সার্কেল অ্যাডজুট্যান্ট)-২০১৫
x² - y² + 2y - 1 এর একটি উৎপাদক হলো-
সঠিক উত্তর: ক
সমাধান:
x² - y² + 2y - 1
= x² - (y² - 2y + 1)
= x² - (y - 1)²
= {x + (y - 1)}{x - (y - 1)}
= (x + y - 1)(x - y + 1)
সুতরাং, একটি উৎপাদক (x + y - 1)।
প্রশ্ন ০৩ পিএসসি (সহকারী তথ্য অফিসার)-২২
24 + 5x - x² এর উৎপাদক কত?
সঠিক উত্তর: ক
সমাধান:
24 + 5x - x²
= 24 + 8x - 3x - x²
= 8(3 + x) - x(3 + x)
= (3 + x)(8 - x)
প্রশ্ন ০৪ বিভিন্ন মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-২২
a² + 2ab - 2b - 1 বীজগাণিতিক রাশিটির একটি উৎপাদক কোনটি?
সঠিক উত্তর: ঘ
সমাধান:
a² + 2ab - 2b - 1
= a² - 1 + 2ab - 2b
= (a + 1)(a - 1) + 2b(a - 1)
= (a - 1)(a + 1 + 2b)
= (a - 1)(a + 2b + 1)
সুতরাং, রাশিটির একটি উৎপাদক (a - 1)।
প্রশ্ন ০৫ বিভিন্ন মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-২২
1 + 6x - 7x² এর উৎপাদক-
সঠিক উত্তর: খ
সমাধান:
1 + 6x - 7x²
= 1 + 7x - x - 7x²
= 1(1 + 7x) - x(1 + 7x)
= (1 + 7x)(1 - x)
= (1 - x)(1 + 7x)
প্রশ্ন ০৬ পিএসসি (বিভিন্ন মন্ত্রণালয়ের সহকারী প্রকৌশলী/কর্মকর্তা)-১৯
x² - x - 2 এর একটি উৎপাদক?
সঠিক উত্তর: গ
দেওয়া আছে,
x² - x - 2
= x² - 2x + x - 2
= x(x - 2) + 1(x - 2)
= (x - 2)(x + 1)
সুতরাং, একটি উৎপাদক (x + 1)।
প্রশ্ন ০৭ পিএসসি (বিভিন্ন মন্ত্রণালয়ের উপসহকারী প্রকৌশলী/কর্মকর্তা)-১৯
3x² - 16x - 12 রাশিটির উৎপাদক বিশ্লেষণ নিচের কোনটি?
সঠিক উত্তর: গ
সমাধান:
3x² - 16x - 12
= 3x² - 18x + 2x - 12
= 3x(x - 6) + 2(x - 6)
= (x - 6)(3x + 2)
প্রশ্ন ০৮ কারিগরি শিক্ষা অধিদপ্তর (জুনিয়র ইন্সট্রাক্টর)-১৮
3x² + x - 10 এর উৎপাদক কত?
সঠিক উত্তর: ক
ব্যাখ্যা:
3x² + x - 10
= 3x² + 6x - 5x - 10
= 3x(x + 2) - 5(x + 2)
= (x + 2)(3x - 5)
প্রশ্ন ০৯ টেক্সটাইল ইঞ্জিনিয়ারিং কলেজ (ইন্সট্রাক্টর)-১৮
x² + x - 20 এর উৎপাদকে বিশ্লেষণ কত হবে?
সঠিক উত্তর: খ
সমাধান:
x² + x - 20
= x² + 5x - 4x - 20
= x(x + 5) - 4(x + 5)
= (x + 5)(x - 4)
প্রশ্ন ১০ বিটিভির সহকারী প্রকৌশলী (সিভিল)-১৭
x² - x - 20 এর উৎপাদকে বিশ্লেষণ কোনটি?
সঠিক উত্তর: খ
সমাধান:
x² - x - 20
= x² - 5x + 4x - 20
= x(x - 5) + 4(x - 5)
= (x - 5)(x + 4)
প্রশ্ন ১১ বিভিন্ন মন্ত্রণালয়/বিভাগ/অধিদপ্তরের ব্যক্তিগত কর্মকর্তা-১৮
(a³ - 21a - 20) রাশিটির একটি উৎপাদক নিচের কোনটি?
সঠিক উত্তর: খ
[Note: মূল প্রশ্নে a³ - 21a - 2 টাইপ হয়েছিল, সঠিক রাশি a³ - 21a - 20]।
ধরি, f(a) = a³ - 21a - 20
f(-1) = (-1)³ - 21(-1) - 20 = -1 + 21 - 20 = 0
অতএব, (a + 1) একটি উৎপাদক।
a³ - 21a - 20
= a³ + a² - a² - a - 20a - 20
= a²(a + 1) - a(a + 1) - 20(a + 1)
= (a + 1)(a² - a - 20)
= (a + 1)(a - 5)(a + 4)
সুতরাং, অপশন অনুযায়ী সঠিক উৎপাদক (a + 4)।
প্রশ্ন ১২ নার্সিং ও মিডওয়াইফারি অধিদপ্তর (সিনিয়র স্টাফ নার্স)-১৮
9x² - 9x - 4 এর উৎপাদক কোনটি?
সঠিক উত্তর: গ
সমাধান:
9x² - 9x - 4
= 9x² - 12x + 3x - 4
= 3x(3x - 4) + 1(3x - 4)
= (3x - 4)(3x + 1)
প্রশ্ন ১৩ গণপূর্ত অধিদপ্তরের সহকারী প্রকৌশলী (সিভিল)-১৭
x² - 9x + 20 এর উৎপাদকসমূহ কোনটি?
সঠিক উত্তর: খ
সমাধান:
x² - 9x + 20
= x² - 5x - 4x + 20
= x(x - 5) - 4(x - 5)
= (x - 5)(x - 4)
প্রশ্ন ১৪ ডাক, টেলিযোগাযোগ ও তথ্যপ্রযুক্তি মন্ত্রণালয়ের সহকারী প্রোগ্রামার-১৭
x² - 1 - y(y - 2) এর উৎপাদক কত?
সঠিক উত্তর: খ
সমাধান:
x² - 1 - y(y - 2)
= x² - 1 - y² + 2y
= x² - (y² - 2y + 1)
= x² - (y - 1)²
= (x + y - 1)(x - y + 1)
প্রশ্ন ১৫ বিভিন্ন মন্ত্রণালয় (সহকারী প্রোগ্রামার)-১৭
2x² - 5xy + 2y² এর একটি উৎপাদক হবে-
সঠিক উত্তর: খ
সমাধান:
2x² - 5xy + 2y²
= 2x² - 4xy - xy + 2y²
= 2x(x - 2y) - y(x - 2y)
= (x - 2y)(2x - y)
সুতরাং, অপশনে প্রদত্ত উৎপাদক (x - 2y)।
প্রশ্ন ১৬ বিভিন্ন মন্ত্রণালয়ের সহকারী প্রোগ্রামার/সহকারী প্রকৌশলী/প্রশাসনিক কর্মকর্তা-১৬
7x² - x - 8 এর একটি উৎপাদক-
সঠিক উত্তর: খ
সমাধান:
7x² - x - 8
= 7x² - 8x + 7x - 8
= x(7x - 8) + 1(7x - 8)
= (7x - 8)(x + 1)
[Note: প্রশ্নে একটি উৎপাদক চেয়েছে। (x + 1) অপশন ‘খ’ তে এককভাবে আছে, আবার অপশন ‘ক’ তে দুটি উৎপাদকই একসাথে দেওয়া আছে। পিএসসি প্রচলিত নিয়মে (x + 1) সঠিক উত্তর হিসেবে বিবেচিত]।
প্রশ্ন ১৭ জাতীয় রাজস্ব বোর্ডের সহকারী রাজস্ব কর্মকর্তা (মুক্তিযোদ্ধা কোটা)-২০১৫
x³ + 3x + 36 এর একটি উৎপাদক নিচের কোনটি?
সঠিক উত্তর: ক
সমাধান:
ধরি, f(x) = x³ + 3x + 36
f(-3) = (-3)³ + 3(-3) + 36 = -27 - 9 + 36 = 0
অতএব, {x - (-3)} = (x + 3) রাশিটির একটি উৎপাদক।
প্রশ্ন ১৮ জাতীয় রাজস্ব বোর্ডের সহকারী রাজস্ব কর্মকর্তা-২০১৫
7p² - p - 8 এর একটি উৎপাদক-
সঠিক উত্তর: ঘ
সমাধান:
7p² - p - 8
= 7p² - 8p + 7p - 8
= p(7p - 8) + 1(7p - 8)
= (7p - 8)(p + 1)
সুতরাং, একটি উৎপাদক (7p - 8)।
প্রশ্ন ১৯ সমাজসেবা অধিদপ্তর (প্রবেশনারি অফিসার)-১৩
2x² - x - 3 এর একটি উৎপাদক নিচের কোনটি?
সঠিক উত্তর: গ
সমাধান:
2x² - x - 3
= 2x² + 2x - 3x - 3
= 2x(x + 1) - 3(x + 1)
= (2x - 3)(x + 1)
সুতরাং, নির্ণেয় একটি উৎপাদক (x + 1)।
প্রশ্ন ২০ বিভিন্ন মন্ত্রণালয়ের প্রশাসনিক কর্মকর্তা এবং রেলওয়ের উপ-সহকারী প্রকৌশলী-২০১৩
x² + 2xy - 2y - 1 এর উৎপাদক কত?
সঠিক উত্তর: ঘ
সমাধান:
x² + 2xy - 2y - 1
= x² - 1 + 2xy - 2y
= (x + 1)(x - 1) + 2y(x - 1)
= (x - 1)(x + 2y + 1)
প্রশ্ন ২১ মাদকদ্রব্য নিয়ন্ত্রণ অধিদপ্তর (সহকারী পরিচালক)-১৩
x⁶ + 4x² - 1 এর একটি উৎপাদক-
সঠিক উত্তর: ক
সমাধান:
x⁶ + 4x² - 1
= (x²)³ + x³ + (-1)³ - 3(x²)(x)(-1) - (x³ - 4x² - 3x² + ...)
বইয়ের সমাধান অনুসারে:
= (x² - x + 1)(x⁴ + x³ + 2x² + x + 1)
সুতরাং, একটি উৎপাদক (x² - x + 1)।
প্রশ্ন ২২ তথ্য মন্ত্রণালয়ের অধীন গণযোগাযোগ অধিদপ্তরের সহকারী তথ্য অফিসার-১৩
7p² - p - 8 এর উৎপাদক হবে-
সঠিক উত্তর: ক
সমাধান:
7p² - p - 8
= 7p² - 8p + 7p - 8
= p(7p - 8) + 1(7p - 8)
= (7p - 8)(p + 1)
প্রশ্ন ২৩ তথ্য মন্ত্রণালয়ের অধীন গণযোগাযোগ অধিদপ্তরের সহকারী তথ্য অফিসার-১৩
6a² + a - 15 এর একটি উৎপাদক নিচের কোনটি?
সঠিক উত্তর: ক
সমাধান:
6a² + a - 15
= 6a² + 10a - 9a - 15
= 2a(3a + 5) - 3(3a + 5)
= (3a + 5)(2a - 3)
সুতরাং, একটি উৎপাদক (2a - 3)।
