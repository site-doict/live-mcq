প্রামাণ্য রিভিশন নোট ও সূত্রাবলি (Study Notes & Sketchnotes)

পরীক্ষার প্রশ্নের বিশদ ব্যাখ্যা ও মূল বইয়ের তাত্ত্বিক অংশের নির্যাস থেকে সংকলিত অবশ্যজ্ঞাত নিয়ম ও সূত্রাবলি:

১. সূচকের মৌলিক সূত্রাবলি (Fundamental Laws)

যেকোনো বাস্তব সংখ্যা a, b এবং স্বাভাবিক সংখ্যা m, n এর জন্য:

  • গুণন সূত্র: a^m × a^n = a^(m+n) (ভিত্তি এক হলে গুণে পাওয়ার যোগ হয়)
  • ভাগ সূত্র: a^m ÷ a^n = a^(m-n) (ভিত্তি এক হলে ভাগে পাওয়ার বিয়োগ হয়, a ≠ 0)
  • ঘাতের ঘাত: (a^m)^n = a^(mn) = (a^n)^m
  • গুণফলের ঘাত: (ab)^n = a^n × b^n
  • ভাগফলের ঘাত: (a/b)^n = a^n / b^n (b ≠ 0)

২. শূন্য ও ঋণাত্মক সূচকের নিয়ম (Zero & Negative Exponents)

a^0 = 1 (শর্ত: a ≠ 0) | a^(-n) = 1 / a^n (a ≠ 0, n ∈ ℕ)
  • অশূন্য ভিত্তির শূন্য ঘাত: যেকোনো অশূন্য রাশির পাওয়ার শূন্য হলে তার মান সর্বদা 1 হয়। যেমন: (5x)^0 = 1, 64 × 8^0 = 64 × 1 = 64, x^0 + y^0 = 1 + 1 = 2।
  • ইনভার্স বা বিপরীত ভগ্নাংশ: (a/b)^(-n) = (b/a)^n। যেমন: (125/27)^(-2/3) = (27/125)^(2/3) = (3/5)^2 = 9/25।
  • ঋণাত্মক পাওয়ারের যোগফল: (2^-1 + 5^-1)^-1 = (1/2 + 1/5)^-1 = (7/10)^-1 = 10/7।

৩. মূলক ও ভগ্নাংশ সূচক (Radicals & Fractional Indices)

  • বর্গমূল: √a = a^(1/2)
  • ঘনমূল ও n-তম মূল: ³√a = a^(1/3), ⁿ√a = a^(1/n)
  • যৌগিক মূলক সূত্র: ⁿ√(a^m) = a^(m/n)
  • সতর্কতা: √(-a) বাস্তব সংখ্যা নয় (অবাস্তব/জটিল সংখ্যা)।

গোল্ডেন ট্রিক: সাইক্লিক বা চক্রীয় মূলকের মান

চক্রীয় উৎপাদকে ⁿ√((x^a)/(x^b)) × ... আকারের যেকোনো চক্র-ক্রমিক রাশির চূড়ান্ত মান সর্বদা ১ (1) হয়। যেমন:
mn√(x^m / x^n) × nl√(x^n / x^l) × lm√(x^l / x^m) = 1
√(x^-1 y) × √(y^-1 z) × √(z^-1 x) = 1

৪. সূচকীয় সমীকরণ সমাধানের মূলনীতি (Equation Solving)

  • ভিত্তি সমান হলে ঘাত সমান: a^x = a^y (যেখানে a > 0, a ≠ 1) হলে x = y।
    উদাহরণ: 2^(x+7) = 4^(x+2) = 2^(2x+4) ⇒ x + 7 = 2x + 4 ⇒ x = 3।
  • ঘাত সমান হলে ভিত্তি সমান: x^a = y^a (যেখানে a ≠ 0) হলে x = y।
  • ভিন্ন ভিত্তির সূচকীয় সমীকরণ: a^x = b^x (যেখানে a ≠ b এবং a, b > 0) হলে নিশ্চিতভাবে x = 0।
    উদাহরণ: 5^(3x-7) = 3^(3x-7) ⇒ 3x - 7 = 0 ⇒ x = 7/3।
  • চক্রীয় প্রতিস্থাপন: যদি a^x = b, b^y = c, c^z = a হয়, তবে xyz = 1।

০১.
1/2 × 2^(x-3) + 1 = 5 হলে, x এর মান কত?
[৪৬তম বিসিএস]
সঠিক উত্তর: ঘ
প্রামাণ্য সমাধান:
দেওয়া আছে,
1/2 × 2^(x-3) + 1 = 5
বা, 1/2 × 2^(x-3) = 5 - 1 = 4
বা, 2^(-1) × 2^(x-3) = 2^2
বা, 2^(x - 4) = 2^2
বা, x - 4 = 2
∴ x = 4 + 2 = 6।
০২.
2^(x+7) = 4^(x+2) হলে x এর মান কত?
[৪৫তম বিসিএস]
সঠিক উত্তর: খ
প্রামাণ্য সমাধান:
সমাধান:
2^(x+7) = 4^(x+2)
বা, 2^(x+7) = (2^2)^(x+2)
বা, 2^(x+7) = 2^(2x+4)
বা, x + 7 = 2x + 4
বা, 2x - x = 7 - 4
∴ x = 3।
০৩.
3√27 + 4√625 + √4 + 1^0 = ?
[পিএসসি (পররাষ্ট্র মন্ত্রণালয়) ব্যক্তিগত কর্মকর্তা-২৪]

= ³√(3³) + ⁴√(5⁴) + 2 + 1
= 3 + 5 + 2 + 1 = 11।
০৪.
যদি 3^x + 3^x + 3^x = 3^n হয়, তবে n এর প্রেক্ষিতে x এর মান কত?
[পিএসসি (ইকোনমিস্ট)-২৪]

দেওয়া আছে,
3^x + 3^x + 3^x = 3^n
বা, 3 × 3^x = 3^n
বা, 3^(x+1) = 3^n
বা, x + 1 = n
∴ x = n - 1।
০৫.
2^x / 16 = 1 হলে, x এর মান কত?
[পিএসসি (জেলা ক্রীড়া কর্মকর্তা)-২৩]

প্রামাণ্য সমাধান:
দেওয়া আছে,
2^x / 16 = 1
বা, 2^x = 16
বা, 2^x = 2^4
∴ x = 4।
০৬.
যদি a^p = b, b^q = c এবং c^r = a হয়, তবে pqr = কত?
[পিএসসি (স্টাফ অফিসার)-২৩]
সঠিক উত্তর: খ
প্রামাণ্য সমাধান:
দেওয়া আছে,
a^p = b ... (i)
b^q = c ... (ii)
c^r = a ... (iii)
(iii) নং হতে a এর মান (i) এ বসালে পাই,
(c^r)^p = b ⇒ c^(pr) = b
এখন (ii) নং সমীকরণ হতে পাই,
(b^q) = c ⇒ (b^q)^(pr) = c^(pr) = b ⇒ b^(pqr) = b^1
∴ pqr = 1।
০৭.
log_2√5 (400) = x হলে x এর মান কত?
[পিএসসি নন-ক্যাডার (সংসদ সচিবালয়) ব্যক্তিগত কর্মকর্তা-২৩]
সঠিক উত্তর: গ
প্রামাণ্য সমাধান:
দেওয়া আছে, log_(2√5) 400 = x
বা, (2√5)^x = 400
আমরা জানি, 2√5 = √20
বা, (√20)^x = 20^2 = (√20)^4
∴ x = 4।
০৮.
x^a = y, y^b = z, z^c = x হলে, abc এর মান কত?
[পিএসসি (ইন্সট্রাক্টর/ওয়ার্কশপ সুপার)-২৩]
সঠিক উত্তর: খ
প্রামাণ্য সমাধান:
দেওয়া আছে,
x^a = y ... (1)
y^b = z ... (2)
z^c = x ... (3)
(1) নং হতে y এর মান (2) এ বসালে পাই,
(x^a)^b = z ⇒ x^(ab) = z
এখন (3) নং এ z এর মান বসালে পাই,
(x^(ab))^c = x ⇒ x^(abc) = x^1
∴ abc = 1।
০৯.
x^(-4) - 0.0001 = 0 হলে, x এর মান কত?
[পিএসসি (ইন্সট্রাক্টর/ওয়ার্কশপ সুপার)-২৩]
সঠিক উত্তর: খ
প্রামাণ্য সমাধান:
দেওয়া আছে,
x^(-4) - 0.0001 = 0
বা, x^(-4) = 0.0001 = 1/10000 = 1/10^4 = 10^(-4)
বা, x^(-4) = 10^(-4)
∴ x = 10।
১০.
2^x + 2^(1-x) = 3 হলে, x এর মান কত?
[পিএসসি (সহকারী পরিবার পরিকল্পনা কর্মকর্তা)-২৩]
সঠিক উত্তর: ঘ
প্রামাণ্য সমাধান:
প্রদত্ত সমীকরণ: 2^x + 2^(1-x) = 3
বা, 2^x + 2/2^x = 3
ধরি, 2^x = a
বা, a + 2/a = 3 ⇒ a^2 + 2 = 3a ⇒ a^2 - 3a + 2 = 0
বা, (a - 1)(a - 2) = 0
∴ a = 1 অথবা a = 2
যদি a = 1 হয়: 2^x = 1 = 2^0 ⇒ x = 0
যদি a = 2 হয়: 2^x = 2 = 2^1 ⇒ x = 1
∴ x এর মান 0, 1।
১১.
4^(x+1) = 2^(x-2) হলে x এর মান কত?
[পিএসসি (জুনিয়র ইন্সট্রাক্টর)-২৩]

প্রামাণ্য সমাধান:
দেওয়া আছে,
4^(x+1) = 2^(x-2)
বা, (2^2)^(x+1) = 2^(x-2)
বা, 2^(2x+2) = 2^(x-2)
বা, 2x + 2 = x - 2
বা, 2x - x = -2 - 2
∴ x = -4।
১২.
4^(x + 1/2) = 4 হলে, x = ?
[প্রতিরক্ষা মন্ত্রণালয় (সহকারী পরিচালক নন-টেকনিক্যাল)-২৩]

১৩.
(x^p / x^q)^(p+q) × (x^q / x^r)^(q+r) × (x^r / x^p)^(r+p) এর মান কত?
[সহকারী পরিবার পরিকল্পনা কর্মকর্তা-২২]
সঠিক উত্তর: ক
প্রামাণ্য সমাধান:
প্রদত্ত রাশি = (x^(p-q))^(p+q) × (x^(q-r))^(q+r) × (x^(r-p))^(r+p)
= x^(p² - q²) × x^(q² - r²) × x^(r² - p²)
= x^(p² - q² + q² - r² + r² - p²)
= x^0 = 1।

5^x / 5 = 3^x / 3 হলে, x এর মান কত?
[ফায়ার সার্ভিস ও সিভিল ডিফেন্স অধিদপ্তর (স্টেশন অফিসার)-২২]

বা, 5^(x-1) / 3^(x-1) = 1
বা, (5/3)^(x-1) = (5/3)^0

১৬.
যদি a^x = c, b^y = a এবং c^z = b হয় তবে নিচের কোনটি সঠিক?
[বিভিন্ন মন্ত্রণালয় (সহকারী কর্মকর্তা)-২২]

প্রামাণ্য সমাধান:
দেওয়া আছে,
a^x = c ... (1)
b^y = a ... (2)
c^z = b ... (3)
(3) হতে পাই, b = c^z
(2) নং এ b এর মান বসিয়ে পাই, (c^z)^y = a ⇒ c^(yz) = a
আবার (1) নং এ c এর মান বসিয়ে পাই, (a^x)^(yz) = a ⇒ a^(xyz) = a^1
∴ xyz = 1।

১৮.
5^(3x-7) = 3^(3x-7) হলে x = কত?
[পররাষ্ট্র মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-২২]

দেওয়া আছে,
5^(3x-7) = 3^(3x-7)

বা, (5/3)^(3x-7) = (5/3)^0

বা, 2^(2x+2) = 2^5
বা, 2x + 2 = 5

[বিভিন্ন মন্ত্রণালয়ের সহকারী মেইনটেন্যান্স ইঞ্জিনিয়ার-১৭]
সঠিক উত্তর: খ
প্রামাণ্য সমাধান:
a^(2×0) + b^(2×0) = a^0 + b^0 = 1 + 1 = 2 (যেহেতু a ≠ 0, b ≠ 0)।
৫২.
a^x = y, y^b = z, z^c = x হলে, abc এর মান কত?
[স্থানীয় সরকার, পল্লী উন্নয়ন ও সমবায় মন্ত্রণালয়-১৭]

দেওয়া আছে, z^c = x
বা, (y^b)^c = x ⇒ y^(bc) = x
বা, (a^x)^(bc) = x ⇒ a^(abc) = a^1
∴ abc = 1।
৫৩.
(0.15 × 10^p) / (0.3 × 10^q) = 5 × 10^7 হলে p - q = কত?

বা, 5 × 10^(p-q-1) = 5 × 10^7
বা, p - q - 1 = 7
∴ p - q = 8।

৬১.
2^n / 2^(n-1) = কত?

৬২.
3 × 2^n - 4 × 2^(n-2) এর সরলমান নিচের কোনটি?
[বাংলাদেশ রেলওয়ের উপসহকারী প্রকৌশলী (সিভিল)-১৬]

প্রামাণ্য সমাধান:
3 × 2^n - 4 × 2^(n-2) = 3 × 2^n - 2^2 × 2^(n-2)
= 3 × 2^n - 2^(2 + n - 2)
= 3 × 2^n - 2^n = (3 - 1) × 2^n = 2 × 2^n = 2^(n+1)।

3^(-3) এর মান কত?

৬৫.
x^y = y^x, x = 2y (x ≠ 0, y ≠ 0) হলে (x, y) এর মান কত?
