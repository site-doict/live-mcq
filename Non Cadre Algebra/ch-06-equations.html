৪৩তম বিসিএস পরমমান অসমতা ও সমাধান সেট |x - 2| < 3 এর সমাধান নির্ণয়
৪০তম বিসিএস দ্বিঘাত সমীকরণের মূল ও নিশ্চায়ক D = b² - 4ac এর শর্ত ও মূলের প্রকৃতি বিশ্লেষণ
৩৮তম ও ৩৫তম বিসিএস বাস্তব সমস্যাভিত্তিক সরল সমীকরণ সংখ্যা, ভগ্নাংশ ও বেঞ্চ-ছাত্র সংক্রান্ত সমীকরণ

১. অসমতার মৌলিক স্বীকার্য ও নিয়ম

• ঋণাত্মক চিহ্নে রূপান্তর: a > b এবং c < 0 হলে ac < bc এবং a/c < b/c (অসমতার চিহ্ন উল্টে যায়)।
• ব্যস্তকরণ: a > b > 0 হলে 1/a < 1/b।
• পরমমান অসমতা:
- |x| < a ⇒ -a < x < a
- |x| > a ⇒ x < -a অথবা x > a
• দ্বিঘাত অসমতা: (x - a)(x - b) < 0 (যেখানে a < b) হলে a < x < b।

২. দ্বিঘাত সমীকরণ ও নিশ্চায়কের ধর্ম

আদর্শ দ্বিঘাত সমীকরণ: ax² + bx + c = 0
মূলদ্বয়: x = [-b ± √(b² - 4ac)] / 2a
নিশ্চায়ক (Discriminant): D = b² - 4ac
• D > 0 এবং পূর্ণবর্গ: মূলদ্বয় বাস্তব, অসমান ও মূলদ।
• D > 0 কিন্তু পূর্ণবর্গ নয়: মূলদ্বয় বাস্তব, অসমান ও অমূলদ।
• D = 0: মূলদ্বয় বাস্তব ও সমান (প্রতিটি -b/2a)।
• D < 0: মূলদ্বয় অবাস্তব / জটিল সংখ্যা।
মূলদ্বয়ের যোগফল = -b/a, গুণফল = c/a

⚡ শর্টকাট কৌশল: বাস্তব সমস্যা সমাধান

• বর্গের অন্তর: দুটি ক্রমিক সংখ্যার বর্গের অন্তর d হলে:
বড় সংখ্যা = (d + ১) ÷ ২, ছোট সংখ্যা = (d - ১) ÷ ২।

• অঙ্কদ্বয়ের স্থান বিনিময়: মূল সংখ্যা ও স্থান বিনিময়কৃত সংখ্যার পার্থক্য সর্বদা ৯ × (অঙ্কদ্বয়ের অন্তর) হবে।

• বেঞ্চ ও ছাত্র সমস্যা: প্রতি ক্ষেত্রে বেঞ্চের সমীকরণ তৈরি করে সমান ধরে এক নিমেষে ছাত্র সংখ্যা বের করা যায়।

৩. সমীকরণ বনাম অভেদ

বৈশিষ্ট্য সমীকরণ (Equation) অভেদ (Identity)
চলকের মান নির্দিষ্ট সংখ্যক মানে সিদ্ধ চলকের যেকোনো মানে সিদ্ধ
প্রতীক সমান চিহ্ন (=) অভেদ চিহ্ন (≡) বা (=)
সহগ সম্পর্ক পক্ষান্তরে সমাধান বের হয় উভয়পক্ষের অনুরূপ ঘাতের সহগ সর্বদা সমান
স্কোর: ০ / ১২৬
০১.
|x - 1| < 2 এর ক্ষেত্রে নিচের কোনটি সঠিক?
[বিভিন্ন মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-২২]
সঠিক উত্তর: গ
সমাধান:
|x - 1| < 2
⇒ -2 < x - 1 < 2
উভয়পক্ষে 1 যোগ করে পাই:
-2 + 1 < x - 1 + 1 < 2 + 1
⇒ -1 < x < 3
অতএব, ব্যবধিতে প্রকাশ করলে: x ∈ (-1, 3)।
০২.
A = {x ∈ ℕ : x² > 8, x³ < 30} হলে x এর সঠিক মান কত?
[আইন, বিচার ও সংসদ বিষয়ক মন্ত্রণালয়ের সাব-রেজিস্ট্রার-১২]
সঠিক উত্তর: খ
সমাধান:
যে সকল স্বাভাবিক সংখ্যার বর্গ 8 অপেক্ষা বড় এবং ঘন 30 অপেক্ষা ছোট:
• x = 2 হলে: 2² = 4 < 8 (শর্ত মানে না)
• x = 3 হলে: 3² = 9 > 8 এবং 3³ = 27 < 30 (উভয় শর্ত পূরণ করে)
• x = 4 হলে: 4² = 16 > 8 কিন্তু 4³ = 64 > 30 (শর্ত মানে না)
∴ সঠিক মান x = 3।
০৩.
|x - 5| ≤ 4 হলে, নিচের যে ব্যবধি সত্য তা হলো-
[স্বাস্থ্য ও পরিবার কল্যাণ মন্ত্রণালয়ের সিনিয়র স্টাফ নার্স-১৭]
সঠিক উত্তর: ঘ
সমাধান:
|x - 5| ≤ 4
⇒ -4 ≤ x - 5 ≤ 4
উভয়পক্ষে 5 যোগ করে পাই:
-4 + 5 ≤ x ≤ 4 + 5
⇒ 1 ≤ x ≤ 9
∴ ব্যবধি আকারে: x ∈ [1, 9] (বদ্ধ ব্যবধি)।
০৪.
|4x - 3| < 1 অসমতাটির সমাধান কত?
[পিএসসি (পররাষ্ট্র মন্ত্রণালয় সহকারী কর্মকর্তা)-২৪]
সঠিক উত্তর: ক
সমাধান:
|4x - 3| < 1
⇒ -1 < 4x - 3 < 1
⇒ -1 + 3 < 4x < 1 + 3
⇒ 2 < 4x < 4
4 দ্বারা ভাগ করে পাই:
2/4 < x < 4/4
⇒ 1/2 < x < 1।
০৫.
x² - 3x + 2 < 0 অসমতাটির সমাধান কোনটি?
[বিসিএস প্রিলিমিনারি ও পিএসসি নন-ক্যাডার]
সঠিক উত্তর: খ
সমাধান:
x² - 3x + 2 < 0
⇒ (x - 1)(x - 2) < 0
আমরা জানি, (x - a)(x - b) < 0 (যেখানে a < b) হলে সমাধান a < x < b হয়।
∴ 1 < x < 2।
০৬.
|4x - 3| > 1 অসমতাটির সমাধান কত?
[পররাষ্ট্র মন্ত্রণালয় (সহকারী কর্মকর্তা)-২২]
সঠিক উত্তর: খ
সমাধান:
|4x - 3| > 1
আমরা জানি, |y| > a হলে y < -a অথবা y > a হয়।
অতএব, 4x - 3 < -1 অথবা 4x - 3 > 1
⇒ 4x < 2 অথবা 4x > 4
⇒ x < 1/2 অথবা x > 1।
০৭.
|x| < 3 এর সমাধান সেট কোনটি?
[পররাষ্ট্র মন্ত্রণালয় (সুপারিনটেনডেন্ট)-১৯]
সঠিক উত্তর: গ
সমাধান:
|x| < 3 এর অর্থ হলো মূলবিন্দু থেকে x এর দূরত্ব 3 অপেক্ষা কম।
⇒ -3 < x < 3
∴ সমাধান সেট = {x ∈ ℝ : -3 < x < 3} বা ব্যবধি আকারে (-3, 3)।
০৮.
|x + 1| < 3 অসমতার সমাধান সেট হবে-
[বিডি রেলওয়ে সহকারী কমান্ড্যান্ট-১৮]
সঠিক উত্তর: ক
সমাধান:
|x + 1| < 3
⇒ -3 < x + 1 < 3
⇒ -3 - 1 < x < 3 - 1
⇒ -4 < x < 2।
০৯.
x > y এবং z < 0 হলে, নিচের কোন শর্তটি সঠিক হবে?
[বিভিন্ন মন্ত্রণালয় (সহকারী প্রোগ্রামার)-১৭]
সঠিক উত্তর: ঘ
ব্যাখ্যা:
অসমতার নিয়ম অনুসারে, কোনো অসমতার উভয়পক্ষকে একটি ঋণাত্মক সংখ্যা (z < 0) দ্বারা গুণ বা ভাগ করলে অসমতার দিক পরিবর্তন হয়ে যায় (চিহ্ন উল্টে যায়)।
যেহেতু x > y এবং z < 0,
∴ xz < yz এবং x/z < y/z।
১০.
x² - 5x + 6 < 0 এর সমাধান নিচের কোনটি?
[পল্লী উন্নয়ন ও সমবায় মন্ত্রণালয়ের সহকারী প্রকৌশলী-১৭]
সঠিক উত্তর: খ
সমাধান:
x² - 5x + 6 < 0
⇒ x² - 3x - 2x + 6 < 0
⇒ (x - 2)(x - 3) < 0
∴ 2 < x < 3।
১১.
(a - 3)(b + 3) < 0 হলে নিচের কোনটি সত্য?
[বিভিন্ন মন্ত্রণালয় সহকারী প্রকৌশলী-১৬]
সঠিক উত্তর: ক
ব্যাখ্যা:
দুটি রাশির গুণফল ঋণাত্মক (< 0) হলে রাশি দুটির একটি ধনাত্মক এবং অপরটি ঋণাত্মক হতে হবে:
যদি a - 3 > 0 এবং b + 3 < 0 হয়,
তবে a > 3 এবং b < -3।
সুতরাং অপশন (ক) সত্য।
১২.
x + 3 > 2x - 1 অসমতাটির সমাধান সেট হবে?
[আনসার ও ভিডিপি সার্কেল অ্যাডজুট্যান্ট-১৫]
সঠিক উত্তর: খ
সমাধান:
x + 3 > 2x - 1
⇒ x - 2x > -1 - 3
⇒ -x > -4
উভয়পক্ষকে -1 দ্বারা গুণ করলে অসমতার দিক পরিবর্তিত হয়:
∴ x < 4।
১৩.
x² - 7x + 12 < 0 এর সমাধান সেট কোনটি?
[৪৬তম বিসিএস প্রিলিমিনারি]
সঠিক উত্তর: খ
সমাধান:
x² - 7x + 12 < 0
⇒ x² - 4x - 3x + 12 < 0
⇒ (x - 3)(x - 4) < 0
⇒ 3 < x < 4
ব্যবধি আকারে: (3, 4)।
১৪.
x² - (a + b)x + ab = 0 এর সমাধান সেট নিচের কোনটি?
[প্রেসিডেন্ট এর কার্যালয় সহকারী প্রটোকল অফিসার-২৪]
সঠিক উত্তর: ক
সমাধান:
x² - (a + b)x + ab = 0
⇒ x² - ax - bx + ab = 0
⇒ x(x - a) - b(x - a) = 0
⇒ (x - a)(x - b) = 0
∴ x = a অথবা x = b
সমাধান সেট = {a, b}।
১৫.
(x + 5)² = x² + bx + c সমীকরণে b ও c এর মান কত হলে সমীকরণটি অভেদ হবে?
[৪৫তম বিসিএস প্রিলিমিনারি]
সঠিক উত্তর: ঘ
সমাধান:
বামপক্ষ: (x + 5)² = x² + 2·x·5 + 5² = x² + 10x + 25
ডানপক্ষ: x² + bx + c
একটি সমীকরণ অভেদ হলে উভয়পক্ষের অনুরূপ ঘাতের সহগ সমান হয়:
x এর সহগ: b = 10
ধ্রুবক পদ: c = 25
∴ b = 10, c = 25।
১৬.
4x² + x + 1 = 0 সমীকরণের মূল দুটি হবে-
[পিএসসি (ইন্সট্রাক্টর)-২৪]
সঠিক উত্তর: ক
সমাধান:
প্রদত্ত সমীকরণ: 4x² + x + 1 = 0
এখানে a = 4, b = 1, c = 1
নিশ্চায়ক (Discriminant), D = b² - 4ac
= 1² - 4·4·1 = 1 - 16 = -15
যেহেতু নিশ্চায়ক ঋণাত্মক (D < 0), তাই সমীকরণের মূল দুটি অবাস্তব (জটিল) ও অসমান হবে।
১৭.
ax² + 4x + 3 = 0 সমীকরণটির মূলদ্বয় বাস্তব ও অসমান হলে নিচের কোনটি সঠিক?
[পিএসসি নন-ক্যাডার সহকারী প্রকৌশলী]
সঠিক উত্তর: ক
সমাধান:
ax² + 4x + 3 = 0 সমীকরণের মূলদ্বয় বাস্তব ও অসমান হওয়ার শর্ত হলো নিশ্চায়ক D > 0 হতে হবে:
b² - 4ac > 0
⇒ 4² - 4·a·3 > 0
⇒ 16 - 12a > 0
⇒ -12a > -16
উভয়পক্ষকে -12 দ্বারা ভাগ করলে দিক উল্টে যায়:
∴ a < 16/12 ⇒ a < 4/3।
১৮.
x² - 3x + 2 = 0 সমীকরণের মূল দুটি হবে—
[পিএসসি (বিভিন্ন মন্ত্রণালয়ের উপসহকারী প্রকৌশলী)-১৯]
সঠিক উত্তর: ক
সমাধান:
x² - 3x + 2 = 0
⇒ (x - 1)(x - 2) = 0
∴ x = 1, 2।
মূলদ্বয় হলো 1 এবং 2 (উভয়েই বাস্তব ও মূলদ)।
১৯.
ax² + bx + c = 0 সমীকরণের মূল দুটি মূলদ হবে যদি—
[পিএসসি নন-ক্যাডার প্রশ্নব্যাংক]
সঠিক উত্তর: ক
ব্যাখ্যা:

একটি ক্লাসে ৩০ জন ছাত্রের মধ্যে ১৮ জন ফুটবল খেলে এবং ১৪ জন ক্রিকেট খেলে। কতজন কেবল ফুটবল খেলে?

৬০ মিটার দীর্ঘ রশিকে ৩ : ৭ : ১০ অনুপাতে ভাগ করলে ক্ষুদ্রতম অংশটির দৈর্ঘ্য কত মিটার?

৬০ মিটার দীর্ঘ রশিকে ৩ : ৭ : ১০ অনুপাতে ভাগ করলে মধ্যম অংশটির দৈর্ঘ্য কত মিটার?

১১৪.

[বহিরাগমন ও পাসপোর্ট অধিদপ্তর সহকারী পরিচালক-১৪]

১১৫.
ক ও খ -এর মধ্যে ১৮০ টাকা এমনভাবে ভাগ করে দিতে হবে যেন খ, ক এর টাকার দ্বিগুণ পায়। খ কত টাকা পাবে?
