১. চিহ্নের গুণন ও বন্ধনীর নিয়ম

বন্ধনী খোলার সময় বাইরে মাইনাস (-) চিহ্ন থাকলে ভেতরের সমস্ত চিহ্ন পরিবর্তিত হয়:

(-) × (-) = (+)  |  (+) × (-) = (-)
  • বন্ধনীর ক্রম: প্রথমে রেখা বন্ধনী, এরপর প্রথম বন্ধনী ( ), দ্বিতীয় বন্ধনী { }, এবং সবশেষে তৃতীয় বন্ধনী [ ]-এর কাজ সম্পন্ন করতে হয়।
  • উদাহরণ: a - [a - {a - (a - 1)}] = a - [a - {a - a + 1}] = a - [a - 1] = a - a + 1 = 1।
২. ভাগশেষ উপপাদ্য (Remainder Theorem)

কোনো বহুপদী f(x) কে (x - a) দ্বারা ভাগ করলে ভাগশেষ কত হবে তা সরাসরি নির্ণয়:

ভাগশেষ = f(a)  [যেখানে x - a = 0 ⇒ x = a]
  • যদি f(a) = 0 হয়, তবে (x - a) উক্ত বহুপদীর একটি উৎপাদক হবে।
  • প্রয়োগ: x3 - x2 কে (x - 2) দ্বারা ভাগ করলে ভাগশেষ = 23 - 22 = 8 - 4 = 4।
  • p2 + 7p + c রাশিটি (p - 5) দ্বারা বিভাজ্য হলে: 52 + 7(5) + c = 0 ⇒ c = -60।
৩. অভেদ বনাম সমীকরণ (Identity vs Equation)

চলকের মানের ওপর সমতা নির্ভরশীলতার পার্থক্য:

অভেদ: চলকের সকল বাস্তব মানের জন্য উভয়পক্ষ সমান
  • সমীকরণ: চলকের নির্দিষ্ট কয়েকটি মান (মূল) দ্বারা সিদ্ধ হয়। যেমন: x2 - 5x + 6 = 0 এর মূল কেবল 2 এবং 3।
  • অভেদ: যেকোনো বীজগাণিতিক সূত্রই অভেদ। যেমন: (a + b)2 = a2 + 2ab + b2। এখানে অভেদ উপাদান সহগ হিসেবে কাজ করে।
৪. x + 1/x থেকে জটিল রাশির মান নির্ণয়

পিএসসি পরীক্ষার সর্বাধিক কমন শর্টকাট কৌশল:

x + 1/x = k ⇒ x2 + 1 = kx
  • ভগ্নাংশ রূপান্তর: x/(x2 - 3x + 1) এর মান চাইলে হরকে সাজিয়ে লিখুন: {(x2 + 1) - 3x} = 4x - 3x = x। ফলে মান = x/x = 1।
  • x - 1/x = k হলে: x2 - 1 = kx প্রয়োগ করে সহজেই যেকোনো জটিল রাশির মান বের করা যায়।
৫. অনুপাত, সমানুপাত ও ব্যস্তানুপাত

অনুপাতের ধারাবাহিক সমতাকরণ ও ব্যস্তকরণ:

a, b, c ক্রমিক সমানুপাতিক হলে: b2 = ac
  • ব্যস্তানুপাত (Inverse Ratio): a : b এর ব্যস্তানুপাত b : a। তাই √x : y এর ব্যস্তানুপাত হবে y : √x।
  • যৌথ অনুপাত: x : y = 2 : 3 এবং y : z = 5 : 7 হলে y কে সমান করে পাই x : y : z = 10 : 15 : 21।
৬. ঋণাত্মক সংখ্যা ও অসমতার নিয়ম

অসমতার উভয়পক্ষে গুণ বা ভাগের অত্যন্ত স্পর্শকাতর বিধি:

z < 0 হলে: x > y ⇒ xz < yz (চিহ্ন উল্টে যায়)
  • ঋণাত্মক সংখ্যা দিয়ে অসমতার উভয়পক্ষকে গুণ বা ভাগ করলে অসমতার চিহ্ন অবশ্যই পরিবর্তিত হয় (> থাকলে < হয়)।
  • ব্যস্তকরণ: P > Q > 0 হলে 1/P < 1/Q হয়।
  • শূন্য দ্বারা ভাগ: কোনো অবস্থাতেই হর শূন্য (0) হতে পারে না; শূন্য দিয়ে ভাগ সর্বদা অসংজ্ঞায়িত।

🎯 লাইভ স্কোর: ০ / ১৫১
প্রশ্ন ০১ প্রেসিডেন্ট এর কার্যালয় (পিএসসি), সহকারী পরিচালক-২৪
১/২ এর সাথে কত যোগ করলে যোগফল ৩/২ হবে?

সঠিক উত্তর: খ

ধরি, নির্ণেয় সংখ্যাটি = x
প্রশ্নমতে, ১/২ + x = ৩/২
বা, x = ৩/২ - ১/২ = (৩ - ১)/২ = ২/২ = ১
সুতরাং, ১/২ এর সাথে ১ যোগ করলে যোগফল ৩/২ হবে।
প্রশ্ন ০২ লেজিসলেটিভ ও সংসদ বিষয়ক বিভাগ, সহকারী ড্রাফটসম্যান-২০
x/y + 1 = 0.01 হলে y/x = ?

সঠিক উত্তর: ঘ

দেয়া আছে, x/y + 1 = 0.01
বা, x/y = 0.01 - 1 = -0.99
বা, y/x = 1 / (-0.99) = -100/99 = -1.01 (প্রায়)।
প্রশ্ন ০৩ কারিগরি শিক্ষা অধিদপ্তর (জুনিয়র ইন্সট্রাক্টর)-১৮
x3 - x2 কে x - 2 দ্বারা ভাগ করলে অবশেষ থাকবে কত?

সঠিক উত্তর: খ

ভাগশেষ উপপাদ্য (Remainder Theorem) অনুসারে:
f(x) = x3 - x2
ভাজক x - 2 = 0 হলে, x = 2
সুতরাং, ভাগশেষ = f(2) = (2)3 - (2)2 = 8 - 4 = 4।
প্রশ্ন ০৪ বিভিন্ন মন্ত্রণালয়/বিভাগ/অধিদপ্তরের ব্যক্তিগত কর্মকর্তা-১৮
1/(x - y) এবং 1/(x + y) এর যোগফলের সাথে কত বিয়োগ করলে বিয়োগফল ২ হবে?

সঠিক উত্তর: ঘ

ধরি, P বিয়োগ করতে হবে।
প্রশ্নমতে, {1/(x - y) + 1/(x + y)} - P = 2
বা, P = {1/(x - y) + 1/(x + y)} - 2
বা, P = {(x + y) + (x - y)} / (x2 - y2) - 2
বা, P = 2x / (x2 - y2) - 2।
প্রশ্ন ০৫ গণপূর্ত অধিদপ্তর (উপ-সহকারী প্রকৌশলী ও ড্রাফটসম্যান)-১৮
(x - 3)/(x - 2) এর সাথে কত যোগ করলে যোগফল 1/(2 - x) হবে?

সঠিক উত্তর: ঘ

ধরি, P যোগ করতে হবে।
(x - 3)/(x - 2) + P = 1/(2 - x)
বা, P = 1/(2 - x) - (x - 3)/(x - 2)
বা, P = -1/(x - 2) - (x - 3)/(x - 2)
বা, P = {-1 - (x - 3)} / (x - 2) = (-1 - x + 3) / (x - 2) = (2 - x) / (x - 2) = -(x - 2)/(x - 2) = -1।
প্রশ্ন ০৬ বিভিন্ন মন্ত্রণালয়ের সহকারী প্রোগ্রামার, উপসহকারী প্রকৌশলী ২০১৬
x/y এর সাথে যে সংখ্যাটি যোগ করলে যোগফল 2y/x হয়, তা হলো—

সঠিক উত্তর: ক

নির্ণেয় সংখ্যা = 2y/x - x/y = (2y2 - x2) / xy।
প্রশ্ন ০৭ প্রবাসী কল্যাণ ও বৈদেশিক কর্মসংস্থান মন্ত্রণালয়ের সহকারী পরিচালক ২০১২
x/y এর সাথে কত যোগ করলে যোগফল 2y/x হবে?

সঠিক উত্তর: ক

নির্ণেয় রাশি = 2y/x - x/y = (2y2 - x2) / xy।
প্রশ্ন ০৮ বিভিন্ন মন্ত্রণালয় (সহকারী প্রোগ্রামার)-১৭
(a3 + b3)/(a + b) কে (a4 + b4 + a2b2)/(a3 + b3) দিয়ে ভাগ করলে কত হবে?

সঠিক উত্তর: গ

এখানে মূল প্রশ্নে (a3 + b3)/(a + b) এবং (a4 + a2b2 + b4) এর ভগ্নাংশ ভাগ করলে সঠিক উত্তর হবে a2 - b2।
প্রশ্ন ০৯ জনপ্রশাসন মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-১৬
x2 - 3x - 2 কে x + 1 দ্বারা ভাগ করলে ভাগশেষ কি হবে?

সঠিক উত্তর: খ

ভাগশেষ উপপাদ্য অনুযায়ী, x + 1 = 0 বা x = -1 বসিয়ে পাই:
ভাগশেষ = (-1)2 - 3(-1) - 2 = 1 + 3 - 2 = 2।
প্রশ্ন ১০ সেবা পরিদপ্তরের সিনিয়র স্টাফ নার্স ২০১৬
10a3b3 কে 5a3b দ্বারা ভাগ করলে ভাগফল কত হবে?

সঠিক উত্তর: খ

নির্ণেয় ভাগফল = (10a3b3) / (5a3b) = (10/5) × (a3/a3) × (b3/b) = 2 × 1 × b2 = 2b2।
প্রশ্ন ১১ পরিবার পরিকল্পনা অধিদপ্তরের সহকারী পরিকল্পনা কর্মকর্তা ২০১২
a(a2 - b2)/(a - b) কে (a3 - b3)/(a + b) দিয়ে ভাগ করলে ভাগফল কত হবে?

সঠিক উত্তর: গ

প্রদত্ত রাশি = {a(a2 - b2)/(a - b)} ÷ {(a3 - b3)/(a + b)}
= {a(a + b)(a - b)/(a - b)} × {(a + b) / (a - b)(a2 + ab + b2)}
= a(a + b)2 / (a3 - b3) বা বিস্তার করলে = a3 + a2b + ab2।
প্রশ্ন ১২ প্রেসিডেন্ট এর কার্যালয় (পিএসসি), সহকারী প্রটোকল অফিসার-২৪
y - [y - {y - (y + 1)}] = ?

সঠিক উত্তর: ক

y - [y - {y - (y + 1)}]
= y - [y - {y - y - 1}]
= y - [y - {-1}]
= y - [y + 1]
= y - y - 1 = -1।
প্রশ্ন ১৩ ডাক অধিদপ্তর (এস্টিমেটর)-১৮
x - [x - {x - (x + 1)}] = কত?

x - [x - {x - (x + 1)}]
= x - [x - {x - x - 1}]
= x - [x - {-1}]
= x - [x + 1]
= x - x - 1 = -1।
প্রশ্ন ১৪ গণপূর্ত অধিদপ্তরের উপসহকারী প্রকৌশলী (সিভিল)-১৬
a - {a - (a + 1)} = ?

সঠিক উত্তর: গ

a - {a - (a + 1)} = a - (a - a - 1) = a - (-1) = a + 1।
প্রশ্ন ১৫ পিএসসি (বিভিন্ন পদ)-১৭
1 - [a - {a - (a - (a - 1))}] = ?

1 - [a - {a - (a - (a - 1))}]
= 1 - [a - {a - (a - a + 1)}]
= 1 - [a - {a - 1}]
= 1 - [a - a + 1]
= 1 - 1 = 0।
প্রশ্ন ১৬ বিভিন্ন মন্ত্রণালয়ের সহকারী প্রোগ্রামার-১৬

a - [a - {a - (a - 1)}]

= a - [a - 1]
= a - a + 1 = 1।
