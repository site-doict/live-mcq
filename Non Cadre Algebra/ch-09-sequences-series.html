📌 ১. সমান্তর ধারা (Arithmetic Series)

যে ধারার যেকোনো পদ ও তার পূর্ববর্তী পদের অন্তর সর্বদা সমান, তাকে সমান্তর ধারা বলে।

n-তম পদ: n-তম পদ = a + (n - 1)d
n সংখ্যক পদের সমষ্টি: Sn = n/2 [2a + (n - 1)d]
Sn = ( ১ম পদ + শেষ পদ / ২ ) × পদসংখ্যা
পদসংখ্যা নির্ণয়: পদসংখ্যা = শেষ পদ - ১ম পদ/সাধারণ অন্তর + ১
স্বাভাবিক সংখ্যার সমষ্টি: ১+২+৩\( + \cdots +n = \)n(n+1)/2
বর্গের সমষ্টি: ১২+২২\( + \cdots +n \)২ = n(n+1)(2n+1)/6
ঘনের সমষ্টি: ১৩+২৩\( + \cdots +n \)৩ = [n(n+1)/2]২

📌 ২. গুণোত্তর ধারা (Geometric Series)

যেকোনো পদ ও তার পূর্ববর্তী পদের অনুপাত সর্বদা সমান হলে তাকে গুণোত্তর ধারা বলে।

n-তম পদ: n-তম পদ = arn - 1
সমষ্টি (r < 1): Sn = a(1 - rn)/1 - r
সমষ্টি (r > 1): Sn = a(rn - 1)/r - 1
অসীমতক সমষ্টি (|r| < 1): S∞ = a/1 - r
