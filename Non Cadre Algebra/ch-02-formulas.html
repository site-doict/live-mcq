১. বর্গের মৌলিক ১০টি সূত্র ও অনুসিদ্ধান্ত
(a ± b)2 = a2 ± 2ab + b2
  • অনুসিদ্ধান্ত ১: a2 + b2 = (a + b)2 - 2ab = (a - b)2 + 2ab।
  • অনুসিদ্ধান্ত ২: (a + b)2 = (a - b)2 + 4ab এবং (a - b)2 = (a + b)2 - 4ab।
  • অনুসিদ্ধান্ত ৩: 2(a2 + b2) = (a + b)2 + (a - b)2।
  • অনুসিদ্ধান্ত ৪: 4ab = (a + b)2 - (a - b)2।
  • অনুসিদ্ধান্ত ৫: ab = {(a + b)/2}2 - {(a - b)/2}2।
২. পূর্ণবর্গ রাশিতে রূপান্তরের টেকনিক

যেকোনো রাশিকে পূর্ণবর্গ করতে প্রান্তপদদ্বয়ের বর্গমূলের দ্বিগুণ মেলানো:

a2 ± 2ab + b2 = (a ± b)2

৩. x + 1/x থেকে বিভিন্ন ঘাতের শর্টকাট চার্ট

যদি x + 1/x = k হয়, তবে সরাসরি মান নির্ণয়ের জাদুসূত্র:

x2 + 1/x2 = k2 - 2  |  x3 + 1/x3 = k3 - 3k
  • যদি x - 1/x = k হয়: x2 + 1/x2 = k2 + 2 এবং x3 - 1/x3 = k3 + 3k।
  • পঞ্চম ঘাত (x5 + 1/x5): (x2 + 1/x2)(x3 + 1/x3) - (x + 1/x)।
  • ষষ্ঠ ঘাত (x6 + 1/x6): (x3 + 1/x3)2 - 2।
৪. 8xy(x2 + y2) এর সরাসরি সূত্র

পিএসসি নন-ক্যাডার পরীক্ষায় বহুল পুনরাবৃত্ত প্রশ্ন:

8xy(x2 + y2) = 4xy × 2(x2 + y2)
  • 4xy = (x + y)2 - (x - y)2 এবং 2(x2 + y2) = (x + y)2 + (x - y)2।
  • সরাসরি গুণফল: {(x + y)2 - (x - y)2} × {(x + y)2 + (x - y)2} = (x + y)4 - (x - y)4।
  • x + y = √7 এবং x - y = √3 হলে মান = (7 - 3) × (7 + 3) = 4 × 10 = ৪০।
৫. তিন রাশির বর্গ (a + b + c)2
(a + b + c)2 = a2 + b2 + c2 + 2(ab + bc + ca)
  • a2 + b2 + c2 = (a + b + c)2 - 2(ab + bc + ca)।
  • 2(ab + bc + ca) = (a + b + c)2 - (a2 + b2 + c2)।
  • যদি a + b + c = 0 হয়, তবে a2 + b2 + c2 = -2(ab + bc + ca)।
৬. কিউবিক মাস্টার কি (Cubic Master Key)

a + b + c = 0 হলে ঘনফলের কালজয়ী শর্ত:

a + b + c = 0 ⇒ a3 + b3 + c3 = 3abc
  • প্রমাণ: a + b = -c ⇒ (a + b)3 = (-c)3 ⇒ a3 + b3 + 3ab(a + b) = -c3 ⇒ a3 + b3 + c3 = 3abc।
  • x + y + z = 0 হলেও একইভাবে x3 + y3 + z3 = 3xyz হয়।
