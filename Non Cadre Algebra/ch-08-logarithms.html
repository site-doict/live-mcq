লগারিদম (Logarithms)

পিএসসি নন-ক্যাডার ও বিসিএস পরীক্ষার প্রামাণ্য প্রশ্নব্যাংক, মৌলিক সূত্রাবলি, স্কেচনোট ও নির্ভুল সমাধান।

📊 প্রশ্ন বিশ্লেষণ ছক (লগারিদম)

বিষয় ও শাখা গুরুত্বপূর্ণ টপিক ও প্রশ্ন প্রকার গড় প্রশ্ন সংখ্যা প্রস্তুতি অগ্রাধিকার
লগের সংজ্ঞানুসারে মান নির্ণয় loga x = b ⇒ ab = x রূপান্তর, অজ্ঞাত রাশি x নির্ণয় ২৮+ টি ⭐⭐⭐⭐⭐ (সর্বোচ্চ)
লগের গুণ, ভাগ ও সূচক সূত্র log(xy) = log x + log y, log(x/y) = log x - log y, log xp = p log x ২২+ টি ⭐⭐⭐⭐⭐
ভিত্তি পরিবর্তন ও লগের বৈশিষ্ট্য loga b · logb a = 1, ভিত্তি পরিবর্তনের মাধ্যমে সরলীকরণ ১৫+ টি ⭐⭐⭐⭐
ধারার সাথে লগারিদমের মিশ্রণ log 2 + log 4 + log 8 + ... ধারার যোগফল ও পদ নির্ণয় ১০+ টি ⭐⭐⭐⭐

📝 প্রামাণ্য রিভিশন নোট ও সূত্রাবলি (Sketchnotes)

📌 ১. লগারিদমের সংজ্ঞা ও অস্তিত্বের শর্ত

যদি a > 0, a ≠ 1 হয়, তবে ax = N হলে x = loga N বলা হয়। একে পড়া হয় "a ভিত্তিক N এর লগারিদম হলো x"।

⚠️ অতীব গুরুত্বপূর্ণ শর্তাবলি (পরীক্ষায় প্রায়ই আসে):
  • ভিত্তি a > 0 হতে হবে এবং a ≠ 1 হতে হবে।
  • যে সংখ্যার লগ নেওয়া হয় তাকে অবশ্যই ধনাত্মক হতে হবে (N > 0)। ঋণাত্মক বা শূন্য সংখ্যার বাস্তব লগ নেই।
  • লগারিদমের উদ্ভাবক: স্কটিশ গণিতবিদ জন নেপিয়ার (John Napier), ১৬১৪ খ্রিস্টাব্দ।

⚡ ২. মূল সূত্রাবলি এক নজরে

ভিত্তি ও ১ এর লগ: loga 1 = 0
loga a = 1
গুণের সূত্র (Product): loga (MN) = loga M + loga N
ভাগের সূত্র (Quotient): loga (M/N) = loga M - loga N
ঘাতের সূত্র (Power): loga Mr = r · loga M
ভিত্তি পরিবর্তন (Base Change): loga b = (logc b) / (logc a)
loga b · logb a = 1
বিপরীত সম্পর্ক: aloga N = N

🎯 ৩. পিএসসি পরীক্ষার বিশেষ শর্টকাট ট্রিকস

  • রুট ভিত্তির ক্ষেত্রে: log√3 81 = x হলে, (√3)x = 81 = 34 = (√3)8 ⇒ x = 8। অর্থাৎ ভিত্তির ঘাত সমান বানিয়ে তুলনা করলেই সরাসরি উত্তর বের হয়ে আসে।
  • দশমিক লগের মান: log10 (0.0001) = log10 (10-4) = -4। দশমিকে যতটি ঘরের পর ১ আছে, সূচক তত ঋণাত্মক।
  • লগারিদম ধারা: log 2 + log 4 + log 8 + ... = log 2 + 2 log 2 + 3 log 2 + ... এটি একটি সমান্তর ধারা যার প্রথম পদ a = log 2 এবং সাধারণ অন্তর d = log 2।

10 ৪৫তম বিসিএস

যদি log(x) + log(y) = log(x + y) হয়, তবে-

সঠিক উত্তর: ক. y = x/x - 1
log(x) + log(y) = log(x + y)
⇒ log(xy) = log(x + y)
⇒ xy = x + y
⇒ xy - y = x
⇒ y(x - 1) = x
∴ y = x/x - 1।
