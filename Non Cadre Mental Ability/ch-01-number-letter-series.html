📝 বিগত বছরের প্রশ্নব্যাংক

স্কোর: ০ / 27
প্রশ্ন ০১ পিএসসি - বাণিজ্য মন্ত্রণালয় (সুপারিনটেনডেন্ট)-২৪
সারিটি পূর্ণ করুন: ২৭, ৫, ২৫, ৮, ২৩, ১১, ২১, ..... , .....
সঠিক উত্তর: খ
এখানে দুটি পর্যায়ক্রমিক ধারা রয়েছে:
১ম ধারা (বিজোড় পদ): ২৭, ২৫, ২৩, ২১, ১৯ (-২ করে কমছে)
২য় ধারা (জোড় পদ): ৫, ৮, ১১, ১৪ (+৩ করে বাড়ছে)
অতএব পরবর্তী পদ দুটি যথাক্রমে ১৪ ও ১৯।
প্রশ্ন ০২ পিএসসি (ইকোনমিস্ট)-২৪
৮, ১১, ১৭, ২৯, ৫৩, ..... পরবর্তী সংখ্যাটি কত?
সঠিক উত্তর: ক
পদগুলোর অন্তর পর্যবেক্ষণ করি:
১১ - ৮ = ৩
১৭ - ১১ = ৬ (৩ × ২)
২৯ - ১৭ = ১২ (৬ × ২)
৫৩ - ২৯ = ২৪ (১২ × ২)
অতএব পরবর্তী অন্তর হবে ২৪ × ২ = ৪৮।
সুতরাং পরবর্তী সংখ্যা = ৫৩ + ৪৮ = ১০১।
প্রশ্ন ০৩ পিএসসি (সহকারী কাস্টোডিয়ান)-২৩
৬, ১৭, ৪৯, ১৪৪, ......... পরবর্তী সংখ্যাটি কত?
সঠিক উত্তর: ঘ
ধারার নিয়ম:
১ম পদ = ৬
২য় পদ = (৬ × ৩) - ১ = ১৮ - ১ = ১৭
৩য় পদ = (১৭ × ৩) - ২ = ৫১ - ২ = ৪৯
৪র্থ পদ = (৪৯ × ৩) - ৩ = ১৪৭ - ৩ = ১৪৪
৫ম পদ = (১৪৪ × ৩) - ৪ = ৪৩২ - ৪ = ৪২৮।
প্রশ্ন ০৪ বিদ্যুৎ ও জ্বালানি মন্ত্রণালয় সহকারী পরিচালক (নন-টেকনিক্যাল)-২৩
৫, ৭, ১০, ১৪, ——, ২৫ ধারায় শূন্যস্থানের সংখ্যাটি কত?
সঠিক উত্তর: গ
পদগুলোর পার্থক্য:
৭ - ৫ = ২
১০ - ৭ = ৩
১৪ - ১০ = ৪
অতএব পরবর্তী বৃদ্ধি হবে ৫: ১৪ + ৫ = ১৯
এবং ১৯ + ৬ = ২৫। সুতরাং শূন্যস্থানে বসবে ১৯।
প্রশ্ন ০৫ ফায়ার সার্ভিস ও সিভিল ডিফেন্স অধিদপ্তর (স্টেশন অফিসার)-২২
1, 3, 11, 43, --- ক্রমানুসারে পরবর্তী সংখ্যাটি কত?
সঠিক উত্তর: খ
পার্থক্য পর্যবেক্ষণ:
৩ - ১ = ২
১১ - ৩ = ৮ (২ × ৪)
৪৩ - ১১ = ৩২ (৮ × ৪)
পরবর্তী পার্থক্য = ৩২ × ৪ = ১২৮
অতএব পরবর্তী সংখ্যা = ৪৩ + ১২৮ = ১৭১।
প্রশ্ন ০৬ পিএসসি (সহকারী তথ্য অফিসার)-২২
৪, ৮, ১৩, ১৯, ২৬, ......... ধারাটির ৯ম পদ কত?
সঠিক উত্তর: গ
পদ বৃদ্ধি ক্রম:
১ম পদ = ৪
২য় পদ = ৪ + ৪ = ৮
৩য় পদ = ৮ + ৫ = ১৩
৪র্থ পদ = ১৩ + ৬ = ১৯
৫ম পদ = ১৯ + ৭ = ২৬
৬ষ্ঠ পদ = ২৬ + ৮ = ৩৪
৭ম পদ = ৩৪ + ৯ = ৪৩
৮ম পদ = ৪৩ + ১০ = ৫৩
৯ম পদ = ৫৩ + ১১ = ৬৪।
প্রশ্ন ০৭ পররাষ্ট্র মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-২২
19, 28, 39, 52, 67, ....... শূন্যস্থানে কোন সংখ্যাটি বসবে?
সঠিক উত্তর: খ
পার্থক্য:
28 - 19 = 9
39 - 28 = 11
52 - 39 = 13
67 - 52 = 15
পার্থক্য বিজোড় সংখ্যা অনুসারে ২ করে বাড়ছে। অতএব পরবর্তী পার্থক্য হবে ১৭।
সুতরাং সংখ্যাটি = 67 + 17 = 84।
প্রশ্ন ০৮ শ্রম মন্ত্রণালয় (হিসাবরক্ষক)-২১
1 থেকে 10 পর্যন্ত জোড় সংখ্যাগুলোর গড় কত?
সঠিক উত্তর: গ
1 থেকে 10 পর্যন্ত জোড় সংখ্যাগুলো হলো: 2, 4, 6, 8, 10 (মোট ৫টি সংখ্যা)।
গড় = (2 + 4 + 6 + 8 + 10) / 5 = 30 / 5 = 6।
প্রশ্ন ০৯ বাণিজ্য মন্ত্রণালয় (সুপারিনটেনডেন্ট)-১৯
সংখ্যাগুলোর পরবর্তী সংখ্যাটি নির্ণয় কর: ১, ৫, ৭, ১৩, ২১, ৩৫, .........
সঠিক উত্তর: গ
পদগুলোর সমন্বয়:
১ম + ২য় + ১ = ১ + ৫ + ১ = ৭ (৩য় পদ)
২য় + ৩য় + ১ = ৫ + ৭ + ১ = ১৩ (৪র্থ পদ)
৩য় + ৪র্থ + ১ = ৭ + ১৩ + ১ = ২১ (৫ম পদ)
৪র্থ + ৫ম + ১ = ১৩ + ২১ + ১ = ৩৫ (৬ষ্ঠ পদ)
৫ম + ৬ষ্ঠ + ১ = ২১ + ৩৫ + ১ = ৫৭ (৭ম পদ)।
প্রশ্ন ১০ গণপূর্ত অধিদপ্তর (উপ-সহকারী প্রকৌশলী)-১৮
27, -9, 3, -1... অনুক্রমের পরবর্তী সংখ্যাটি কত?
সঠিক উত্তর: ক
এটি সাধারণ অনুপাত r = -9/27 = -1/3 বিশিষ্ট গুণোত্তর অনুক্রম।
অতএব পরবর্তী পদ = (-1) × (-1/3) = 1/3।
প্রশ্ন ১১ পল্লী উন্নয়ন ও সমবায় বিভাগ (উপজেলা সমন্বয়কারী)-১৭
১, ৩, ৫, ৯, ১৭ ধারার পরবর্তী সংখ্যাটি কত?
সঠিক উত্তর: ক
পার্থক্যগুলো লক্ষ্য করি:
৩ - ১ = ২
৫ - ৩ = ২
৯ - ৫ = ৪
১৭ - ৯ = ৮
পরবর্তী পার্থক্য হবে ৮ × ২ = ১৬।
সুতরাং পরবর্তী পদ = ১৭ + ১৬ = ৩৩।
প্রশ্ন ১২ ডাক ও টেলিযোগাযোগ মন্ত্রণালয় (সহকারী প্রোগ্রামার)-১৭
৬, ১৭, ৪৯, ১৪৪ অনুক্রমটির পরবর্তী পদ কত?
সঠিক উত্তর: ঘ
প্যাটার্ন: (পদ × ৩) - ক্রমিক সংখ্যা:
৬ × ৩ - ১ = ১৭
১৭ × ৩ - ২ = ৪৯
৪৯ × ৩ - ৩ = ১৪৪
১৪৪ × ৩ - ৪ = ৪৩২ - ৪ = ৪২৮।
প্রশ্ন ১৩ পিএসসি (বিভিন্ন পদ)-১৭
২, ৪, ৩, ৭, ৪, ১০, ৫ ------- ধারাটির পরবর্তী পদ কি হবে?
সঠিক উত্তর: গ
এখানে দুটি ধারা সংমিশ্রিত আছে:
বিজোড় ক্রমে: ২, ৩, ৪, ৫... (+১ করে বাড়ছে)
জোড় ক্রমে: ৪, ৭, ১০, ... (+৩ করে বাড়ছে)
অতএব পরবর্তী পদটি হবে জোড় ক্রমের: ১০ + ৩ = ১৩।
প্রশ্ন ১৪ পরিসংখ্যান ও তথ্য ব্যবস্থাপনা অধিদপ্তর পরিসংখ্যান কর্মকর্তা-১৭
11, 15, 23, 39.... ধারার পরবর্তী সংখ্যা কত?
সঠিক উত্তর: গ
অন্তর দ্বিগুণ হারে বাড়ছে:
15 - 11 = 4
23 - 15 = 8
39 - 23 = 16
পরবর্তী বৃদ্ধি = 16 × 2 = 32।
সুতরাং পরবর্তী সংখ্যা = 39 + 32 = 71।
প্রশ্ন ১৫ বিভিন্ন মন্ত্রণালয়ের সহকারী প্রকৌশলী ও উপসহকারী প্রকৌশলী-১৬
2, 3, 5, 8, 13, 21, 34, .............. ধারাটির পরের সংখ্যাটি কত?
সঠিক উত্তর: ক
এটি একটি ফিবোনাচ্চি ধারা (Fibonacci Series), যেখানে প্রতিটি পদ পূর্ববর্তী দুটি পদের যোগফলের সমান:
২ + ৩ = ৫
৩ + ৫ = ৮
৫ + ৮ = ১৩
৮ + ১৩ = ২১
১৩ + ২১ = ৩৪
২১ + ৩৪ = ৫৫।
প্রশ্ন ১৬ সহকারী পরিবার পরিকল্পনা কর্মকর্তা-১৬
০, ৩, ৮, ১৪, ২৪, ..... ধারাটির পরবর্তী সংখ্যা কোনটি?
সঠিক উত্তর: ঘ
পার্থক্য:
৩ - ০ = ৩
৮ - ৩ = ৫ (৩ + ২)
১৪ - ৮ = ৬ (৫ + ১)
২৪ - ১৪ = ১০ (৬ + ৪)
অন্তর বৃদ্ধির প্যাটার্নে ২৪ + ১১ = ৩৫।
প্রশ্ন ১৭ আইন, বিচার ও সংসদ বিষয়ক মন্ত্রণালয় (সাব-রেজিস্ট্রার)-১৬
শূন্যস্থানে কোন সংখ্যাটি বসবে? ২১২, ১৭৯, ১৪৬, ১১৩, ——
সঠিক উত্তর: গ
প্রতিটি পদের সাধারণ অন্তর:
২১২ - ১৭৯ = ৩৩
১৭৯ - ১৪৬ = ৩৩
১৪৬ - ১১৩ = ৩৩
সুতরাং শূন্যস্থানের সংখ্যা = ১১৩ - ৩৩ = ৮০।
প্রশ্ন ১৮ বাংলাদেশ রেলওয়ে (সহকারী স্টেশন মাস্টার)-১৬
১০, ২২, ৪৬, ৯৪, ........... ধারাটির পরবর্তী সংখ্যা কত?
সঠিক উত্তর: খ
পার্থক্যগুলো লক্ষ্য করি:
২২ - ১০ = ১২
৪৬ - ২২ = ২৪ (১২ × ২)
৯৪ - ৪৬ = ৪৮ (২৪ × ২)
অতএব পরবর্তী পার্থক্য = ৪৮ × ২ = ৯৬।
সুতরাং নির্ণেয় পদ = ৯৪ + ৯৬ = ১৯০।
প্রশ্ন ১৯ এনএসআই (সহকারী পরিচালক)-২০১৫
১, ২, ৩, ৫, ৮, ১৩, ২১, ৩৪............... ধারার পরবর্তী সংখ্যা কত?
সঠিক উত্তর: ক
ফিবোনাচ্চি ধারা: ২১ + ৩৪ = ৫৫।
প্রশ্ন ২০ এনএসআই (সহকারী পরিচালক)-২০১৫

৩² = ৯
৬² = ৩৬
৯² = ৮১
১২² = ১৪৪
অতএব পরবর্তী সংখ্যা = ১৫² = ২২৫।
প্রশ্ন ২১ মাধ্যমিক ও উচ্চ শিক্ষা অধিদপ্তর হিসাবরক্ষক-১৩
৫, ৭, ১১, ১৯, —— শূন্যস্থানে কোন সংখ্যাটি বসবে?

৭ - ৫ = ২
১১ - ৭ = ৪
১৯ - ১১ = ৮

সুতরাং সংখ্যাটি = ১৯ + ১৬ = ৩৫।
প্রশ্ন ২২ সমাজসেবা অধিদপ্তর (প্রবেশনারী অফিসার)-১৩
৫, ১১, ১৯, ২৯,.... ধারার পরের সংখ্যা কত?
সঠিক উত্তর: গ
পার্থক্য জোড় ক্রম অনুসারে বাড়ছে:
১১ - ৫ = ৬
১৯ - ১১ = ৮
২৯ - ১৯ = ১০
পরবর্তী পার্থক্য = ১২।
সুতরাং পরের সংখ্যা = ২৯ + ১২ = ৪১।
প্রশ্ন ২৩ মাদকদ্রব্য নিয়ন্ত্রণ অধিদপ্তর (সহকারী পরিচালক)-১৩
১৯, ৩৩, ৫১, ৭৩, — শেষ সংখ্যাটি কত?
সঠিক উত্তর: গ
পার্থক্য:
৩৩ - ১৯ = ১৪
৫১ - ৩৩ = ১৮ (১৪ + ৪)
৭৩ - ৫১ = ২২ (১৮ + ৪)
পরবর্তী পার্থক্য = ২২ + ৪ = ২৬।
সুতরাং শেষ সংখ্যা = ৭৩ + ২৬ = ৯৯।
প্রশ্ন ২৪ মহা হিসাব নিরীক্ষক ও নিয়ন্ত্রকের কার্যালয় (অডিটর)-১১
২, ৩, ৫, ৯, ১৭- শূন্যস্থানের সংখ্যাটি কত?
সঠিক উত্তর: ক
পার্থক্য দ্বিগুণ হারে বৃদ্ধি:
৩ - ২ = ১
৫ - ৩ = ২
৯ - ৫ = ৪
১৭ - ৯ = ৮
পরবর্তী পার্থক্য = ১৬।
সুতরাং নির্ণেয় পদ = ১৭ + ১৬ = ৩৩।
প্রশ্ন ২৫ সড়ক ও জনপথ অধিদপ্তর (উপসহকারী প্রকৌশলী)-১০
১, ৯, ২৫, ৪৯, ৮১ ------ ধারাটির পরবর্তী সংখ্যাটি কত?
সঠিক উত্তর: খ
বিজোড় সংখ্যার বর্গ:
১² = ১, ৩² = ৯, ৫² = ২৫, ৭² = ৪৯, ৯² = ৮১
পরবর্তী পদ = ১১² = ১২১।
প্রশ্ন ২৬ স্বরাষ্ট্র মন্ত্রণালয় (কারা তত্ত্বাবধায়ক)-১০
১, ৪১, ............., ৮১ ধারাটির সংখ্যাগুলোর গড় কত?
সঠিক উত্তর: ক
সমান্তর ধারার গড় = (প্রথম পদ + শেষ পদ) / ২ = (১ + ৮১) / ২ = ৮২ / ২ = ৪১।
প্রশ্ন ২৭ পাসপোর্ট ও ইমিগ্রেশন অধিদপ্তর (সহকারী পরিচালক)-০৭
বিশেষ ক্রমানুযায়ী সাজানো ৯, ৩৬, ৮১, ১৪৪, ২২৫ সংখ্যাগুলোর পরবর্তী সংখ্যা কত হবে?
সঠিক উত্তর: গ
৩ এর গুণিতকের বর্গ:
৩² = ৯, ৬² = ৩৬, ৯² = ৮১, ১২² = ১৪৪, ১৫² = ২২৫
পরবর্তী পদ = ১৮² = ৩২৪।
