📝 প্রামাণ্য সন্ধি রিভিশন নোট ও সূত্রাবলি (Part 1)

📌 স্বরসন্ধি ও বিসর্গ সন্ধির প্রধান সূত্র

  • অ/আ + ই/ঈ = এ: পরম + ঈশ = পরমেশ; শুভ + ইচ্ছা = শুভেচ্ছা; যথা + ইষ্ট = যথেষ্ট; মহা + ঈশ = মহেশ।
  • অ/আ + উ/ঊ = ও: সূর্য + উদয় = সূর্যোদয়; যথা + উচিত = যথোচিত।
  • বিসর্গ সন্ধি (র-জাত ও স-জাত): নিঃ + রব = নীরব; নিঃ + রস = নীরস; দুঃ + অবস্থা = দুরবস্থা; শিরঃ + ছেদ = শিরশ্ছেদ; মনঃ + কষ্ট = মনঃকষ্ট।
  • বিসর্গের পর চ/ছ থাকলে 'শ্' হয়: শিরঃ + ছেদ = শিরশ্ছেদ; নিঃ + চয় = নিশ্চয়।

⚡ নিপাতনে সিদ্ধ সন্ধি (বিশেষ তালিকা)

  • নিপাতনে সিদ্ধ স্বরসন্ধি: গো + অক্ষ = গবাক্ষ; প্র + ঊঢ় = প্রৌঢ়; কুল + অটা = কুলটা; মার্ত + অণ্ড = মার্তণ্ড; শুদ্ধ + ওদন = শুদ্ধোদন।
  • নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি: এক + দশ = একাদশ; বৃহৎ + পতি = বৃহস্পতি; বন + পতি = বনস্পতি; গো + পদ = গোষ্পদ; আ + চর্য = আশ্চর্য।
  • নিপাতনে সিদ্ধ বিসর্গসন্ধি: অহঃ + অহ = অহরহ; অহঃ + নিশ = অহর্নিশ; বাচঃ + পতি = বাচস্পতি।

১.
'পরমেশ' শব্দটির সঠিক সন্ধি বিচ্ছেদ কোনটি? ৫০তম বিসিএস
উত্তর: (খ) পরম + ঈশ

ব্যাখ্যা: স্বরসন্ধির নিয়ম অনুসারে, অ-কার কিংবা আ-কারের পর ই-কার কিংবা ঈ-কার থাকলে উভয়ে মিলে এ-কার হয়; এ-কার পূর্ববর্তী ব্যঞ্জনের সঙ্গে যুক্ত হয়। যেমন-

  • অ + ই = এ; শুভ + ইচ্ছা = শুভেচ্ছা।
  • আ + ই = এ; যথা + ইষ্ট = যথেষ্ট।
  • অ + ঈ = এ; পরম + ঈশ = পরমেশ।
  • আ + ঈ = এ; মহা + ঈশ = মহেশ।

এরূপ- ঢাকেশ্বরী, পূর্ণেন্দু, শ্রবণেন্দ্রিয়, স্বেচ্ছা, রমেশ, নরেন্দ্র ইত্যাদি।

উৎস: বাংলা ভাষার ব্যাকরণ, নবম-দশম শ্রেণি (২০১৯-সংস্করণ)।

২.
কোন শব্দটি বিসর্গ সন্ধির মাধ্যমে গঠিত? ৪৯তম বিসিএস
উত্তর: (ক) নীরব

ব্যাখ্যা: বিসর্গ সন্ধির মাধ্যমে গঠিত শব্দটি হলো নীরব। শব্দটির সঠিক সন্ধিবিচ্ছেদ: নিঃ + রব = নীরব।

অন্যান্য বিকল্পের নিয়ম:

  • ব্যঞ্জন + ব্যঞ্জন = ব্যঞ্জনসন্ধি: আগে ৎ বা দ্ এবং পরে চ্ বা ছ্ থাকলে ৎ বা দ্ স্থানে চ্ হয়; ৎ বা দ্-এর পরে জ্ বা ঝ্ থাকলে ৎ ও দ্ স্থানে জ্ হয়। যেমন- উৎ + জ্বল = উজ্জ্বল।
  • ব্যঞ্জন + ব্যঞ্জন = ব্যঞ্জনসন্ধি: ম্-এর পর অন্তঃস্থ ধ্বনি য, র, ল, ব কিংবা শ, ষ, স, হ থাকলে, ম্ স্থলে অনুস্বার হয়। যেমন- সম্ + সার = সংসার, সম্ + গ্রাম = সংগ্রাম।
  • স্বরসন্ধি: প্রথম পদের শেষের অ-ধ্বনি বা আ-ধ্বনির সঙ্গে দ্বিতীয় পদের প্রথম হ্রস্ব-উ ধ্বনি বা দীর্ঘ-ঊ ধ্বনির যোগে ও-ধ্বনি হয়। বানানে তা ও-কারের রূপ নিয়ে আগের বর্ণে যুক্ত হয়। যেমন- কাল + উত্তীর্ণ = কালোত্তীর্ণ, মন + উত্তীর্ণ = মনোত্তীর্ণ।
৩.
'শিরশ্ছেদ' শব্দের সন্ধিবিচ্ছেদ- ৪৬তম বিসিএস
উত্তর: (খ) শিরঃ + ছেদ

ব্যাখ্যা: বিসর্গ সন্ধির নিয়ম : বিসর্গের পর অঘোষ অল্পপ্রাণ কিংবা মহাপ্রাণ তালব্য ব্যঞ্জন থাকলে বিসর্গের স্থলে তালব্য শিস্ ধ্বনি (শ্) হয়, অঘোষ মূর্ধন্য ব্যঞ্জন থাকলে মূর্ধন্য শিস্ ধ্বনি (ষ্) হয়, অঘোষ দন্ত্য ব্যঞ্জন থাকলে দন্ত্য শিস্ ধ্বনি (স্) হয়। যেমন-

  • সূত্র: (ঃ + চ / ছ = শ + চ / ছ); নিঃ + চয় = নিশ্চয়, শিরঃ + ছেদ = শিরশ্ছেদ, নিঃ + ছিদ্র = নিশ্ছিদ্র, দুঃ + চিন্তা = দুশ্চিন্তা।
  • সূত্র: (ঃ + ট / ঠ = ষ + ট / ঠ); ধনুঃ + টঙ্কার = ধনুষ্টঙ্কার, নিঃ + ঠুর = নিষ্ঠুর।
  • সূত্র: (ঃ + ত / থ = স + ত / থ); দুঃ + তর = দুস্তর, দুঃ + থ = দুস্থ।

উৎস: ভাষা-শিক্ষা, ড. হায়াৎ মামুদ এবং বাংলা ভাষার ব্যাকরণ ও নির্মিতি, নবম-দশম শ্রেণি (২০১৯-সংস্করণ)।

৪.
নিপাতনে সিদ্ধ স্বরসন্ধির দৃষ্টান্ত কোনটি? ৪৪তম বিসিএস
উত্তর: (ক) গো + অক্ষ = গবাক্ষ

ব্যাখ্যা: নিপাতনে সিদ্ধ স্বরসন্ধি: স্বরধ্বনির সাথে স্বরধ্বনির মিলনকে স্বরসন্ধি বলে। কতগুলো সন্ধি এই নিয়মের অনুসরণ করে না। এগুলোকে নিপাতনে সিদ্ধ স্বরসন্ধি বলে। যেমন-

কুলটা = কুল + অটাবিশ্বৌষ্ঠ = বিশ্ব + ওষ্ঠ
গবাক্ষ = গো + অক্ষঅক্ষৌহিণী = অক্ষ + উহিণী
প্রৌঢ় = প্র + ঊঢ়রক্তোষ্ঠ = রক্ত + ওষ্ঠ
অন্যান্য = অন্য + অন্যগবাক্ষি = গো + অক্ষি
মার্তণ্ড = মার্ত + অণ্ডগবেন্দ্র = গো + ইন্দ্র
শুদ্ধোদন = শুদ্ধ + ওদনপরস্পর = পর + পর
স্বৈর = স্ব + ঈরপ্রেষণ = প্র + এষণ
সীমন্ত = সীমন + অন্তসারঙ্গ = সার + অঙ্গ
স্বৈরিণী = স্ব + ঈরিণী

অন্যদিকে, পৌ + অক = পাবক, যতি + ইন্দ্র = যতীন্দ্র উপর্যুক্ত শব্দগুলো সাধারণ স্বরসন্ধির নিয়ম অনুসারে গঠিত হয়েছে।

৫.
'দুরবস্থা' শব্দটি সন্ধি বিচ্ছেদ করা হলে নিচের কোনটি পাওয়া যায়? ৩৯তম বিসিএস
উত্তর: (ক) দুঃ + অবস্থা

ব্যাখ্যা: বিসর্গ সন্ধি: বিসর্গের সাথে অর্থাৎ র্ ও স্-এর সাথে স্বরধ্বনির কিংবা ব্যঞ্জনধ্বনির যে সন্ধি হয় তাকে বিসর্গ সন্ধি বলে।

নিয়ম: পূর্বপদের শেষে যদি অ/আ ভিন্ন অন্য স্বরধ্বনির পর বিসর্গ (র-জাত) থাকে এবং পরপদের প্রথমে যদি স্বরধ্বনি থাকে তবে সন্ধির ফলে বিসর্গ র হয়ে যায় এবং পরের স্বরধ্বনির সঙ্গে যুক্ত হয়। જેમন-

উঃ + অ = উ + র → দুঃ + অবস্থা = দুরবস্থা, চতুঃ + অঙ্গ = চতুরঙ্গ।

৬.
'সদ্যোজাত' শব্দটি কিভাবে গঠিত হয়েছে? ৩৮তম বিসিএস
উত্তর: (গ) সদ্যঃ + জাত

ব্যাখ্যা: অ-কারের পরস্থিত স-জাত বিসর্গের পর ঘোষ অল্পপ্রাণ ও ঘোষ মহাপ্রাণ ব্যঞ্জনধ্বনি, নাসিক্য ধ্বনি কিংবা অন্তঃস্থ য, অন্তঃস্থ ব, র, ল, হ থাকলে অ-কার ও স-জাত বিসর্গ স্থলে ও-কার হয়। যেমন-

সদ্যঃ + জাত = সদ্যোজাতমনঃ + হর = মনোহর
তিরঃ + ধান = তিরোধানতপঃ + বন = তপোবন
মনঃ + রম = মনোরম
৭.
'রবীন্দ্র'-এর সঠিক সন্ধি বিচ্ছেদ কোনটি? ৩৬তম বিসিএস
উত্তর: (গ) রবি + ইন্দ্র

ব্যাখ্যা: ই/ঈ + ই/ঈ = 'ঈ'-কার (ী) হয়। যেমন-

সুধী + ইন্দ্র = সুধীন্দ্রসতী + ইন্দ্র = সতীন্দ্র
পরি + ঈক্ষা = পরীক্ষাপ্রতি + ঈক্ষা = প্রতীক্ষা
অতি + ইত = অতীতমহী + ইন্দ্র = মহীন্দ্র
রবি + ইন্দ্র = রবীন্দ্রসতী + ঈশ = সতীশ
৮.
'দ্বৈপায়ন' শব্দের শুদ্ধ সন্ধিবিচ্ছেদ কোনটি? ৩৫তম বিসিএস
উত্তর: (ক) দ্বীপ + আয়ন

ব্যাখ্যা: আয়ন (< ফক্):

(ক) বংশধর অর্থে: বাৎস + আয়ন = বাৎসায়ন, বদর + আয়ন = বাদরায়ণ, ('রামায়ণ' এই 'আয়ন' প্রত্যয়যোগে সিদ্ধ নয়। রাম অয়ন যার এই অর্থে রামায়ণ)।

(খ) এই স্থানে জাত অর্থে: দ্বীপ + আয়ন = দ্বৈপায়ন।

এই 'আয়ন'-এর সঙ্গে কৃদন্ত আয় + অন = আয়নের পার্থক্য লক্ষণীয়। দুগ্ধতায়ন, বনায়ন, দুর্বৃত্তায়ন, বিশ্বায়ন প্রভৃতি শব্দ 'আয়ন' যোগে গঠিত নয়। এ বিষয়ে অন, কৃৎপ্রত্যয় দ্রষ্টব্য। দ্বৈপায়ন শব্দটি মূলত প্রত্যয় সাধিত শব্দ যার প্রকৃতি প্রত্যয় দ্বীপ + আয়ন।

এটি সন্ধি সাধিত শব্দ নয়, সংস্কৃত তদ্ধিত প্রত্যয় সাধিত শব্দ। ৩৫তম বিসিএস প্রিলিমিনারি পরীক্ষায় এ প্রশ্নটি আসার পর থেকে বিভিন্ন প্রতিযোগিতামূলক পরীক্ষায় এসে থাকে। এটি পরীক্ষায় আসলে দ্বীপ + আয়ন = দ্বৈপায়ন উত্তর করবেন।

৯.
সন্ধি-সাধিত শব্দ 'পরস্পর' কোন ধরনের সন্ধির দৃষ্টান্ত? ৩১তম বিসিএস
উত্তর: (গ) নিপাতনে সিদ্ধ

ব্যাখ্যা: কতগুলো ব্যঞ্জন সন্ধি কোনো নিয়ম অনুসারে হয় না, এগুলোকে নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি বলে।

আ + চর্য = আশ্চর্যএক্ + দশ = একাদশ
গো + পদ = গোষ্পদপতৎ + অঞ্জলি = পতঞ্জলি
বন্ + পতি = বনস্পতিহরি + চন্দ্র = হরিশ্চন্দ্র
বৃহৎ + পতি = বৃহস্পতিদিব্ + লোক = দ্যুলোক
তৎ + কর = তস্করআ + পদ = আস্পদ
পর্ + পর = পরস্পরবিশ্ব + মিত্র = বিশ্বামিত্র
মনস্ + ঈষা = মনীষাপশ্চাৎ + অর্ধ = পশ্চার্ধ
ষট্ + দশ = ষোড়শবাক্ + ঈশ্বরী = বাগেশ্বরী
১০.
বাগাড়ম্বর শব্দের সন্ধি-বিচ্ছেদ- ৩০তম বিসিএস
উত্তর: (ঘ) বাক্ + আড়ম্বর

ব্যাখ্যা: ক, চ, ট, ত, প থাকলে এবং তাদের পরে স্বরধ্বনি থাকলে সেগুলো যথাক্রমে গ, জ, ড (ড়), দ, ব হয়। পরবর্তী স্বরধ্বনিটি পূর্ববর্তী ব্যঞ্জনধ্বনির সঙ্গে যুক্ত হয়। যেমন-

  • ক্ + আ = গ; বাক্ + আড়ম্বর = বাগাড়ম্বর
  • ক্ + অ = গ; দিক্ + অন্ত = দিগন্ত
  • ক্ + ঈ = গ; বাক্ + ঈশ = বাগীশ
  • চ্ + অ = জ; পিচ্ + অন্ত = পিজন্ত
  • ট্ + আ = ড়; ষট্ + আনন = ষড়ানন
  • ত্ + অ = দ; তৎ + অবধি = তদবধি
  • প্ + অ = ব; সুপ্ + অন্ত = সুবন্ত

এরূপ- তদন্ত, কৃদন্ত, সদানন্দ, সদুপায়, সদুপদেশ, জগদিন্দ্র ইত্যাদি।

১১.
'জনৈক' শব্দটির সন্ধি বিচ্ছেদ- ২৯তম বিসিএস
উত্তর: (খ) জন + এক

ব্যাখ্যা: অ/আ + এ/ঐ = ঐ (ৈ)-কার হয়। যেমন-

  • অ + এ = ঐ; জন + এক = জনৈক
  • আ + এ = ঐ; সদা + এব = সদৈব
  • অ + ঐ = ঐ; মত + ঐক্য = মতৈক্য
  • আ + ঐ = ঐ; মহা + ঐশ্বর্য = মহৈশ্বর্য

এরূপ- হিতৈষী, সর্বৈব, অতুলৈশ্বর্য ইত্যাদি।

১২.
কোন সন্ধিটি নিপাতনে সিদ্ধ? ২৭তম বিসিএস
উত্তর: (গ) পর + পর = পরস্পর

ব্যাখ্যা: কতগুলো সন্ধি কোনো নিয়ম অনুসারে হয় না, এগুলোকে নিপাতনে সিদ্ধ সন্ধি বলে। যেমন- পর + পর = পরস্পর।

অন্যদিকে, সম + সার = সংসার; উৎ + ছেদ = উচ্ছেদ; বাক্ + দান = বাগদান ইত্যাদি নিয়মমাফিক ব্যঞ্জনসন্ধির উদাহরণ।

১৩.
'প্রাতরাশ' এর সন্ধি - ২৩তম বিসিএস
উত্তর: (গ) প্রাতঃ + আশ

ব্যাখ্যা: কিছু বিসর্গ সন্ধির উদাহরণ হলো-

প্রাতঃ + আশ = প্রাতরাশঅন্তঃ + গত = অন্তর্গত
পুনঃ + আয় = পুনরায়পুনঃ + উক্ত = পুনরুক্ত
অন্তঃ + ধান = অন্তর্ধানঅহঃ + অহ = অহরহ
১৪.
'সন্ধি' ব্যাকরণের কোন অংশের আলোচ্য বিষয়? ১৮তম বিসিএস
উত্তর: (খ) ধ্বনিতত্ত্ব

ব্যাখ্যা: ধ্বনিতত্ত্বের আলোচ্য বিষয় সমূহ: ধ্বনির উচ্চারণ প্রণালী, উচ্চারণ স্থান, ধ্বনির প্রতীক বা বর্ণবিন্যাস, সন্ধি, ধ্বনি পরিবর্তন, ণ-ত্ব ও ষ-ত্ব বিধান ইত্যাদি। যেহেতু সন্ধি মূলত সন্নিহিত দুটি ধ্বনির মিলন, তাই এটি ব্যাকরণের ধ্বনিতত্ত্বে (Phonology) আলোচিত হয়।

১৫.
সন্ধির প্রধান সুবিধা কি? ১৮তম বিসিএস
উত্তর: (গ) উচ্চারণের সুবিধা

ব্যাখ্যা: সন্ধি : সন্নিহিত দুটি ধ্বনির মিলনকে সন্ধি বলে। সন্ধির প্রধান উদ্দেশ্য স্বাভাবিক উচ্চারণের সহজপ্রবণতা এবং ধ্বনিগত মাধুর্য সম্পাদন। সন্ধির প্রধান সুবিধা হলো উচ্চারণের সুবিধা।

১৬.
ষড়ঋতু শব্দের সন্ধি বিচ্ছেদ- ১৭তম বিসিএস
উত্তর: (ঘ) ষট্ + ঋতু

ব্যাখ্যা: এ রকম আরো কিছু উদাহরণ :

দিক্ + অন্ত = দিগন্তষট্ + ঋতু = ষড়ঋতু
বাক্ + ঈশ = বাগীশসৎ + ইচ্ছা = সদিচ্ছা
পিচ্ + অন্ত = পিজন্ততৎ + অন্ত = তদন্ত
ষট্ + আনন = ষড়াননসুপ্ + অন্ত = সুবন্ত
১৭.
দ্যুলোক শব্দের যথার্থ সন্ধি-বিচ্ছেদ কোনটি? ১৫তম বিসিএস
উত্তর: (খ) দিব্ + লোক

ব্যাখ্যা: দ্যুলোক শব্দের যথার্থ সন্ধি বিচ্ছেদ হলো দিব্ + লোক = দ্যুলোক। এটি একটি নিপাতনে সিদ্ধ সন্ধি।

১৮.
'রত্নাকর' শব্দটির সন্ধি বিচ্ছেদ- ১০তম বিসিএস
উত্তর: (ঘ) রত্ন + আকর

ব্যাখ্যা: অ/আ + অ/আ = আ (-া) - কার হয়। যেমন-

  • অ + অ = আ: নর + অধম = নরাধম। এরূপ- হিমাচল, প্রাণাধিক, হস্তান্তর, হিতাহিত ইত্যাদি।
  • অ + আ = আ: হিম + আলয় = হিমালয়। রত্ন + আকর = রত্নাকর। এরূপ- দেবালয়, সিংহাসন ইত্যাদি।
  • আ + অ = আ: যথা + অর্থ = যথার্থ। এরূপ- আশাতীত, কথামৃত, মহার্ঘ ইত্যাদি।
  • আ + আ = আ: বিদ্যা + আলয় = বিদ্যালয়। এরূপ- কারাগার, মহাশয়, সদানন্দ ইত্যাদি।
