পার্টস অব স্পিচ রূপান্তর (Transformation of Parts of Speech)

Noun, Verb, Adjective ও Adverb-এর পারস্পরিক রূপান্তর, প্রিফিক্স ও সাফিক্স ব্যবহারের মাস্টার সূত্রাবলি এবং ৮৮টি বিগত সালের প্রামাণ্য প্রশ্নব্যাংক।

📊 পিএসসি প্রশ্ন পর্যালোচনা ও রূপান্তর বিভাজন ছক
রূপান্তরের ক্যাটাগরি প্রধান সাফিক্স ও সূত্র প্রশ্ন সংখ্যা
Noun Form রূপান্তর (Q01-Q22) -tion, -ment, -ance/-ence, -al, -ty, -th, -age ২২টি
Verb Form রূপান্তর (Q23-Q62) en-, be-, -en, -ify, -ize/-ise, irregular roots ৪০টি
Adjective Form রূপান্তর (Q63-Q87) -able/-ible, -ous, -al/-ial, -ful, Latin roots (sun→solar) ২৫টি
Adverb Form রূপান্তর (Q88) Adjective + ly = Adverb (beautifully) ১টি

📝 প্রামাণ্য ইন্টারেক্টিভ রিভিশন নোট ও সূত্রাবলি (Part 1)

🏷️ Noun Form গঠনের মাস্টার সাফিক্স

Verb বা Adjective-এর শেষে সুনির্দিষ্ট সাফিক্স যুক্ত করে Noun গঠিত হয়:

  • -tion / -sion: educate → education, realize → realization, invade → invasion
  • -ance / -ence: accept → acceptance, independent → independence, signify → significance
  • -al: approve → approval, acquit → acquittal, survive → survival
  • -ty / -ity: stupid → stupidity, brief → brevity, cruel → cruelty, obstinate → obstinacy
  • -th: strong → strength, deep → depth, wide → width
  • -age: waste → wastage, marry → marriage
  • ব্যতিক্রমী Noun রূপ: do → deed, see → sight, hate → hatred, please → pleasure, believe → belief
⚡ Verb Form গঠনের প্রিফিক্স ও সাফিক্স
প্রিফিক্স রুল:
• en- / em-: danger → endanger, poor → impoverish, courage → encourage, able → enable, sure → ensure
• be-: friend → befriend, fool → befool
সাফিক্স রুল:
• -en: weak → weaken, deep → deepen, short → shorten, strength → strengthen, fresh → freshen, glad → gladden
• -ify: beauty → beautify, clear → clarify, peace → pacify, pure → purify
• -ize / -ise: memory → memorize, real → realize, trauma → traumatize, politics → politicise
🎨 Adjective Form গঠনের সূত্রাবলি
  • -able / -ible: tax → taxable, agree → agreeable, contempt → contemptible
  • -ous: people → populous, courage → courageous, tenacity → tenacious
  • -al / -ial: time → temporal, empire → imperial, literature → literary
  • Noun + ly = Adjective: home → homely, love → lovely, friend → friendly
  • ল্যাটিন / বিশেষ Adjective জোড়:
    • Sun → Solar (চন্দ্র → Lunar)
    • Egg → Oval (ডিম্বাকার)
    • Eye → Ocular (চক্ষু সংক্রান্ত)
    • Lip → Labial (ওষ্ঠ্য)
