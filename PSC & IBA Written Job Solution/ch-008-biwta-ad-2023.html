ধরি, পরপর তিনটি ক্রমিক সংখ্যা যথাক্রমে \((x - 1), x, (x + 1)\)।

⇒ \(x^3 - x - 120 = 0\)

⇒ \(x^3 - 5x^2 + 5x^2 - 25x + 24x - 120 = 0\)

⇒ \(x^2(x - 5) + 5x(x - 5) + 24(x - 5) = 0\)

৬১. একটি নির্দিষ্ট গতিতে ১৫ কিলোমিটার দূরত্ব অতিক্রম করতে A এর থেকে B ৩০ মিনিট বেশি সময় নেয়। কিন্তু যদি A তার গতি দ্বিগুণ করে, সে একই দূরত্ব অতিক্রম করতে B এর থেকে এক ঘণ্টা কম সময় নেয়। B এর গতি (কি. মি./ঘণ্টা) কত?

৬২. সমাধান করুন: \(\sqrt{x^2 - 6x + 15} - \sqrt{x^2 - 6x + 13} = \sqrt{10} - \sqrt{8}\)

স্বমূল্যায়ন:
প্রামাণ্য সমাধান ও বিশদ ব্যাখ্যা:

সমাধান:

দেওয়া আছে, \(\sqrt{x^2 - 6x + 15} - \sqrt{x^2 - 6x + 13} = \sqrt{10} - \sqrt{8}\)

পক্ষান্তর করে পাই,

⇒ \(\sqrt{x^2 - 6x + 15} + \sqrt{8} = \sqrt{x^2 - 6x + 13} + \sqrt{10}\)

উভয়পক্ষকে বর্গ করে পাই,

⇒ \((x^2 - 6x + 15) + 2\sqrt{8(x^2 - 6x + 15)} + 8 = (x^2 - 6x + 13) + 2\sqrt{10(x^2 - 6x + 13)} + 10\)

⇒ \(x^2 - 6x + 23 + 2\sqrt{8(x^2 - 6x + 15)} = x^2 - 6x + 23 + 2\sqrt{10(x^2 - 6x + 13)}\)

উভয়পক্ষ থেকে \((x^2 - 6x + 23)\) বাদ দিয়ে ও ২ দিয়ে ভাগ করে পাই,

⇒ \(\sqrt{8(x^2 - 6x + 15)} = \sqrt{10(x^2 - 6x + 13)}\)

পুনরায় উভয়পক্ষকে বর্গ করে পাই,

⇒ \(8(x^2 - 6x + 15) = 10(x^2 - 6x + 13)\)

⇒ \(4(x^2 - 6x + 15) = 5(x^2 - 6x + 13)\)

⇒ \(4x^2 - 24x + 60 = 5x^2 - 30x + 65\)

⇒ \(x^2 - 6x + 5 = 0\)

⇒ \(x^2 - 5x - x + 5 = 0\)

⇒ \(x(x - 5) - 1(x - 5) = 0\)

⇒ \((x - 5)(x - 1) = 0\)

হয় \(x - 5 = 0 \Rightarrow x = 5\)

অথবা \(x - 1 = 0 \Rightarrow x = 1\)

∴ নির্ণেয় সমাধান: \(x = 1, 5\)
