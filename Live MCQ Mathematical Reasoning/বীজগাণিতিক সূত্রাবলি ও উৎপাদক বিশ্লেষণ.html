১. বর্গ ও ঘনের কালজয়ী বীজগাণিতিক সূত্রাবলি (Standard Identities)

বর্গ সূত্র ও অনুসিদ্ধান্ত:
• \((a+b)^2 = a^2 + 2ab + b^2\),   \((a-b)^2 = a^2 - 2ab + b^2\)
• \(a^2 - b^2 = (a+b)(a-b)\)
• \(a^2 + b^2 = (a+b)^2 - 2ab = (a-b)^2 + 2ab = \frac{(a+b)^2 + (a-b)^2}{2}\)
• \(4ab = (a+b)^2 - (a-b)^2\),   \(ab = \Big(\frac{a+b}{2}\Big)^2 - \Big(\frac{a-b}{2}\Big)^2\)

ঘন সূত্রাবলি:
• \(a^3 + b^3 = (a+b)(a^2 - ab + b^2) = (a+b)^3 - 3ab(a+b)\)
• \(a^3 - b^3 = (a-b)(a^2 + ab + b^2) = (a-b)^3 + 3ab(a-b)\)
• \(a^3+b^3+c^3 - 3abc = (a+b+c)(a^2+b^2+c^2 - ab - bc - ca)\)
গুরুত্বপূর্ণ শর্ত: যদি \(a+b+c = 0\) হয়, তবে \(a^3+b^3+c^3 = 3abc\)।
