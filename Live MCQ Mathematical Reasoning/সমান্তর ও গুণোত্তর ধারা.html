১. সমান্তর ধারা (Arithmetic Progression, AP)

প্রথম পদ = \(a\), সাধারণ অন্তর = \(d\)
• \(n\)-তম পদ = \(a + (n-1)d\)
• \(n\) সংখ্যক পদের সমষ্টি: \(S_n = \frac{n}{2}[2a + (n-1)d] = \frac{n}{2}(\text{প্রথম পদ} + \text{শেষ পদ})\)
• পদসংখ্যা নির্ণয় শর্টকাট: \(n = \frac{\text{শেষ পদ} - \text{প্রথম পদ}}{\text{সাধারণ অন্তর}} + 1\)

বিশেষ সমষ্টির সূত্রসমূহ:
• \(1 + 2 + 3 + \dots + n = \frac{n(n+1)}{2}\)
• \(1^2 + 2^2 + 3^2 + \dots + n^2 = \frac{n(n+1)(2n+1)}{6}\)
• \(1^3 + 2^3 + 3^3 + \dots + n^3 = \Big[\frac{n(n+1)}{2}\Big]^2\)

২. গুণোত্তর ধারা (Geometric Progression, GP)

প্রথম পদ = \(a\), সাধারণ অনুপাত = \(r = \frac{\text{যেকোনো পদ}}{\text{তার পূর্ববর্তী পদ}}\)
• \(n\)-তম পদ = \(a r^{n-1}\)
• \(n\) পদের সমষ্টি: \(S_n = \frac{a(1 - r^n)}{1 - r}\) (যখন \(r < 1\)) বা \(S_n = \frac{a(r^n - 1)}{r - 1}\) (যখন \(r > 1\))
• অসীমতক সমষ্টি (Sum to Infinity):
যখন \(|r| < 1\) (অর্থাৎ \(-1 < r < 1\)), তখন ধারাটির অসীম পদের সমষ্টি বিদ্যমান থাকে:
\(S_\infty = \frac{a}{1 - r}\)
