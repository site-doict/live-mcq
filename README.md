# 📚 বাংলা সাহিত্য পূর্ণাঙ্গ প্রস্তুতি — স্মার্ট ইবুক ও রিভিশন পোর্টাল

বিসিএস (BCS) ও বিভিন্ন সরকারি-বেসরকারি প্রতিযোগিতামূলক পরীক্ষার জন্য বাংলা সাহিত্যের (পৃষ্ঠা ৭৩–২০২) পূর্ণাঙ্গ অধ্যায়ভিত্তিক স্টাডি নোট, বিগত বছরের প্রশ্নব্যাংক, বিশ্লেষণ এবং ইন্টারেক্টিভ কুইজ সমৃদ্ধ একটি আধুনিক স্মার্ট ইবুক ওয়েব পোর্টাল।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Smart E-Book Features)

1. **কেন্দ্রীয় সূচিপত্র ও পাঠ ট্র্যাকার (`index.html`)**:
   - ৫টি যুগ/অংশ এবং ৩১টি পরিচ্ছেদের পূর্ণাঙ্গ তালিকা।
   - অধ্যায়ভিত্তিক ড্রপডাউন অ্যাকর্ডিয়ন এবং লাইভ সার্চ ফিল্টার।
   - লোকালস্টোরেজ ভিত্তিক অগ্রগতি বার (Progress Tracker) — পড়া শেষ হলে টিক দিন, স্বয়ংক্রিয়ভাবে শতকরা হার আপডেট হবে।
   - প্রতি টপিকের পাশে সরাসরি **'পড়ুন →'** বাটন।

2. **স্মার্ট ফ্লোটিং ন্যাভিগেশন বার (`nav-component.js`)**:
   - প্রতিটি কনটেন্ট ফাইলের শীর্ষে স্টিকি গ্লাস মরফিজম বার।
   - **☰ সূচিপত্র**: ক্লিক করলেই বাম পাশ থেকে ভেসে উঠবে পূর্ণাঙ্গ সাইডবার ড্রয়ার।
   - **🏠 হোম**: এক ক্লিকেই মূল ইনডেক্স ড্যাশবোর্ডে ফিরে যাওয়ার সুবিধা।
   - **◀ আগের / পরের ▶ পাঠ**: অধ্যায় থেকে অধ্যায়ে সহজে যাওয়ার বোতাম।
   - **বর্তমান পাঠ হাইলাইট**: সূচিপত্রে আপনি যে পাঠে আছেন সেটি স্বয়ংক্রিয়ভাবে চিহ্নিত থাকবে।
   - **কিবোর্ড শর্টকাট**: `M` (সূচিপত্র ড্রয়ার), `Alt + Left` (পূর্ববর্তী পাঠ), `Alt + Right` (পরবর্তী পাঠ), `Esc` (ড্রয়ার বন্ধ)।

3. **পূর্ণাঙ্গ ইন্টারঅ্যাক্টিভ কুইজ ও সেলফ-অ্যাসেসমেন্ট**:
   - প্রতিটি অধ্যায়ের শেষে বিগত বিসিএসের প্রশ্ন ও ব্যাখ্যা।
   - লাইভ স্কোর ও সঠিক/ভুল উত্তর প্রদর্শন।

4. **ডার্ক ও লাইট থিম সাপোর্ট**:
   - রাত বা দিনে পড়ার সুবিধার্থে চোখ-বান্ধব থিম টগল।

## 🚀 গিটহাব ও গিটহাব পেইজে হোস্ট করার নিয়ম (GitHub Pages Setup)

এই প্রজেক্টটি সরাসরি গিটহাবে আপলোড করে সম্পূর্ণ ওয়েবসাইট হিসেবে পড়া যাবে:

### ধাপ ১: গিটহাব রিপোজিটরিতে কোড পুশ করুন
আপনার টার্মিনালে নিচের কমান্ডগুলো চালান:
```bash
git init
git add .
git commit -m "Initial commit - Smart Bangla Literature E-Book"
git branch -M main
git remote add origin https://github.com/আপনার-ইউজারনেম/আপনার-রিপো-নাম.git
git push -u origin main
```

### ধাপ ২: GitHub Pages চালু করুন
1. আপনার গিটহাব রিপোজিটরির **Settings** ট্যাবে যান।
2. বাম পাশের মেনু থেকে **Pages** অপশনে ক্লিক করুন।
3. **Build and deployment** সেকশনে:
   - **Source**: `Deploy from a branch` সিলেক্ট করুন।
   - **Branch**: `main` এবং ফোল্ডার `/ (root)` সিলেক্ট করে **Save** দিন।
4. ১-২ মিনিটের মধ্যে আপনার নিজস্ব লাইভ ইবুক সাইট প্রস্তুত হয়ে যাবে (যেমন: `https://your-username.github.io/your-repo/`)!

> **নোট**: রিপোজিটরিতে `.nojekyll` ফাইলটি ইতোমধ্যে যুক্ত করা হয়েছে, যাতে বাংলা ইউনিকোড ফাইলনেম নিয়ে গিটহাবে কোনো সমস্যা না হয়।
