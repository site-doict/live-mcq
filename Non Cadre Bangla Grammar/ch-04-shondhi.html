১ম অংশ: প্রামাণ্য ইন্টারেক্টিভ রিভিশন নোট ও সূত্রাবলি

🎯 ১. সন্ধির পরিচয় ও শ্রেণিবিভাগ

• সন্ধি শব্দের অর্থ: মিলন। পরস্পর সন্নিহিত দুটি ধ্বনির মিলন, রূপান্তর বা বিলোপকে সন্ধি বলে। এর উদ্দেশ্য উচ্চারণে স্বাচ্ছন্দ্য ও ধ্বনিমাধুর্য সৃষ্টি।

• প্রকারভেদ:
- খাঁটি বাংলা সন্ধি: ২ প্রকার (স্বরসন্ধি ও ব্যঞ্জনসন্ধি)।
- তৎসম (সংস্কৃত) সন্ধি: ৩ প্রকার (স্বরসন্ধি, ব্যঞ্জনসন্ধি ও বিসর্গ সন্ধি)।

✨ ২. স্বরসন্ধির প্রধান ও মোস্ট রিপিটেড সূত্রাবলি

  • অ/আ + অ/আ = আ : রত্ন + আকর = রত্নাকর, হিম + আলয় = হিমালয়, বিদ্যা + আলয় = বিদ্যালয়, শশ + অঙ্ক = শশাঙ্ক, নব + অন্ন = নবান্ন।
  • ই/ঈ + ই/ঈ = ঈ : রবি + ইন্দ্র = রবীন্দ্র, গিরি + ইন্দ্র = গিরীন্দ্র, পরি + ঈক্ষা = পরীক্ষা।
  • অ/আ + এ/ঐ = ঐ : জন + এক = জনৈক, মত + ঐক্য = মতৈক্য, সদা + এব = সদৈব, মহা + ঐশ্বর্য = মহৈশ্বর্য।
  • অ/আ + ঋত = আর : তৃষ্ণা + ঋত = তৃষ্ণার্ত, ক্ষুধা + ঋত = ক্ষুধার্ত, শীত + ঋত = শীতার্ত।
  • উ/ঊ + ভিন্ন স্বর = ব-ফলা : সু + আগত = স্বাগত, অনু + এষণ = অন্বেষণ, তনু + ঈ = তন্বী, সু + অল্প = স্বল্প।
  • ই/ঈ + ভিন্ন স্বর = য-ফলা : পরি + আলোচনা = পর্যালোচনা, পরি + অন্ত = পর্যন্ত, অতি + অন্ত = অত্যন্ত।
  • ও + ভিন্ন স্বর = অব্ : পো + ইত্র = পবিত্র, পো + অন = পবন, গো + আদি = গবাদি।

⚡ ৩. ব্যঞ্জনসন্ধি ও বিসর্গ সন্ধির অলঙ্ঘনীয় সূত্র

• ব্যঞ্জনসন্ধির মুখ্য সূত্র:
- বর্গের ১ম + স্বর/ঘোষ = বর্গের ৩য়: উৎ + যোগ = উদ্যোগ, ষট্ + ঋতু = ষড়ঋতু, বাক্ + দান = বাগদান।
- সম্ + স্পর্শ ব্যঞ্জন = নাসিক্য: সম্ + চয় = সঞ্চয়, সম্ + তাপ = সন্তাপ।
- সম্ + অন্তঃস্থ/উষ্মবর্ণ = অনুস্বার: সম্ + বিধান = সংবিধান, সম্ + যোজন = সংযোজন, অলম্ + কার = অলঙ্কার।

💡 বিসর্গ সন্ধি ট্রিকস:
• বিসর্গ + চ/ছ = শ: নিঃ + চয় = নিশ্চয়, শিরঃ + ছেদ = শিরশ্ছেদ।
• বিসর্গ + ট/ঠ = ষ: ধনুঃ + টংকার = ধনুষ্টংকার, নিঃ + ঠুর = নিষ্ঠুর।
• বিসর্গ + ত/থ = স: দুঃ + তর = দুস্তর, দুঃ + থ = দুস্থ।
• অ-কারান্ত বিসর্গ + ঘোষ ব্যঞ্জন = ও-কার: মনঃ + যোগ = মনোযোগ, মনঃ + রম = মনোরম, মনঃ + হর = মনোহর।
• হ্রস্ব ই/উ + বিসর্গ + র = দীর্ঘ স্বর + বিসর্গ লোপ: নিঃ + রোগ = নীরোগ, নিঃ + রব = নীরব, নিঃ + রস = নীরস।
• বিশেষ বিসর্গ সন্ধি: অহঃ + অহ = অহরহ, বাচঃ + পতি = বাচস্পতি, ভাস্ + কর = ভাস্কর, পুরঃ + কার = পুরস্কার, নমঃ + কার = নমস্কার।

💎 ৪. নিপাতনে সিদ্ধ সন্ধির বিশেষ তালিকা

কোনো ব্যাকরণিক নিয়ম না মেনে যে সন্ধিগুলো সিদ্ধ হয়:

  • নিপাতনে সিদ্ধ স্বরসন্ধি: গো + অক্ষ = গবাক্ষ, কুল + অটা = কুলটা, প্র + ঊঢ় = প্রৌঢ়, শুদ্ধ + ওদন = শুদ্ধোদন, মার্ত + অণ্ড = মার্তণ্ড।
  • নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি: আ + চর্য = আশ্চর্য, গো + পদ = গোষ্পদ, বৃহৎ + পতি = বৃহস্পতি, মনস্ + ঈষা = মনীষা, পতৎ + অঞ্জলি = পতঞ্জলি, বন + পতি = বনস্পতি, পর + পর = পরস্পর, তৎ + কর = তস্কর।
  • খাঁটি বাংলা সন্ধি: নাত + জামাই = নাজ্জামাই, যা + ইচ্ছে + তাই = যাচ্ছেতাই, মাথা + এ = মাথায়।

২য় অংশ: বিগত বছরের প্রামাণ্য প্রশ্নব্যাংক ও কুইজ

স্কোর: ০ / ৫৩
সন্ধির পরিচয় ও প্রকারভেদ বাংলাদেশ কোস্ট গার্ড ও কৃষি প্রশিক্ষণ একাডেমির নার্স-১৯/ উপজেলা পোস্ট মাস্টার-১০/পিএসসি (জেলা ক্রীড়া কর্মকর্তা)-২৩
০১. পাশাপাশি দুটি বর্ণ বা ধ্বনির মিলনকে কী বলা হয়?/পরস্পর সন্নিহিত ধ্বনির মিলন, পরিবর্তন ও লোপকে বলে-

পরস্পর সন্নিহিত দুটি ধ্বনির মিলন, পরিবর্তন বা লোপকে সন্ধি বলে। সন্ধির মূল উদ্দেশ্য স্বাভাবিক উচ্চারণে সহজসাধ্যতা ও ধ্বনিমাধুর্য সম্পাদন।

সন্ধির পরিচয় ও প্রকারভেদ বিভিন্ন মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-২০১৫
০২. কোনটিকে সন্ধির সংজ্ঞা বলা হয়?

পরস্পর সন্নিহিত দুটি ধ্বনি পরিবর্তিত হয়ে এক ধ্বনিতে রূপান্তর বা ধ্বনির মিলনকে সন্ধি বলে। যেমন: সূর্য + উদয় = সূর্যোদয়, বিদ্যা + আলয় = বিদ্যালয়।

সন্ধির পরিচয় ও প্রকারভেদ গণপূর্ত অধিদপ্তরের উপসহকারী প্রকৌশলী (সিভিল)-১৭
০৩. ব্যাকরণ অনুযায়ী খাঁটি বাংলা সন্ধি কয় প্রকার?

ব্যাকরণ অনুযায়ী খাঁটি বাংলা সন্ধি দুই প্রকার: স্বরসন্ধি ও ব্যঞ্জনসন্ধি। তবে বাংলা ভাষায় ব্যবহৃত তৎসম সন্ধি তিন প্রকার: স্বরসন্ধি, ব্যঞ্জনসন্ধি ও বিসর্গ সন্ধি।

সন্ধির পরিচয় ও প্রকারভেদ পিএসসি (সিনিয়র স্টাফ নার্স)-২০
০৪. যেসব নিয়মে সন্ধি নিয়মানুসারে হয় তাকে বলে-

যেসব সন্ধি ব্যাকরণের সাধারণ কোনো নিয়ম অনুসারে হয় না, সেগুলোকে নিপাতনে সিদ্ধ সন্ধি বলে। প্রশ্নটি ভুলভাবে মুদ্রিত হওয়ায় সঠিক বিকল্প প্রযোজ্য হয়নি।

স্বরসন্ধি পিএসসি (বিভিন্ন পদ)-১৯
০৫. সঠিক সন্ধি বিচ্ছেদ কোনটি?

উ-কার কিংবা ঊ-কারের পর উ বা ঊ ভিন্ন অন্য স্বর থাকলে উ বা ঊ স্থানে ব-ফলা হয় এবং তা পূর্ববর্তী ব্যঞ্জনের সাথে যুক্ত হয়। যেমন: অনু + এষণ = অন্বেষণ; সু + আগত = স্বাগত; পরিচ্ছদ = পরি + ছদ।

বিসর্গ সন্ধি পিএসসি (ইন্সট্রাক্টর/ ওয়ার্কশপ সুপার)-২৩
০৬. বিসর্গ (ঃ) সন্ধিঘটিত শুদ্ধ শব্দ কোনটি?

বিসর্গের পর অঘোষ অল্পপ্রাণ কিংবা মহাপ্রাণ দন্ত্য ব্যঞ্জন (ত, থ) থাকলে বিসর্গ স্থানে দন্ত্য শিষ ধ্বনি (স) হয়। যেমন: দুঃ + তর = দুস্তর; দুঃ + বার = দুর্বার; দুঃ + অন্ত = দুরন্ত।

নিপাতনে সিদ্ধ সন্ধি বিভিন্ন মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-২০১৫
০৭. কোনটি সন্ধির নিপাতনে সিদ্ধ হয়েছে?

নিপাতনে সিদ্ধ স্বরসন্ধি: গো + অক্ষ = গবাক্ষ, কুল + অটা = কুলটা, প্র + ঊঢ় = প্রৌঢ়। ব্যঞ্জনসন্ধি: আ + চর্য = আশ্চর্য, গো + পদ = গোষ্পদ। বিসর্গ সন্ধি: প্রাতঃ + কাল = প্রাতঃকাল, মনঃ + কষ্ট = মনঃকষ্ট।

ব্যঞ্জনসন্ধি নির্বাচন কমিশন সচিবালয় (উপজেলা/থানা নির্বাচন অফিসার)-০৮
০৮. ‘অলঙ্কার’ শব্দের সঠিক সন্ধিজাত বিশ্লেষণ কোনটি?

ম-এর পর ক-বর্গীয় বর্ণ থাকলে ‘ম’ স্থানে ঙ বা অনুস্বার (ং) হয়। অলম্ + কার = অলঙ্কার বা অলংকার।

বিসর্গ সন্ধি পিএসসি (ইকোনমিস্ট)-২৪/ পিএসসি এর নন ক্যাডার (সংসদ সচিবালয় এর ব্যক্তিগত কর্মকর্তা)-২৩/ সংস্কৃতি মন্ত্রণালয়ের উপ-সহকারী প্রকৌশলী (সিভিল)-১৯
০৯. ‘অহরহ’ শব্দটির সন্ধি বিচ্ছেদ কোনটি?

অহঃ + অহ = অহরহ (বিশেষ বিসর্গ সন্ধির উদাহরণ)। অনুরূপ: ভাস্ + কর = ভাস্কর, বাচ্ + পতি = বাচস্পতি।

ব্যঞ্জনসন্ধি পিএসসি (বিভিন্ন মন্ত্রণালয়ের প্রশাসনিক কর্মকর্তা)-১৯
১০. ‘উদ্যোগ’ শব্দের সন্ধিবিচ্ছেদ কোনটি?

উৎ + যোগ = উদ্যোগ। ক্, চ্, ট্, ত্, প্ এর পর স্বরধ্বনি বা ঘোষ বর্ণ থাকলে তারা যথাক্রমে গ্, জ্, ড্/ড়্, দ্, ব্ হয়। যেমন: ত্ + য = দ্ + য (উৎ + যোগ = উদ্যোগ, উৎ + ঘাটন = উদ্ঘাটন, তদ্ + রূপ = তদ্রূপ)।

নিপাতনে সিদ্ধ সন্ধি ফায়ার সার্ভিস ও সিভিল ডিফেন্স অধিদপ্তর (স্টেশন অফিসার)-২২
১১. ‘গো + অক্ষ = গবাক্ষ’ এটি কোন ধরনের সন্ধি বিচ্ছেদ—

গবাক্ষ, মার্তণ্ড, শুদ্ধোদন, অন্যান্য, প্রৌঢ়, কুলটা ইত্যাদি নিপাতনে সিদ্ধ সন্ধি।

স্বরসন্ধি পররাষ্ট্র মন্ত্রণালয় (সুপারিনটেনডেন্ট)-১৯
১২. ‘গীতাঞ্জলি’ এর সন্ধিবিচ্ছেদ কোনটি?

গীতা + অঞ্জলি = গীতাঞ্জলি (আ + অ = আ)। অথবা গীত + অঞ্জলি (অ + অ = আ)। প্রশ্নে ‘গীতা + অঞ্জলি’ উত্তর হিসেবে গৃহীত।

স্বরসন্ধি উপজেলা মহিলা বিষয়ক কর্মকর্তা ২০১৬
১৩. জনৈক শব্দের সন্ধি বিচ্ছেদ—

অ-কার কিংবা আ-কারের পর এ-কার কিংবা ঐ-কার থাকলে উভয় মিলে ঐ-কার হয়। অর্থাৎ অ + এ = ঐ (জন + এক = জনৈক)।

স্বরসন্ধি পররাষ্ট্র মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-১৯/ কারা অধিদপ্তর (কারা তত্ত্বাবধায়ক)-১০
১৪. “তৃষ্ণার্ত” সন্ধি বিচ্ছেদ কোনটি?

অ-কার কিংবা আ-কারের পর ‘ঋত’ শব্দ থাকলে (অ, আ + ঋ) উভয় মিলে ‘আর’ হয় এবং বানানে পূর্ববর্তী বর্ণে ‘আ’ ও পরবর্তী বর্ণে রেফ লেখা হয়। যেমন: তৃষ্ণা + ঋত = তৃষ্ণার্ত; শীত + ঋত = শীতার্ত; ক্ষুধা + ঋত = ক্ষুধার্ত।

স্বরসন্ধি বিসিআইসির সহকারী ব্যবস্থাপক (প্রশাসন) ২০১১
১৫. ‘তন্বী’ শব্দটির সন্ধি-বিচ্ছেদ কোনটি?

উ-কার কিংবা ঊ-কারের পর উ বা ঊ ভিন্ন অন্য স্বর থাকলে উ বা ঊ স্থানে ব-ফলা হয়। তনু + ঈ = তন্বী; সু + অল্প = স্বল্প; অনু + এষণ = অন্বেষণ।

বিসর্গ সন্ধি শিক্ষা প্রকৌশল অধিদপ্তর (সহকারী প্রকৌশলী)-২২
১৬. কোনটি ‘দুস্থ’ শব্দের সঠিক সন্ধি বিচ্ছেদ?

বিসর্গের পর অঘোষ অল্পপ্রাণ কিংবা মহাপ্রাণ দন্ত্য ব্যঞ্জন (ত, থ) থাকলে বিসর্গ স্থানে দন্ত্য শিষ ধ্বনি (স) হয়। যেমন: দুঃ + থ = দুস্থ; দুঃ + তর = দুস্তর।

বিসর্গ সন্ধি আনসার ও ভিডিপি অধিদপ্তর (সার্কেল অ্যাডজুট্যান্ট/উপজেলা আনসার ও ভিডিপি কর্মকর্তা/সহকারী অ্যাডজুট্যান্ট)-২০১৫
১৭. ‘দুষ্কৃতি’ শব্দের সঠিক সন্ধিবিচ্ছেদ কোনটি?

দুঃ + কৃতি = দুষ্কৃতি। অ বা আ ভিন্ন অন্য স্বরবর্ণের পরস্থিত বিসর্গের পর ক, খ, প, ফ থাকলে বিসর্গ স্থলে অঘোষ মূর্ধন্য শিষ ধ্বনি (ষ) হয়। যেমন: নিঃ + কর = নিষ্কর, দুঃ + কর = দুষ্কর, নিঃ + ফল = নিষ্ফল।

বিসর্গ সন্ধি মাধ্যমিক ও উচ্চ শিক্ষা অধিদপ্তরের প্রদর্শক ২০১৩
১৮. ‘দুর্নীতি’ শব্দটির সন্ধিবিচ্ছেদ হবে-

‘অ’ ও ‘আ’ ভিন্ন অন্য স্বরের পরে বিসর্গ থাকলে এবং তার সঙ্গে ঘোষ অল্পপ্রাণ ও ঘোষ মহাপ্রাণ নাসিক্য ধ্বনির সন্ধি হলে বিসর্গ স্থানে ‘র’ হয়। দুঃ + নীতি = দুর্নীতি।

বিসর্গ সন্ধি আইন, বিচার ও সংসদ বিষয়ক মন্ত্রণালয়ের সাব-রেজিস্ট্রার ২০১২
১৯. ‘ধনুষ্টংকার’ -এর সঠিক সন্ধিবিচ্ছেদ কোনটি?

বিসর্গের পর ট বা ঠ থাকলে বিসর্গ স্থলে মূর্ধন্য শিষধ্বনি ‘ষ’ হয়। ধনুঃ + টংকার = ধনুষ্টংকার; নিঃ + ঠুর = নিষ্ঠুর।

বিসর্গ সন্ধি পাসপোর্ট ও ইমিগ্রেশন অধিদপ্তর (সহকারী পরিচালক)-০৭
২০. কোনটি শুদ্ধ সন্ধি বিচ্ছেদ?

ধনুঃ + বিদ্যা = ধনুর্বিদ্যা। বিসর্গের পর ঘোষ ব্যঞ্জন থাকলে বিসর্গ র-এ পরিণত হয়।

বিসর্গ সন্ধি পিএসসি (সহকারী কাস্টোডিয়ান)-২৩
২১. ‘নীরোগ’ শব্দের সন্ধি বিচ্ছেদ কোনটি?

ই কিংবা উ ধ্বনির পরের বিসর্গের সঙ্গে ‘র’ এর সন্ধি হলে বিসর্গের লোপ হয় ও বিসর্গের পূর্ববর্তী হ্রস্ব স্বর দীর্ঘ হয়। নিঃ + রোগ = নীরোগ; নিঃ + রব = নীরব; নিঃ + রস = নীরস।

বিসর্গ সন্ধি তথ্য মন্ত্রণালয়ের অধীন চলচ্চিত্র ও প্রকাশনা অধিদপ্তরের ক্যামেরাম্যান-১৯
২২. ‘নীরব’ শব্দের সন্ধি বিচ্ছেদ কোনটি?

নিঃ + রব = নীরব। ই-ধ্বনির পরের বিসর্গের সাথে ‘র’ এর মিলনে বিসর্গ লোপ পেয়ে পূর্বের হ্রস্ব ‘ই’ দীর্ঘ ‘ঈ’ হয়।

স্বরসন্ধি জনস্বাস্থ্য প্রকৌশল অধিদপ্তর (এস্টিমেটর)-১৮/ গণপূর্ত অধিদপ্তরের উপসহকারী প্রকৌশলী (সিভিল)-১৭
২৩. সন্ধি বিচ্ছেদ করুন: নবান্ন

নব + অন্ন = নবান্ন (অ + অ = আ)। স্বরধ্বনির সাথে স্বরধ্বনির মিলনকে স্বরসন্ধি বলে।

খাঁটি বাংলা সন্ধি জনপ্রশাসন মন্ত্রণালয়ের অধীনে পিএসসির সহকারী পরিচালক ২০১৬
২৪. “নাজ্জামাই” শব্দের যথার্থ সন্ধি বিচ্ছেদ কোনটি?

নাত + জামাই = নাজ্জামাই (খাঁটি বাংলা ব্যঞ্জনসন্ধি: ত্ + জ = জ্জ)।

ব্যঞ্জনসন্ধি পিএসসি (জুনিয়র ইন্সট্রাক্টর)-২৩
২৫. ‘প্রচ্ছদ’ শব্দের প্রকৃত সন্ধি বিচ্ছেদ হলো :

স্বরধ্বনির পর ‘ছ’ থাকলে উক্ত ব্যঞ্জনধ্বনিটি দ্বিত্ব (চ্ছ) হয়। যথা- প্র + ছদ = প্রচ্ছদ; পরি + ছদ = পরিচ্ছদ।

স্বরসন্ধি পিএসসি (সহকারী পরিবার পরিকল্পনা কর্মকর্তা)-২২
২৬. ‘পর্যালোচনা’ শব্দটির সঠিক সন্ধি বিচ্ছেদ ----

পরি + আলোচনা = পর্যালোচনা (ই + আ = য-ফলা + আ)।

স্বরসন্ধি খাদ্য অধিদপ্তর, সহকারী প্রকৌশলী (সিভিল)-২২/ ডাক অধিদপ্তর (বিল্ডিং ওভারশিয়ার)-১৮
২৭. ‘পর্যন্ত’ এর সন্ধিবিচ্ছেদ কোনটি?

পরি + অন্ত = পর্যন্ত (ই + অ = য-ফলা)। অতি + অন্ত = অত্যন্ত।

বিসর্গ সন্ধি বিভিন্ন মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-২২
২৮. ‘প্রাতরাশ’ শব্দের সন্ধি

বিসর্গ সন্ধির ক্ষেত্রে প্রাতঃ, পুনঃ ইত্যাদির পর স্বরধ্বনি থাকলে সন্ধির ফলে বিসর্গ ‘র’ হয়ে পরবর্তী স্বরধ্বনির সাথে যুক্ত হয়। প্রাতঃ + আশ = প্রাতরাশ; পুনঃ + অধিকার = পুনরাধিকার।

বিসর্গ সন্ধি কারিগরি শিক্ষা অধিদপ্তর (ক্রাফট ইন্সট্রাক্টর)-২১
২৯. সন্ধি বিচ্ছেদ করুন: ‘পুরস্কার’

পুরঃ + কার = পুরস্কার। অ-কারযুক্ত বিসর্গের পর ক, খ, প, ফ থাকলে বিসর্গ স্থানে দন্ত্য ‘স’ হয়। যেমন: পুরঃ + কার = পুরস্কার; নমঃ + কার = নমস্কার; পদঃ + খলন = পদস্খলন।

স্বরসন্ধি বিভিন্ন মন্ত্রণালয়/বিভাগ/অধিদপ্তরের ব্যক্তিগত কর্মকর্তা-১৮
৩০. ‘পুষ্পারতি’ শব্দের সন্ধি বিচ্ছেদ—

পুষ্প + আরতি = পুষ্পারতি (অ + আ = আ)।

স্বরসন্ধি পিএসসি (বিভিন্ন পদ)-১৭
৩১. “পবিত্র” শব্দের সন্ধি বিচ্ছেদ কোনটি?

পো + ইত্র = পবিত্র। ও-কারের পর ভিন্ন স্বর থাকলে ও-কার স্থানে ‘অব্’ হয়। যেমন: পো + অন = পবন; পো + ইত্র = পবিত্র; গো + আদি = গবাদি।

স্বরসন্ধি বহিরাগমন ও পাসপোর্ট অধিদপ্তরের সহকারী পরিচালক ২০১৪
৩২. ‘পরীক্ষা’ শব্দটির সন্ধি বিচ্ছেদ কোনটি?

পরি + ঈক্ষা = পরীক্ষা (ই + ঈ = ঈ)। অনুরূপ: প্রতি + ঈক্ষা = প্রতীক্ষা।

বিসর্গ সন্ধি ফায়ার সার্ভিস ও সিভিল ডিফেন্স অধিদপ্তর (স্টেশন অফিসার)-২২
৩৩. ‘বাচস্পতি’ শব্দটির সন্ধি বিচ্ছেদ কোনটি—

বাচঃ + পতি = বাচস্পতি (একটি বিশেষ বিসর্গ সন্ধি)। অনুরূপ: ভাস্ + কর = ভাস্কর, অহঃ + নিশা = অহর্নিশ, অহঃ + অহ = অহরহ।

স্বরসন্ধি খাদ্য অধিদপ্তর (খাদ্য মন্ত্রণালয়), আঞ্চলিক রক্ষণাবেক্ষণ কর্মকর্তা /আরএমও-উপসহকারী প্রকৌশলী-২২
৩৪. ‘বিদ্যালয়’ শব্দটির সন্ধি বিচ্ছেদ কী?

বিদ্যা + আলয় = বিদ্যালয় (আ + আ = আ)।

ব্যঞ্জনসন্ধি পিএসসি (বিভিন্ন পদ)-১৭
৩৫. “বর্জন” এর সন্ধি বিচ্ছেদ কোনটি?

বৃজ্ + অন = বর্জন (সংস্কৃত কৃৎপ্রত্যয়জাত সন্ধিজাত শব্দ)।

স্বরসন্ধি পিএসসি (পুলিশ হাসপাতাল নিয়োগ)-২৪
৩৬. ‘মতৈক্য’ শব্দটির সঠিক সন্ধি বিচ্ছেদ কোনটি?

মত + ঐক্য = মতৈক্য (অ + ঐ = ঐ)। জন + এক = জনৈক; সদা + এব = সদৈব; মহা + ঐশ্বর্য = মহৈশ্বর্য।

নিপাতনে সিদ্ধ সন্ধি বাংলাদেশ তেল, গ্যাস ও খনিজসম্পদ কর্পোরেশন (মেকানিক্যাল উপ সহকারী প্রকৌশলী)-২৪/পররাষ্ট্র মন্ত্রণালয়ের সাইফার অফিসার ২০১২
৩৭. ‘মনীষা’ শব্দের সন্ধি বিচ্ছেদ করলে পাওয়া যায়-

মনস্ + ঈষা = মনীষা (নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি)। অনুরূপ: বৃহৎ + পতি = বৃহস্পতি; পতৎ + অঞ্জলি = পতঞ্জলি।

ব্যঞ্জনসন্ধি পিএসসি (জুনিয়র ইন্সট্রাক্টর)-২৩
৩৮. ‘মুক্ত’ শব্দের সন্ধি বিচ্ছেদ হলো:

মুচ্ + ত = মুক্ত (চ-এর পর ত থাকলে চ স্থানে ক্ হয়)।

বিসর্গ সন্ধি সড়ক পরিবহন ও সেতু মন্ত্রণালয়ের উপ-সহকারী প্রকৌশলী (যান্ত্রিক)-১৯
৩৯. ‘মনোযোগ’ শব্দটির শুদ্ধ সন্ধি-বিচ্ছেদ কোনটি?

মনঃ + যোগ = মনোযোগ। অ-কারের পরস্থিত বিসর্গের পর ঘোষ ব্যঞ্জন থাকলে বিসর্গ ও-কারে পরিণত হয়। যেমন: মনঃ + রম = মনোরম; মনঃ + হর = মনোহর; বয়ঃ + বৃদ্ধি = বয়োবৃদ্ধি।

বিসর্গ সন্ধি গণপূর্ত অধিদপ্তর (উপ-সহকারী প্রকৌশলী ও ড্রাফটসম্যান)-১৮
৪০. ‘মনোযোগ’ শব্দটি কোন সন্ধিতে গঠিত?

মনঃ + যোগ = মনোযোগ শব্দটি বিসর্গ সন্ধি দ্বারা গঠিত।

স্বরসন্ধি পিএসসি (বিভিন্ন পদ)-১৭
৪১. “মাথায়” শব্দটির সঠিক সন্ধি বিচ্ছেদ কোনটি?

মাথা + এ = মাথায় (খাঁটি বাংলা স্বরসন্ধি: আ + এ = আয়)।

খাঁটি বাংলা সন্ধি স্বরাষ্ট্র মন্ত্রণালয় (কারা তত্ত্বাবধায়ক)-২০১০
৪২. ‘যাচ্ছেতাই’ এর সঠিক সন্ধিবিচ্ছেদ কোনটি?

যা + ইচ্ছে + তাই = যাচ্ছেতাই (খাঁটি বাংলা সন্ধির বিশেষ উদাহরণ)।

স্বরসন্ধি প্রতিরক্ষা মন্ত্রণালয়; সহকারী পরিচালক (নন-টেকনিক্যাল)-২৩/ প্রধানমন্ত্রীর কার্যালয় (সহকারী পরিচালক)-২০১৩
৪৩. রত্নাকর শব্দটির সন্ধিবিচ্ছেদ—

রত্ন + আকর = রত্নাকর (অ + আ = আ)। অনুরূপ: হিম + আলয় = হিমালয়, বিদ্যা + আলয় = বিদ্যালয়।

স্বরসন্ধি দুর্নীতি দমন কমিশন (কোর্ট পরিদর্শক)-২২/পিএসসি (সহকারী পরিবার পরিকল্পনা কর্মকর্তা)-২২/ বিভিন্ন মন্ত্রণালয়/বিভাগ/অধিদপ্তরের প্রশাসনিক কর্মকর্তা-১৮/গণপূর্ত অধিদপ্তর (উপ-সহকারী প্রকৌশলী ও ড্রাফটসম্যান)-১৮
৪৪. ‘রবীন্দ্র’ এর সঠিক সন্ধি বিচ্ছেদ কোনটি?

রবি + ইন্দ্র = রবীন্দ্র (ই + ই = ঈ)। তৎসম স্বরসন্ধির নিয়মানুসারে ই-কার কিংবা ঈ-কারের পর ই-কার বা ঈ-কার থাকলে উভয়ে মিলে দীর্ঘ ঈ-কার হয়।

স্বরসন্ধি সংস্কৃতি মন্ত্রণালয়ের প্রত্নতত্ত্ব অধিদপ্তর (এস্টিমেটর)-১৯/ জনপ্রশাসন মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-১৬
৪৫. ‘শশাঙ্ক’ শব্দের সন্ধিবিচ্ছেদ কোনটি?

শশ + অঙ্ক = শশাঙ্ক (অ + অ = আ)। নর + অধম = নরাধম; বিদ্যা + আলয় = বিদ্যালয়।

বিসর্গ সন্ধি ৪৬তম বিসিএস
৪৬. ‘শিরশ্ছেদ’ শব্দের সন্ধিবিচ্ছেদ-

শিরঃ + ছেদ = শিরশ্ছেদ। বিসর্গের পর চ বা ছ থাকলে বিসর্গ স্থানে তালব্য ‘শ’ হয়।

ব্যঞ্জনসন্ধি পাসপোর্ট অ্যান্ড ইমিগ্রেশন অধিদপ্তর (সহকারী পরিচালক)-০৩
৪৭. ষড় ঋতু শব্দের সন্ধি বিচ্ছেদ—

ষট্ + ঋতু = ষড়ঋতু (ট্ এর পর স্বরধ্বনি থাকায় ট্ স্থানে ড়্ হয়েছে)।

স্বরসন্ধি পিএসসি (পররাষ্ট্র মন্ত্রণালয়); ব্যক্তিগত কর্মকর্তা-২৪/ পিএসসি (জুনিয়র ইন্সট্রাক্টর)-২৩/কর্মসংস্থান ও প্রশিক্ষণ ব্যুরো (ইন্সট্রাক্টর)-২২/স্থানীয় সরকার, পল্লী উন্নয়ন ও সমবায় মন্ত্রণালয়ের সহকারী প্রকৌশলী (সিভিল)-১৭
৪৮. ‘স্বাগত’ শব্দের সন্ধি বিচ্ছেদ কোনটি?

সু + আগত = স্বাগত (উ + আ = ব-ফলা + আ)। তনু + ঈ = তন্বী; অনু + এষণ = অন্বেষণ।

ব্যঞ্জনসন্ধি প্রতিরক্ষা মন্ত্রণালয় (সহকারী পরিচালক)-১৯
৪৯. ‘সঞ্চয়’ শব্দের সন্ধিবিচ্ছেদ কোনটি?

সম্ + চয় = সঞ্চয়। ম্ এর পর যে কোনো বর্গীয় ধ্বনি থাকলে ম্ ধ্বনিটি সেই বর্গের নাসিক্য ধ্বনি হয়। যেমন: শম্ + তা = শান্তা; সম্ + তাপ = সন্তাপ।

ব্যঞ্জনসন্ধি পিএসসি (সহকারী তথ্য অফিসার)-২২
৫০. ‘সংযোজন’ শব্দের সঠিক সন্ধি বিচ্ছেদ হলো-

সম্ + যোজন = সংযোজন। ‘ম’ এর পর অন্তঃস্থ ধ্বনি (য, র, ল, ব) বা উষ্ম বর্ণ (শ, ষ, স, হ) থাকলে ‘ম’ স্থানে অনুস্বার (ং) হয়।

স্বরসন্ধি পররাষ্ট্র মন্ত্রণালয় (সহকারী সাইফার কর্মকর্তা)-২২
৫১. ‘স্বেচ্ছা’ এর সন্ধিবিচ্ছেদ কী?

স্ব + ইচ্ছা = স্বেচ্ছা (অ + ই = এ)। শুভ + ইচ্ছা = শুভেচ্ছা।

ব্যঞ্জনসন্ধি সড়ক ও জনপথ অধিদপ্তরের উপসহকারী প্রকৌশলী-১০
৫২. ‘সংবিধান’ শব্দের সঠিক সন্ধি-বিচ্ছেদ—

সম্ + বিধান = সংবিধান। ম-এর পর অন্তঃস্থ বর্ণ ‘ব’ থাকায় ‘ম’ অনুস্বারে (ং) পরিণত হয়েছে।

স্বরসন্ধি পিএসসি - পররাষ্ট্র মন্ত্রণালয় (সুপারিনটেনডেন্ট)-২৪/বিভিন্ন মন্ত্রণালয়ের সহকারী প্রোগ্রামার, উপসহকারী প্রকৌশলী, প্রশাসনিক কর্মকর্তা ও ব্যক্তিগত কর্মকর্তা ২০১৬
৫৩. ‘ক্ষুধার্ত’ শব্দের সন্ধি বিচ্ছেদ কোনটি?

ক্ষুধা + ঋত = ক্ষুধার্ত (আ + ঋ = আর)। অনুরূপ: তৃষ্ণা + ঋত = তৃষ্ণার্ত, শীত + ঋত = শীতার্ত।

পিএসসি নন-ক্যাডার প্রশ্নব্যাংক (১ম খণ্ড) — বাংলা ব্যাকরণ
