অধ্যায় ০২ পৃষ্ঠা: ৪৯৫–৪৯৭ মোট প্রশ্ন: 17টি

দূরত্ব ও উচ্চতা (Height & Distance)

📌 প্রামাণ্য রিভিশন নোট ও সূত্রাবলি

🏔️ উন্নতি কোণ ও অবনতি কোণ

  • উন্নতি কোণ (Angle of Elevation): অনুভূমিক রেখার উপরের কোনো বিন্দু ভূমির সাথে যে কোণ উৎপন্ন করে।
  • অবনতি কোণ (Angle of Depression): অনুভূমিক রেখার নিচের কোনো বিন্দু দৃষ্টিরেখার সাথে যে কোণ উৎপন্ন করে।
  • সমান্তরাল রেখার ধর্ম: একান্তর কোণ সমান হওয়ায় উন্নতি কোণ = অবনতি কোণ।

🌳 গাছ বা খুঁটি ভাঙার গাণিতিক টেকনিক

  • সম্পূর্ণ উচ্চতা = h, ভাঙা অংশের দৈর্ঘ্য = x, দণ্ডায়মান অংশ = (h - x)।
  • ভাঙা অংশ ভূমির সাথে θ কোণ করলে: sin θ = (h - x) / x।
  • শর্টকাট ৩০° কোণের ক্ষেত্রে: ভাঙা অংশ = 2 × দণ্ডায়মান অংশ। অর্থাৎ ভূমি থেকে h/3 উচ্চতায় ভাঙবে।

⚡ ছায়ার দৈর্ঘ্য ও কোণের সম্পর্ক

• কোণ ৩০° হলে: ছায়ার দৈর্ঘ্য = √3 × উচ্চতা (লম্ব অপেক্ষা বড়)।

• কোণ ৪৫° হলে: ছায়ার দৈর্ঘ্য = উচ্চতা (উভয়ই সমান)।

• কোণ ৬০° হলে: ছায়ার দৈর্ঘ্য = উচ্চতা / √3 (লম্ব অপেক্ষা ছোট)।

📝 বিগত বছরের প্রশ্নব্যাংক

স্কোর: ০ / 17
প্রশ্ন রেলওয়ে মন্ত্রণালয়ের সহকারী সরঞ্জাম নিয়ন্ত্রক-১৬
সঠিক উত্তর: ক
$$\tan\theta = \frac{4}{3}$$ এবং কোণ $\theta$ তৃতীয় চতুর্ভাগে ($\pi < \theta < \frac{3\pi}{2}$) অবস্থিত।
তৃতীয় চতুর্ভাগে $\tan$ ধনাত্মক হলেও $\sin$ ঋণাত্মক হয়।
লম্ব = ৪, ভূমি = ৩ হলে $$\text{অতিভুজ} = \sqrt{4^2 + 3^2} = 5$$
অতএব, $$\sin\theta = -\frac{\text{লম্ব}}{\text{অতিভুজ}} = \mathbf{-\frac{৪}{৫}}$$।
প্রশ্ন বাংলাদেশ রেলওয়ে (সহকারী স্টেশন মাস্টার)-১৬
সঠিক উত্তর: ক
$$\text{cosec}(90° - \theta) = \sec\theta = 2 \implies \frac{1}{\cos\theta} = 2 \implies \cos\theta = \mathbf{\frac{১}{২}}$$।
প্রশ্ন সমাজসেবা অধিদপ্তর (সমাজসেবা অফিসার)-২০১০
সঠিক উত্তর: খ
যোজন-বিয়োজন করে পাই:
$$\frac{(\sin\theta + \cos\theta) + (\sin\theta - \cos\theta)}{(\sin\theta + \cos\theta) - (\sin\theta - \cos\theta)} = \frac{7 + 1}{7 - 1} \implies \frac{2\sin\theta}{2\cos\theta} = \frac{8}{6} = \frac{4}{3}$$
$$\implies \tan\theta = \frac{4}{3}$$
অতএব, $$\sec\theta = \sqrt{1 + \tan^2\theta} = \sqrt{1 + \frac{16}{9}} = \sqrt{\frac{25}{9}} = \mathbf{\frac{৫}{৩}}$$।
প্রশ্ন কারা অধিদপ্তর (কারা তত্ত্বাবধায়ক)-১৩
সঠিক উত্তর: গ
$$\tan 45° = 1$$
$$\frac{1 - \tan^2 45°}{1 + \tan^2 45°} = \frac{1 - 1^2}{1 + 1^2} = \frac{0}{2} = \mathbf{০}$$ (বিকল্পভাবে $\cos 2A = \cos 90° = 0$)।
প্রশ্ন পররাষ্ট্র মন্ত্রণালয়ের সাইফার অফিসার-১২
সঠিক উত্তর: ক
আমরা জানি, $$\pi\text{ রেডিয়ান} = 180°$$
$$\frac{\pi}{10}\text{ রেডিয়ান} = \frac{180°}{10} = \mathbf{১৮°}$$।
প্রশ্ন পিএসসি (সহকারী তথ্য অফিসার)-২২
সঠিক উত্তর: গ
ধরি উন্নতি কোণ $\theta$।
$$\tan\theta = \frac{\text{উচ্চতা}}{\text{ছায়ার দৈর্ঘ্য}} = \frac{15}{5\sqrt{3}} = \frac{3}{\sqrt{3}} = \sqrt{3} = \tan 60° \implies \theta = \mathbf{৬০°}$$।
প্রশ্ন বিভিন্ন মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-২২
সঠিক উত্তর: গ
খুঁটির উচ্চতা $h$ এবং দূরত্ব $d = 10$ মি হলে,
$$\tan 60° = \frac{h}{10} \implies \sqrt{3} = \frac{h}{10} \implies h = \mathbf{১০\sqrt{৩}}\text{ মি}$$।
প্রশ্ন তথ্য মন্ত্রণালয়ের চলচ্চিত্র ও প্রকাশনা অধিদপ্তর ক্যামেরাম্যান-১৯
সঠিক উত্তর: ক
$$\tan 60° = \frac{\text{উচ্চতা}}{২৪০} \implies \sqrt{3} = \frac{\text{উচ্চতা}}{২৪০} \implies \text{উচ্চতা} = \mathbf{২৪০\sqrt{৩}}\text{ মিটার}$$।
প্রশ্ন বিভিন্ন মন্ত্রণালয়ের সহকারী মেইনটেন্যান্স ইঞ্জিনিয়ার-১৭
সঠিক উত্তর: ক
$$\tan 60° = \frac{h}{10} \implies h = 10\sqrt{3} = 10\times 1.732 = \mathbf{১৭.৩২}\text{ মিটার}$$।
প্রশ্ন আইন, বিচার ও সংসদ বিষয়ক মন্ত্রণালয় (সাব-রেজিস্ট্রার)-১৬
সঠিক উত্তর: ক
ধরি দূরত্ব $x$ মিটার।
$$\tan 30° = \frac{12}{x} \implies \frac{1}{\sqrt{3}} = \frac{12}{x} \implies x = \mathbf{১২\sqrt{৩}}\text{ মিটার}$$।
প্রশ্ন ভূমি মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-১৫
সঠিক উত্তর: ক
গাছটির মোট উচ্চতা ১২ মিটার। ভাঙা অংশের দৈর্ঘ্য = $12 - h$।
মাটিতে উৎপন্ন কোণ ৩০° হলে,
$$\sin 30° = \frac{\text{দণ্ডায়মান উচ্চতা}}{\text{ভাঙা অংশ}} = \frac{h}{12 - h}$$
$$\implies \frac{1}{2} = \frac{h}{12 - h} \implies 12 - h = 2h \implies 3h = 12 \implies h = \mathbf{৪}\text{ মিটার}$$।
প্রশ্ন পররাষ্ট্র মন্ত্রণালয়ের সাইফার অফিসার-১২
সঠিক উত্তর: ক
$$\text{উচ্চতা} = 10\tan 60° = 10\sqrt{3} \approx \mathbf{১৭.৩২}\text{ মিটার}$$।
প্রশ্ন কারিগরি শিক্ষা অধিদপ্তর (জুনিয়র ইন্সট্রাক্টর)-১৮
সঠিক উত্তর: ক
দণ্ডায়মান উচ্চতা $h = 16$ মিটার এবং ভূমির সাথে কোণ ৩০°।
ভাঙা অংশ অতিভুজ $L$ হলে,
$$\sin 30° = \frac{16}{L} \implies \frac{1}{2} = \frac{16}{L} \implies L = 32\text{ মিটার}$$
খুঁটিটির মোট উচ্চতা = $h + L = 16 + 32 = \mathbf{৪৮}\text{ মিটার}$$।
প্রশ্ন গণপূর্ত অধিদপ্তর (উপ-সহকারী প্রকৌশলী)-১৮
সঠিক উত্তর: খ
ধরি সম্পূর্ণ উচ্চতা $x$। দণ্ডায়মান অংশ লম্ব = $x/3$ এবং ভাঙা অংশ অতিভুজ = $x - x/3 = 2x/3$।
$$\sin\theta = \frac{\text{লম্ব}}{\text{অতিভুজ}} = \frac{x/3}{2x/3} = \frac{1}{2} = \sin 30° \implies \theta = \mathbf{৩০°}$$।
প্রশ্ন স্থানীয় সরকার প্রকৌশল অধিদপ্তর (সহকারী প্রকৌশলী)-১৭
সঠিক উত্তর: খ
ধরি $x$ ফুট উঁচুতে ভেঙেছিল। অতিভুজ = $18 - x$।
$$\sin 60° = \frac{x}{18 - x} \implies \frac{\sqrt{3}}{2} = \frac{x}{18 - x}$$
$$\implies 2x = 18\sqrt{3} - \sqrt{3}x \implies x(2 + \sqrt{3}) = 18\sqrt{3}$$
$$x = \frac{18\times 1.732}{3.732} \approx \mathbf{৯.৬৪}\text{ ফুট} (বইয়ের উত্তর: ৯ ফুট বা ৯.৬৪ ফুট)$$।
প্রশ্ন মাধ্যমিক ও উচ্চ শিক্ষা অধিদপ্তর প্রদর্শক-১৩
সঠিক উত্তর: গ
ধরি $h$ উচ্চতায় ভেঙেছিল। ভাঙা অংশের দৈর্ঘ্য = $48 - h$।
$$\sin 30° = \frac{h}{48 - h} \implies \frac{1}{2} = \frac{h}{48 - h}$$
$$48 - h = 2h \implies 3h = 48 \implies h = \mathbf{১৬}\text{ মিটার}$$।
প্রশ্ন পাসপোর্ট অ্যান্ড ইমিগ্রেশন অধিদপ্তর (সহকারী পরিচালক)-০৩
সঠিক উত্তর: গ
ধরি $x$ ফুট উঁচুতে ভেঙেছিল। ভাঙা অংশের দৈর্ঘ্য = $18 - x$।
$$\sin 30° = \frac{x}{18 - x} \implies \frac{1}{2} = \frac{x}{18 - x} \implies 18 - x = 2x \implies 3x = 18 \implies x = \mathbf{৬}\text{ ফুট}$$।
