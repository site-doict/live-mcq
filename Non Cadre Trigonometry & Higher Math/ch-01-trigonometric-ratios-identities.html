অধ্যায় ০১ পৃষ্ঠা: ৪৮৮–৪৯৪ মোট প্রশ্ন: 39টি

ত্রিকোণমিতিক অনুপাত ও অভেদাবলি (Trigonometric Ratios & Identities)

📌 প্রামাণ্য রিভিশন নোট ও সূত্রাবলি

📐 মৌলিক অনুপাত ও সম্পর্কের সূত্র

  • সাইন ও কোসেক: sin θ = লম্ব/অতিভুজ, cosec θ = ১/sin θ
  • কস ও সেক: cos θ = ভূমি/অতিভুজ, sec θ = ১/cos θ
  • ট্যান ও কট: tan θ = লম্ব/ভূমি = sin θ / cos θ, cot θ = ১/tan θ

⚡ ত্রিকোণমিতিক পিথাগোরীয় অভেদ

  • ১ম অভেদ: sin²θ + cos²θ = ১ (সুতরাং sin²θ = ১ - cos²θ)
  • ২য় অভেদ: sec²θ - tan²θ = ১ (সুতরাং sec²θ = ১ + tan²θ)
  • ৩য় অভেদ: cosec²θ - cot²θ = ১ (সুতরাং cosec²θ = ১ + cot²θ)

🔥 স্ট্যান্ডার্ড কোণের মান চার্ট (0°, 30°, 45°, 60°, 90°)

• sin: 0° = 0, 30° = 1/2, 45° = 1/√2, 60° = √3/2, 90° = 1

• cos: 0° = 1, 30° = √3/2, 45° = 1/√2, 60° = 1/2, 90° = 0

• tan: 0° = 0, 30° = 1/√3, 45° = 1, 60° = √3, 90° = অসংজ্ঞায়িত (Undefined)

📝 বিগত বছরের প্রশ্নব্যাংক

স্কোর: ০ / 39
প্রশ্ন পিএসসি নন-ক্যাডার (সংসদ সচিবালয়ের প্রশাসনিক কর্মকর্তা)-২৩
সঠিক উত্তর: ক
ট্যানজেন্ট ফাংশন $\tan\theta$ এর মানসীমা হলো $-\infty < \tan\theta < +\infty$। সুতরাং $\tan\theta$ এর সর্বনিম্ন মান অসীম ঋণাত্মক বা -∞।
প্রশ্ন প্রেসিডেন্ট এর কার্যালয় (পিএসসি), সহকারী প্রটোকল অফিসার-২৪
সঠিক উত্তর: গ
দেওয়া আছে,
$$\cot(\theta - 30°) = \frac{1}{\sqrt{3}} = \cot 60°$$
$$\implies \theta - 30° = 60° \implies \theta = 90°$$
অতএব, $$\sin\theta = \sin 90° = \mathbf{১}$$।
প্রশ্ন প্রেসিডেন্ট এর কার্যালয় (পিএসসি), সহকারী প্রটোকল অফিসার-২৪
সঠিক উত্তর: ঘ
$$\cos A = \cot A \implies \cos A = \frac{\cos A}{\sin A}$$
$$\implies \cos A \left(1 - \frac{1}{\sin A}\right) = 0$$
এখানে $\cos A = 0 \implies A = \mathbf{৯০°}$ (অথবা $\sin A = 1 \implies A = 90°$)।
প্রশ্ন পিএসসি (স্টাফ অফিসার)-২৩
সঠিক উত্তর: ক
সমকোণী ত্রিভুজে লম্ব = ৩ এবং অতিভুজ = ৫ হলে,
$$\text{ভূমি} = \sqrt{5^2 - 3^2} = \sqrt{16} = 4$$
অতএব, $$\tan\theta = \frac{\text{লম্ব}}{\text{ভূমি}} = \mathbf{\frac{৩}{৪}}$$।
প্রশ্ন পিএসসি (সহকারী পরিবার পরিকল্পনা কর্মকর্তা)-২২
সঠিক উত্তর: খ
$$\cos 45° = \frac{1}{\sqrt{2}}$$ দেওয়া আছে,
$$\sqrt{3}A = \frac{1}{\sqrt{2}} \implies A = \frac{1}{\sqrt{3}\times \sqrt{2}} = \mathbf{\frac{১}{\sqrt{৬}}}$$।
প্রশ্ন পিএসসি (সহকারী পরিবার পরিকল্পনা কর্মকর্তা)-২২
সঠিক উত্তর: ক
$$\cos\theta - \sin 2\theta = 0 \implies \cos\theta - 2\sin\theta\cos\theta = 0$$
$$\implies \cos\theta(1 - 2\sin\theta) = 0$$
যেহেতু $1 - 2\sin\theta = 0 \implies \sin\theta = \frac{1}{2} \implies \theta = \mathbf{৩০°}$।
প্রশ্ন পিএসসি (সহকারী তথ্য অফিসার)-২২
সঠিক উত্তর: ঘ
$$\cos^4\theta - \sin^4\theta = (\cos^2\theta + \sin^2\theta)(\cos^2\theta - \sin^2\theta)$$
$$= 1 \times \frac{1}{2} = \mathbf{\frac{১}{২}}$$।
প্রশ্ন বিভিন্ন মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-২২
সঠিক উত্তর: খ
$$\sin\theta = \cos\theta \implies \frac{\sin\theta}{\cos\theta} = 1 \implies \tan\theta = 1 = \tan 45° \implies \theta = \mathbf{৪৫°}$$।
প্রশ্ন তথ্য মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-২২
সঠিক উত্তর: ক
$$\cos\theta = \frac{1}{2} = \cos 60° \implies \theta = 60°$$
$$\cos(90° - \theta) = \cos(90° - 60°) = \cos 30° = \mathbf{\frac{\sqrt{৩}}{২}}$$।
প্রশ্ন সমাজকল্যাণ মন্ত্রণালয় (সুপারিনটেনডেন্ট)-১৯
সঠিক উত্তর: গ
$$\cos 120° = \cos(90°\times 1 + 30°) = -\sin 30° = \mathbf{-\frac{১}{২}}$$।
প্রশ্ন টেক্সটাইল ইঞ্জিনিয়ারিং কলেজ (ইন্সট্রাক্টর)-১৮
সঠিক উত্তর: গ
$$\sin 945° = \sin(10\times 90° + 45°) = -\sin 45° = \mathbf{-\frac{১}{\sqrt{২}}}$$ (১০টি সমকোণ অতিক্রম করে ৩য় চতুর্ভাগে অবস্থান করায় সাইনের মান ঋণাত্মক)।
প্রশ্ন বিভিন্ন মন্ত্রণালয়/অধিদপ্তরের ব্যক্তিগত কর্মকর্তা-১৮
সঠিক উত্তর: খ
ত্রিকোণমিতির মৌলিক অভেদ: $$\sin^2\theta + \cos^2\theta = \mathbf{১}$$।
প্রশ্ন গণপূর্ত অধিদপ্তর (এস্টিমেটর)-১৮
সঠিক উত্তর: ক
আমরা জানি, $$\sin 2\theta = 2\sin\theta\cos\theta \implies \sin\theta\cos\theta = \mathbf{\frac{1}{2}\sin 2\theta}$$। সুতরাং শুধুমাত্র (ক) বিবৃতিটি সত্য।
প্রশ্ন বিভিন্ন মন্ত্রণালয়/অধিদপ্তরের ব্যক্তিগত কর্মকর্তা-১৮
সঠিক উত্তর: ঘ
$$A = \frac{\pi}{6} = 30°, \quad B = \frac{\pi}{3} = 60°$$
$$\sin(A + B) = \sin(30° + 60°) = \sin 90° = \mathbf{১}$$।
প্রশ্ন বাংলাদেশ রেলওয়ে (উপসহকারী প্রকৌশলী সিভিল)-১৬
সঠিক উত্তর: ক
$$\cos\theta = \sqrt{1 - \sin^2\theta} = \sqrt{1 - \frac{9}{25}} = \frac{4}{5}$$
$$\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{3/5}{4/5} = \mathbf{\frac{৩}{৪}}$$।
প্রশ্ন বাংলাদেশ রেলওয়ে (উপসহকারী প্রকৌশলী সিভিল)-১৬
সঠিক উত্তর: খ
যেকোনো বাস্তব কোণ $y$ এর জন্য സൈন অনুপাতের পরিসর হলো $-1 \le \sin y \le +1$। সুতরাং $x = \sin y$ এর সর্বোচ্চ মান +১।
প্রশ্ন সহকারী পরিবার পরিকল্পনা কর্মকর্তা-১৬
সঠিক উত্তর: খ
$$\sin 2A = 2\sin A\cos A$$ সূত্রানুসারে, $A = 60°$ বসালে:
$$\sin(2\times 60°) = \mathbf{2\sin 60°\cos 60°}$$।
প্রশ্ন সহকারী পরিবার পরিকল্পনা কর্মকর্তা-১৬
সঠিক উত্তর: খ
আদর্শ ত্রিকোণমিতিক কোণ ছক অনুযায়ী: $$\sin 60° = \mathbf{\frac{\sqrt{৩}}{২}}$$।
প্রশ্ন উপজেলা মহিলা বিষয়ক কর্মকর্তা-১৬
সঠিক উত্তর: খ
কোসাইন ফাংশনের মানসীমা হলো $-1 \le \cos\theta \le 1$। অতএব এর সর্বনিম্ন মান -১।
প্রশ্ন আনসার ও ভিডিপি সার্কেল অ্যাডজুট্যান্ট-১৫
সঠিক উত্তর: ক
লম্ব = ৫, অতিভুজ = ১৩ হলে পিথাগোরাসের উপপাদ্য অনুযায়ী:
$$\text{ভূমি} = \sqrt{13^2 - 5^2} = \sqrt{144} = 12$$
অতএব, $$\tan A = \frac{\text{লম্ব}}{\text{ভূমি}} = \mathbf{\frac{৫}{১২}}$$।
প্রশ্ন বহিরাগমন ও পাসপোর্ট অধিদপ্তর সহকারী পরিচালক-১৪
সঠিক উত্তর: ক
$$\sin 30° = \mathbf{\frac{১}{২}}$$।
প্রশ্ন পিএসসি (সহকারী প্রোগ্রামার)-২২
সঠিক উত্তর: ক
$$\tan 2\theta = \frac{1}{\sqrt{3}} = \tan 30° \implies 2\theta = 30° \implies \theta = \mathbf{১৫°}$$।
প্রশ্ন ফায়ার সার্ভিস ও সিভিল ডিফেন্স অধিদপ্তর (স্টেশন অফিসার)-২২
সঠিক উত্তর: খ
$$\sec^2\theta = 1 + \tan^2\theta = 1 + (\sqrt{8})^2 = 1 + 8 = 9$$
$$\implies \sec\theta = \sqrt{9} = \mathbf{৩}$$।
প্রশ্ন ৪৬তম বিসিএস / পিএসসি নন-ক্যাডার
সঠিক উত্তর: গ
$$1 + \tan^2\theta = 4 \implies \tan^2\theta = 3 \implies \tan\theta = \sqrt{3} = \tan 60° \implies \theta = \mathbf{৬০°}$$।
প্রশ্ন পিএসসি নন-ক্যাডার (সংসদ সচিবালয়ের কর্মকর্তা)-২৩
সঠিক উত্তর: ঘ
$$\sin 2\theta = \frac{2\tan\theta}{1 + \tan^2\theta} = \frac{2\times (3/4)}{1 + (3/4)^2} = \frac{3/2}{1 + 9/16} = \frac{3/2}{25/16} = \frac{3}{2}\times \frac{16}{25} = \mathbf{\frac{২৪}{২৫}}$$।
প্রশ্ন প্রবাসী কল্যাণ মন্ত্রণালয় (সহকারী পরিচালক)-২৩
সঠিক উত্তর: গ
$$2\sin\theta = \sqrt{3} \implies \sin\theta = \frac{\sqrt{3}}{2} = \sin 60° \implies \theta = 60°$$
$$\cot(\pi/2 - \theta) = \tan\theta = \tan 60° = \mathbf{\sqrt{৩}}$$।
প্রশ্ন পররাষ্ট্র মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-২২
সঠিক উত্তর: গ
পোলার সমীকরণ $r = \sin\theta$ কে কার্তেসীয় স্থানাঙ্কে রূপান্তর করলে উভয়পক্ষে $r$ গুণ করে পাই:
$$r^2 = r\sin\theta \implies x^2 + y^2 = y \implies x^2 + \left(y - \frac{1}{2}\right)^2 = \left(\frac{1}{2}\right)^2$$
এটি একটি বৃত্তের সমীকরণ যার কেন্দ্র $(0, 1/2)$ এবং ব্যাসার্ধ $1/2$।
প্রশ্ন বিভিন্ন মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-২২
সঠিক উত্তর: ক
$$\tan A = \frac{1}{\sqrt{3}} = \tan 30° \implies A = 30°$$
অতএব, $$B = 90° - A = 90° - 30° = \mathbf{৬০°}$$।
প্রশ্ন রেলওয়ে মন্ত্রণালয় (হিসাবরক্ষণ কর্মকর্তা)-২২
সঠিক উত্তর: খ
লম্ব = ৫, ভূমি = ১২ হলে,
$$\text{অতিভুজ} = \sqrt{5^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = 13$$
$$\sin\theta = \frac{\text{লম্ব}}{\text{অতিভুজ}} = \mathbf{\frac{৫}{১৩}}$$।
প্রশ্ন পিএসসি (বিভিন্ন মন্ত্রণালয়ের প্রশাসনিক কর্মকর্তা)-১৯
সঠিক উত্তর: ঘ
যেকোনো সংজ্ঞায়িত কোণ $\theta$ এর জন্য পিথাগোরাসীয় মৌলিক অভেদ: $$\sec^2\theta - \tan^2\theta = \mathbf{১}$$। এখানে $\theta = 60°$ মানটি আলাদা করে গণনা করার প্রয়োজন নেই।
প্রশ্ন পিএসসি (প্রশাসনিক কর্মকর্তা)-১৯
সঠিক উত্তর: খ
$$\text{cosec}(90° - \theta) = \sec\theta = 2 \implies \cos\theta = \frac{1}{2} = \cos 60° \implies \theta = 60°$$
অতএব, $$\tan\theta = \tan 60° = \mathbf{\sqrt{৩}}$$ (বিকল্পভাবে $\tan 30° = 1/\sqrt{3}$)।
প্রশ্ন পিএসসি (প্রশাসনিক কর্মকর্তা)-১৯
সঠিক উত্তর: খ
$$\tan^2\theta = \sec^2\theta - 1 = \left(\frac{3}{2}\right)^2 - 1 = \frac{9}{4} - 1 = \frac{5}{4}$$
$$\implies \tan\theta = \mathbf{\frac{\sqrt{৫}}{২}}$$।
প্রশ্ন তথ্য মন্ত্রণালয় (ক্যামেরাম্যান)-১৯
সঠিক উত্তর: ঘ
$$\sec^2\theta = 4 \implies \sec\theta = 2 \implies \cos\theta = \frac{1}{2} = \cos 60° \implies \theta = \mathbf{৬০°}$$।
প্রশ্ন বিভিন্ন মন্ত্রণালয়/অধিদপ্তরের ব্যক্তিগত কর্মকর্তা-১৮
সঠিক উত্তর: ক
ভূমি = ২ এবং অতিভুজ = $\sqrt{5}$ হলে,
$$\text{লম্ব} = \sqrt{(\sqrt{5})^2 - 2^2} = \sqrt{5 - 4} = 1$$
অতএব, $$\tan\theta = \frac{\text{লম্ব}}{\text{ভূমি}} = \mathbf{\frac{১}{২}}$$।
প্রশ্ন গণপূর্ত অধিদপ্তর (উপ-সহকারী প্রকৌশলী)-১৮
সঠিক উত্তর: খ
$$\cos 2\theta = 2\cos^2\theta - 1 = 2\left[\frac{1}{2}\left(a + \frac{1}{a}\right)\right]^2 - 1$$
$$= 2\times \frac{1}{4}\left(a^2 + 2 + \frac{1}{a^2}\right) - 1 = \frac{1}{2}\left(a^2 + \frac{1}{a^2}\right) + 1 - 1 = \mathbf{\frac{1}{2}\left(a^2 + \frac{1}{a^2}\right)}$$।
প্রশ্ন বাংলাদেশ রেলওয়ে (উপসহকারী প্রকৌশলী সিভিল)-১৬
সঠিক উত্তর: গ
$$\sin 2\theta = \frac{2\tan\theta}{1 + \tan^2\theta} = \mathbf{\frac{2b}{1 + b^2}}$$।
প্রশ্ন জনপ্রশাসন মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-১৬
সঠিক উত্তর: খ
$$\frac{2\tan A}{1 - \tan^2 A} = \tan 2A = \tan(2\times 30°) = \tan 60° = \mathbf{\sqrt{৩}}$$।
প্রশ্ন সহকারী পরিবার পরিকল্পনা কর্মকর্তা-১৬
সঠিক উত্তর: খ
$$\tan\theta = 1 \implies \theta = 45°$$
আমরা জানি, $\cos(-\theta) = \cos\theta$।
অতএব, $$\sin\theta - \cos(-\theta) = \sin 45° - \cos 45° = \frac{1}{\sqrt{2}} - \frac{1}{\sqrt{2}} = \mathbf{০}$$।
প্রশ্ন জনপ্রশাসন মন্ত্রণালয়ের অধীনে পিএসসি'র সহকারী পরিচালক-১৬
সঠিক উত্তর: গ
$$\sin A = \frac{1}{2} = \sin 30° \implies A = 30°$$
অতএব, $$\cos A = \cos 30° = \mathbf{\frac{\sqrt{৩}}{২}}$$।
