বৃত্ত, কনিক্স ও ক্যালকুলাস (Circles, Conics & Calculus)

📌 প্রামাণ্য রিভিশন নোট ও সূত্রাবলি

⭕ বৃত্তের সমীকরণ ও বৈশিষ্ট্য

  • মূলবিন্দুতে কেন্দ্র বিশিষ্ট বৃত্ত: x² + y² = r² (ব্যাসার্ধ r)
  • (h, k) কেন্দ্র বিশিষ্ট বৃত্ত: (x - h)² + (y - k)² = r²
  • সাধারণ সমীকরণ: x² + y² + 2gx + 2fy + c = 0, কেন্দ্র (-g, -f), ব্যাসার্ধ = √(g² + f² - c)

📈 ক্যালকুলাস ও অন্তরীভবন (Calculus)

  • d/dx(xⁿ): n · xⁿ⁻¹
  • d/dx(eˣ): eˣ, d/dx(ln x): 1/x
  • যৌগিক নিয়ম: ∫ xⁿ dx = (xⁿ⁺¹)/(n+1) + c (n ≠ -1)

📝 বিগত বছরের প্রশ্নব্যাংক

স্কোর: ০ / 15
প্রশ্ন ১ পিএসসি নন-ক্যাডার বিভিন্ন মন্ত্রণালয়
d/dx (√x) = কত?
সঠিক উত্তর: খ
$$\frac{d}{dx}(\sqrt{x}) = \frac{d}{dx}(x^{1/2}) = \frac{1}{2}x^{1/2 - 1} = \frac{1}{2}x^{-1/2} = \mathbf{\frac{1}{2\sqrt{x}}}$$।
প্রশ্ন ২ আইন মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-২২
∫ ln x dx = কত?
সঠিক উত্তর: গ
আংশিক সমাকলন (Integration by parts) সূত্র $\( \int u v dx = u\int v dx - \int (u \)'\( \int v dx)dx \)$ ব্যবহার করে:
$$\int \ln x \cdot 1 dx = \ln x \cdot x - \int \frac{1}{x}\cdot x dx = x\ln x - x + c = \mathbf{x(\ln x - 1) + c}$$।
প্রশ্ন ৩ বাংলাদেশ রেলওয়ে (উপসহকারী প্রকৌশলী)-১৬
∫ (1/x) dx = কত?
সঠিক উত্তর: ক
মৌলিক সমাকলন সূত্র: $$\int \frac{1}{x} dx = \mathbf{\ln|x| + c}$$ (যেখানে $x \ne 0$)।
প্রশ্ন ৪ বাংলাদেশ রেলওয়ে (উপসহকারী প্রকৌশলী সিভিল)-১৬
y = x² বক্ররেখার (2, 3) বিন্দুতে ঢাল কত?
সঠিক উত্তর: গ
$$y = x^2 \implies \frac{dy}{dx} = 2x$$
$(2, 3)$ বিন্দুতে স্পর্শকের ঢাল = $$2(2) = \mathbf{৪}$$।
প্রশ্ন ৫ সহকারী পরিবার পরিকল্পনা কর্মকর্তা-১৬
2i + 3j + k এবং 3i + j - 2k এর স্কেলার (ডট) গুণন কত?
সঠিক উত্তর: গ
$$\vec{A}\cdot\vec{B} = (2\times 3) + (3\times 1) + (1\times -2) = 6 + 3 - 2 = \mathbf{৭}$$।
প্রশ্ন ৬ বহিরাগমন ও পাসপোর্ট অধিদপ্তর (সহকারী পরিচালক)-১৬
∫ (1/x²) dx এর মান কত?
সঠিক উত্তর: ক
$$\int x^{-2} dx = \frac{x^{-2 + 1}}{-2 + 1} + c = \frac{x^{-1}}{-1} + c = \mathbf{-\frac{1}{x} + c}$$।
প্রশ্ন ৭ কারা অধিদপ্তর (কারা তত্ত্বাবধায়ক)-১৩
d/dx (ln x) = কত?
সঠিক উত্তর: খ
লগারিদমিক ফাংশনের মৌলিক অন্তরজ: $$\frac{d}{dx}(\ln x) = \mathbf{\frac{1}{x}}$$।
প্রশ্ন ৮ পিএসসি (সহকারী তথ্য অফিসার)-২২
বৃত্তের কেন্দ্র (-1, 2) এবং ব্যাসার্ধ 3 সে.মি. হলে বৃত্তটির সমীকরণ কোনটি?
সঠিক উত্তর: ঘ
কেন্দ্র $(h, k) = (-1, 2)$ এবং ব্যাসার্ধ $r = 3$ হলে:
$$(x - h)^2 + (y - k)^2 = r^2 \implies (x + 1)^2 + (y - 2)^2 = 3^2$$
$$x^2 + 2x + 1 + y^2 - 4y + 4 = 9 \implies \mathbf{x^2 + y^2 + 2x - 4y - 4 = 0}$$।
প্রশ্ন ৯ পিএসসি (ইকোনমিস্ট)-২৪
নিচের কোনটি বৃত্তের সমীকরণ?
সঠিক উত্তর: গ
বৃত্তের আদর্শ আকার $(x - h)^2 + (y - k)^2 = r^2$ এর সাথে মিল রেখে: $$\mathbf{x^2 + (y - 2)^2 = 7}$$ একটি বৃত্ত নির্দেশ করে (কেন্দ্র $(0, 2)$, ব্যাসার্ধ $\( \sqrt{7} \)$)।
প্রশ্ন ১০ প্রধানমন্ত্রীর কার্যালয় (সহকারী পরিচালক)-১৩
x² + y² = 16 সমীকরণটির কেন্দ্র ও ব্যাসার্ধ কত?
সঠিক উত্তর: ক
$$x^2 + y^2 = 4^2$$ সমীকরণে কেন্দ্র মূলবিন্দু (0, 0) এবং ব্যাসার্ধ 4 একক।
প্রশ্ন ১১ ডাক অধিদপ্তর (বিল্ডিং ওভারশিয়ার)-১৮
x² - 169 + y² = 0 হলে বৃত্তটির ব্যাসার্ধ কত?
সঠিক উত্তর: গ
$$x^2 + y^2 = 169 = 13^2$$
অতএব বৃত্তটির ব্যাসার্ধ $r = \mathbf{১৩}$ একক।
প্রশ্ন ১২ পিএসসি (সহকারী পরিবার পরিকল্পনা কর্মকর্তা)-২২
3x² + 4y² = 12 সমীকরণটির লেখচিত্র কেমন হবে?
সঠিক উত্তর: ক
$$\frac{3x^2}{12} + \frac{4y^2}{12} = 1 \implies \frac{x^2}{4} + \frac{y^2}{3} = 1 \implies \frac{x^2}{2^2} + \frac{y^2}{(\sqrt{3})^2} = 1$$
যা $\( \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \)$ আকারের একটি আদর্শ উপবৃত্তের (Ellipse) সমীকরণ।
প্রশ্ন ১৩ পিএসসি (প্রশাসনিক কর্মকর্তা)-১৯
x² + y² - 64 = 0 এর লেখচিত্র কী হবে?
সঠিক উত্তর: গ
$$x^2 + y^2 = 64 = 8^2$$
এটি $(0, 0)$ কেন্দ্র ও $8$ ব্যাসার্ধ বিশিষ্ট একটি বৃত্ত (Circle) নির্দেশ করে।
প্রশ্ন ১৪ বাংলাদেশ রেলওয়ে (সহকারী স্টেশন মাস্টার)-১৬
x² + y² + 3 = 0 সমীকরণটি কী নির্দেশ করে?
সঠিক উত্তর: ক
$x^2$ ও $y^2$ এর সহগ সমান এবং $xy$ পদ নেই। সাধারণ দ্বিখাত সমীকরণ $ax^2 + 2hxy + by^2 + 2gx + 2fy + c = 0$-এ $a = b$ ও $h = 0$ শর্ত পূরণ করায় এটি একটি বৃত্ত (অবাস্তব ব্যাসার্ধের বৃত্ত) নির্দেশ করে।
প্রশ্ন ১৫ আইন মন্ত্রণালয় (কারা তত্ত্বাবধায়ক)-১০
x² + y² = a² বৃত্তের পরিসীমা (পরিধি) কত হবে?
সঠিক উত্তর: খ
$$x^2 + y^2 = a^2$$ বৃত্তটির ব্যাসার্ধ $r = a$।
অতএব বৃত্তের পরিধি বা পরিসীমা = $$2\pi r = \mathbf{2\pi a}$$ একক।
