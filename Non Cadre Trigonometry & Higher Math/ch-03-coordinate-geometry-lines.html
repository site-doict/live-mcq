স্থানাঙ্ক জ্যামিতি ও সরলরেখা (Coordinate Geometry & Straight Lines)

📌 প্রামাণ্য রিভিশন নোট ও সূত্রাবলি

📍 দুই বিন্দুর দূরত্ব ও মধ্যবিন্দু

  • দূরত্ব: d = √[(x₂ - x₁)² + (y₂ - y₁)²]
  • মধ্যবিন্দু: ((x₁ + x₂)/2, (y₁ + y₂)/2)
  • ত্রিভুজের ভরকেন্দ্র: ((x₁ + x₂ + x₃)/3, (y₁ + y₂ + y₃)/3)

📏 সরলরেখার ঢাল ও সমীকরণ

  • ঢাল (Slope, m): m = (y₂ - y₁) / (x₂ - x₁) = tan θ
  • সরলরেখার স্ট্যান্ডার্ড সমীকরণ: y = mx + c (m = ঢাল, c = y-অক্ষের ছেদক)
  • ax + by + c = 0 রেখার ঢাল m = -(x এর সহগ) / (y এর সহগ) = -a/b

⚡ রেখাদ্বয়ের সমান্তরাল ও লম্ব হওয়ার শর্ত

• দুটি রেখা সমান্তরাল হলে তাদের ঢাল সমান: m₁ = m₂

• দুটি রেখা পরস্পরের ওপর লম্ব হলে তাদের ঢালের গুণফল -১: m₁ × m₂ = -১

📝 বিগত বছরের প্রশ্নব্যাংক

স্কোর: ০ / 24
প্রশ্ন ১ পিএসসি (জেলা ক্রীড়া কর্মকর্তা)-২৩
(2, 3) বিন্দুটি নিচের কোন সমীকরণকে সিদ্ধ করে?
সঠিক উত্তর: খ
বিন্দু $(2, 3)$ এর মান অপশনগুলোতে বসিয়ে পাই:
ক. $2 + 2(3) = 8 \ne 5$
খ. $2(2) + 3 = 4 + 3 = 7 = 7$ (সিদ্ধ করে)
গ. $2 + 3(3) = 11 \ne 10$
ঘ. $2(2) + 4(3) = 16 \ne 6$
সুতরাং সঠিক উত্তর 2x + y = 7।
প্রশ্ন ২ ৪৫তম বিসিএস / পিএসসি নন-ক্যাডার
নিচের কোনটি সরলরেখার সমীকরণ?
সঠিক উত্তর: গ
আমরা জানি, সরলরেখার সাধারণ সমীকরণ $ax + by + c = 0$ আকারে $x$ ও $y$ এর একঘাত বিশিষ্ট হয় এবং এতে $xy$ পদ থাকে না।
গ. $$\frac{x}{y} - \frac{1}{x} = \frac{1}{y} \implies \frac{x - 1}{y} = \frac{1}{x} \implies x(x - 1) = y$$ বা সরলীকরণ করলে একঘাত সরলরেখা পাওয়া যায়।
প্রশ্ন ৩ ভূমি মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-২২
x + y - 1 = 0 এবং 4x + 4y + 1 = 0 রেখাদ্বয়ের ছেদবিন্দুর স্থানাংক কোনটি?
সঠিক উত্তর: ঘ
১ম রেখা: $x + y = 1$ বা ঢাল $m_1 = -1$।
২য় রেখা: $4x + 4y = -1 \implies x + y = -1/4$ বা ঢাল $m_2 = -1$।
যেহেতু উভয় রেখার ঢাল সমান ($m_1 = m_2 = -1$) কিন্তু ধ্রুবক ভিন্ন, তাই রেখা দুটি পরস্পর সমান্তরাল। সমান্তরাল রেখা কখনো ছেদ করে না, অর্থাৎ এদের ছেদবিন্দু অসীমে (∞, ∞)।
প্রশ্ন ৪ বিভিন্ন মন্ত্রণালয় (ব্যক্তিগত কর্মকর্তা)-২২
x + y + 3 = 0 রেখাটির ঢাল কত হবে?
সঠিক উত্তর: খ
$$x + y + 3 = 0 \implies y = -x - 3$$
$y = mx + c$ সমীকরণের সাথে তুলনা করলে ঢাল $m = \mathbf{-১}$।
প্রশ্ন ৫ বিভিন্ন মন্ত্রণালয় (প্রশাসনিক কর্মকর্তা)-২২
x-অক্ষের উপর y-অক্ষ হতে 3 একক দূরে অবস্থিত বিন্দুর স্থানাংক কোনটি?
সঠিক উত্তর: ক
$x$-অক্ষের উপর অবস্থিত যেকোনো বিন্দুর কোটি $y = 0$। এবং $y$-অক্ষ হতে ৩ একক দূরে অবস্থিত হওয়ায় ভুজ $x = 3$। সুতরাং নির্ণেয় বিন্দুর স্থানাঙ্ক (3, 0)।
প্রশ্ন ৬ পিএসসি (বিভিন্ন মন্ত্রণালয়ের প্রশাসনিক কর্মকর্তা)-১৯
x + 2y = 8 এবং 2x + y = 7 সরলরেখা দুইটির ছেদবিন্দু কোনটি?
সঠিক উত্তর: ঘ
$$x + 2y = 8 \quad \dots (1)$$
$$2x + y = 7 \implies y = 7 - 2x \quad \dots (2)$$
(১) নং-এ $y$ এর মান বসিয়ে:
$$x + 2(7 - 2x) = 8 \implies x + 14 - 4x = 8 \implies -3x = -6 \implies x = 2$$
$$y = 7 - 2(2) = 3$$
সুতরাং ছেদবিন্দু (2, 3)।
প্রশ্ন ৭ তথ্য মন্ত্রণালয়ের চলচ্চিত্র ও প্রকাশনা অধিদপ্তর ক্যামেরাম্যান-১৯
(3, -5) বিন্দুটি কোন চতুর্ভাগে অবস্থিত?
সঠিক উত্তর: ঘ
স্থানাঙ্কের চিহ্ন $(+, -)$ হলে বিন্দুটি ৪র্থ চতুর্ভাগে অবস্থিত (যেহেতু ভুজ ধনাত্মক এবং কোটি ঋণাত্মক)।
প্রশ্ন ৮ পিএসসি (বিভিন্ন মন্ত্রণালয়ের ব্যক্তিগত কর্মকর্তা)-১৯
নিচের কোনটি y অক্ষের সমান্তরাল রেখা নির্দেশ করে?
সঠিক উত্তর: ক
$y$-অক্ষের সমান্তরাল রেখার সমীকরণ সর্বদা $x = a$ (ধ্রুবক) আকারের হয়। সুতরাং x = 4 রেখাটি $y$-অক্ষের সমান্তরাল।
প্রশ্ন ৯ তথ্য মন্ত্রণালয়ের অধীন চলচ্চিত্র ও প্রকাশনা অধিদপ্তর ক্যামেরাম্যান-১৯
3x = y + 3 সরলরেখাটির উপরিস্ত বিন্দু কোনটি?
সঠিক উত্তর: ঘ
বিন্দু $(2, 3)$ বসিয়ে পাই:
বামপক্ষ = $3(2) = 6$
ডানপক্ষ = $3 + 3 = 6$
উভয়পক্ষ সমান হওয়ায় (2, 3) বিন্দুটি উক্ত সরলরেখার উপর অবস্থিত।
প্রশ্ন ১০ নার্সিং ও মিডওয়াইফারি অধিদপ্তর (সিনিয়র স্টাফ নার্স)-১৮
নিচের কোন সমীকরণের উপর (1, -1) ও (3, 5) বিন্দুদ্বয় অবস্থিত?
সঠিক উত্তর: খ
দুই বিন্দু দিয়ে গমনকারী সরলরেখার সমীকরণ:
$$\frac{y - (-1)}{-1 - 5} = \frac{x - 1}{1 - 3} \implies \frac{y + 1}{-6} = \frac{x - 1}{-2}$$
$$\implies \frac{y + 1}{3} = x - 1 \implies y + 1 = 3x - 3 \implies y = 3x - 4$$
উভয়পক্ষে ২ দিয়ে গুণ করলে: $$\mathbf{2y = 6x - 8}$$।
প্রশ্ন ১১ জনস্বাস্থ্য প্রকৌশল অধিদপ্তর (এস্টিমেটর)-১৮
(-3, 4) বিন্দুটি কোন চতুর্ভাগে অবস্থিত?
সঠিক উত্তর: খ
যেহেতু ভুজ ঋণাত্মক এবং কোটি ধনাত্মক $(-, +)$, তাই বিন্দুটি দ্বিতীয় চতুর্ভাগে অবস্থিত।
প্রশ্ন ১২ বিআরটিএ (মোটরযান পরিদর্শক)-১৭
(-3, -4) বিন্দুটি কোন চতুর্ভাগে অবস্থিত?
সঠিক উত্তর: গ
ভুজ ও কোটি উভয়ই ঋণাত্মক $(-, -)$ হওয়ায় বিন্দুটি তৃতীয় চতুর্ভাগে অবস্থিত।
প্রশ্ন ১৩ বিভিন্ন মন্ত্রণালয়/অধিদপ্তরের ব্যক্তিগত কর্মকর্তা-১৮
(2, -5) বিন্দুটি নিচের কোন সরলরেখার উপর অবস্থিত?
সঠিক উত্তর: গ
বিন্দু $(2, -5)$ অপশন (গ)-তে বসালে:
$$4(2) - 3(-5) = 8 + 15 = 23 = 23$$
সুতরাং সঠিক উত্তর 4x - 3y = 23।
প্রশ্ন ১৪ গণপূর্ত অধিদপ্তর (উপ-সহকারী প্রকৌশলী)-১৮
নিচের কোনটি সরলরেখার সমীকরণ নির্দেশ করে না?
সঠিক উত্তর: ঘ
$$y = \frac{2}{x} \implies xy = 2$$
এটি একটি আয়তাকার পরাবৃত্তের (Rectangular Hyperbola) সমীকরণ, সরলরেখা নয়। সরলরেখার সমীকরণে চলকের ঘাত এক হতে হয় এবং $xy$ পদ থাকতে পারে না।
প্রশ্ন ১৫ স্থানীয় সরকার প্রকৌশল অধিদপ্তর (সহকারী প্রকৌশলী)-১৭
x + y - 1 = 0, x - y + 1 = 0 এবং y - 3 = 0 সরলরেখাত্রয় দ্বারা গঠিত ত্রিভুজটি কী ধরনের?
সঠিক উত্তর: গ
১ম রেখা: $y = -x + 1 \implies m_1 = -1$
২য় রেখা: $y = x + 1 \implies m_2 = 1$
ঢালদ্বয়ের গুণফল: $$m_1 \times m_2 = (-1) \times 1 = -1$$
যেহেতু দুটি রেখার ঢালের গুণফল $-1$, তাই রেখা দুটি পরস্পর লম্ব। সুতরাং গঠিত ত্রিভুজটি একটি সমকোণী ত্রিভুজ।
প্রশ্ন ১৬ জনপ্রশাসন মন্ত্রণালয়ের ব্যক্তিগত কর্মকর্তা-১৬
মূল বিন্দু হতে (-5, 5) এবং (5, k) বিন্দুদ্বয়ের দূরত্ব সমান হলে k এর মান কত?
সঠিক উত্তর: ঘ
মূলবিন্দু $(0, 0)$ হতে দূরত্ব:
$$\sqrt{(-5 - 0)^2 + (5 - 0)^2} = \sqrt{(5 - 0)^2 + (k - 0)^2}$$
$$25 + 25 = 25 + k^2 \implies k^2 = 25 \implies k = \mathbf{৫}$$।
প্রশ্ন ১৭ সহকারী পরিবার পরিকল্পনা কর্মকর্তা-১৬
2x + 3y - 6 = 0 রেখাটি x অক্ষকে যে বিন্দুতে ছেদ করে তার স্থানাংক কত?
সঠিক উত্তর: ক
$x$-অক্ষকে ছেদ করলে $y = 0$ হয়।
$$2x + 3(0) - 6 = 0 \implies 2x = 6 \implies x = 3$$
ছেদবিন্দুর স্থানাঙ্ক (3, 0)।
প্রশ্ন ১৮ রেলওয়ে মন্ত্রণালয়ের সহকারী প্রকৌশলী-১৬
যদি X = (x, 0) এবং Y = (0, y) হয়, x + y = 0 এবং x ≠ y হয়, তবে XY রেখার ঢাল কত হবে?
সঠিক উত্তর: ক
$$m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{y - 0}{0 - x} = -\frac{y}{x}$$
যেহেতু $x + y = 0 \implies y = -x$, তাই
$$m = -\frac{-x}{x} = \mathbf{১}$$।
প্রশ্ন ১৯ জনপ্রশাসন মন্ত্রণালয়ের অধীনে পিএসসি'র সহকারী পরিচালক-১৬
y = x + 3 এবং y = -x - 3 রেখাদ্বয়ের ছেদবিন্দু কোনটি?
সঠিক উত্তর: ক
$$x + 3 = -x - 3 \implies 2x = -6 \implies x = -3$$
$$y = -3 + 3 = 0$$
ছেদবিন্দুর স্থানাঙ্ক (-3, 0)।
প্রশ্ন ২০ কারা অধিদপ্তর (কারা তত্ত্বাবধায়ক)-১৩
মূলবিন্দু O এবং P = (x, y) হলে, OP এর দূরত্ব কত?
সঠিক উত্তর: খ
মূলবিন্দু $(0, 0)$ ও $P(x, y)$ এর মধ্যবর্তী দূরত্ব:
$$OP = \sqrt{(x - 0)^2 + (y - 0)^2} = \mathbf{\sqrt{x^2 + y^2}}$$।
প্রশ্ন ২১ পিএসসি নন-ক্যাডার বিভিন্ন মন্ত্রণালয়
4x + 3y = 12 রেখাটি দ্বারা অক্ষদ্বয়ের সাথে উৎপন্ন ত্রিভুজের ক্ষেত্রফল কত বর্গ একক?
সঠিক উত্তর: ক
$$\frac{x}{3} + \frac{y}{4} = 1$$
এখানে $x$-অক্ষের খণ্ডিতাংশ $a = 3$ এবং $y$-অক্ষের খণ্ডিতাংশ $b = 4$।
উৎপন্ন ত্রিভুজের ক্ষেত্রফল = $$\frac{1}{2}ab = \frac{1}{2}\times 3 \times 4 = \mathbf{৬}\text{ বর্গ একক}$$।
প্রশ্ন ২২ পিএসসি সহকারী প্রকৌশলী পরীক্ষা
দুইটি সমান্তরাল সরলরেখার ঢালের মধ্যে সম্পর্ক কী?
সঠিক উত্তর: ক
দুটি সরলরেখা পরস্পর সমান্তরাল হলে তাদের ঢালদ্বয় পরস্পর সমান হয়, অর্থাৎ m₁ = m₂।
প্রশ্ন ২৩ পিএসসি নন-ক্যাডার কারিগরি পরীক্ষা
দুইটি সরলরেখা পরস্পর লম্ব হওয়ার শর্ত কোনটি?
সঠিক উত্তর: ক
দুটি সরলরেখা পরস্পর লম্ব হলে তাদের ঢালদ্বয়ের গুণফল সর্বদা -১ হয় ($m_1 \times m_2 = -1$)।
